# 中英文基础与终端接入

状态：基础实现完成，覆盖范围见下；负责人：Runtime / Native 集成代理；关联需求：T-P4-006 国际化；合同：[语言与消息合同](../../contracts/localization.md)。

`internal/localization` 使用仓库已锁定的 `golang.org/x/text` 处理 BCP 47；没有引入新的版本或临时安装依赖。静态模板使用标准库并限制为具名纯文本插值。所有语言选择均为函数参数，不共享可变当前语言。

CLI 可使用 `suma --language en-US --help` 或 `suma --language zh-CN --control http://127.0.0.1:4310 --project ID tasks`。语言头只影响展示，JSON 字段、任务状态、幂等操作及服务端具体诊断不会因切换语言而重写。交互终端包含项目／需求／任务／运行／流程、加载、空态、错误和键盘提示的中英文。原有安全测试继续检查凭证脱敏、重定向、投递签名、超时未知结果与稳定操作标识。

桌面主进程使用 Electron 的本机语言，可用本进程 `SUMA_LANGUAGE` 覆盖。启动失败、服务未就绪、异常退出和停止失败均有中英文；原始异常作为诊断保留。测试包括实际本机健康接口、实际子进程停止及隔离 Electron 的主入口启动失败交互。主入口模拟不等于安装包或真实桌面窗口验收。

专项验证原件保留在仓库忽略的 `.cache/e2e/localization-stage`，不进入 Git。原始工具和模型日志不翻译。Runner 的冻结源切面与本次 CLI／桌面新增切面分别核验；本阶段未将任何完整模型调用或跨平台安装验收记为通过。

后续接入顺序：账户／组织偏好及通知 → Runner 自有交互诊断 → 智能体自有提示 → 其余业务模块具体目录。机器协议只增加显示元数据，不翻译状态、资源单位、日志正文或证据内容。
