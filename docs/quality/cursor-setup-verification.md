## 实现

- 原高级工具入口接通唯一Cursor配置表单，六项明确输入派生固定Node／index.js，复用原节点身份、项目范围、fresh库存、暂停登记及单独启用，不落回通用JSON或反向MCP入口。
- PowerShell／Bash生成准确逐字引用和UTF8输入，明确把shell／文件路径草稿交给原执行节点指南；换项目／账号／目标时失效，已输入目标不被迟到回调覆盖。
- 原Go --prepare-tools新增--prepare-acp-stdin，私有stdin闭合五字段，复用BuildCursorACPCommand完整包闭包、固定参数及DecodeCommands／O_EXCL／Sync；危险／已有／包内及Windows别名目标在读取输入前拒绝。
- 配置准备只产生原ToolPreparation文件事实；不读取token、执行原生工具、探测版本、启动模型或自动登记／Claim／启用。共同语言环境读取保持原行为。
- 原Driver单一判断RPC完成及无悬而未决写入，Runner再核当前ctx、准确配置／包和真实全树停止；Cursor可在已完成RPC后受控停止长驻宿主，业务结果与真实非零宿主退出分别保存。
- 目录发现明确记录session_cancel_requested／session_cancel_written；标准通知没有native ACK。host_process_exit_code与host_stopped_after_rpc由Go、Schema、Web及桌面同时严格验证，不保留虚构close／ack别名。
- 原执行依据接纳并深校验190 user_inputs，绑定当前session、配置、typed ID及完整写入／执行关闭；修复外层来源匹配遗漏，未知证据不因新增字段而获得成功。
- 简洁中英文配置、折叠依据、390px与44px动作沿原组件；真实GUI发现复制异步disabled丢失键盘焦点，改为可聚焦busy状态及同步防重复入口，失败保留同一命令后可键盘重试。
