## 实际发现及修复

第一轮Vitest因默认最小worker数大于指定最大值而没有执行测试；明确minWorkers=1后43项通过。首轮浏览器探针精确匹配带下拉文本的标签失败，仅改探针定位。实际写入发现浏览器缺少Expected-User／Organization范围头，已按原scope固定发送并保留同操作重试；CLI写入自动附加查询参数被严格HTTP拒绝，改为正文明确绑定项目，测试服务增加真实拒绝条件。没有放宽后端合同来迁就客户端。

多人冲突恢复先展示服务器当前修订与本地草稿，再明确选择以草稿更新当前修订；不只替换版本号就掩盖他人改动。私有视图的活动标题使用固定文本，不泄漏名称或搜索词。
