## 本轮变化

- 已配置项目收起接入步骤，减少重复指引。详情优先展示当前条件、核对启用／暂停／撤销操作和常用事实，技术指纹与原始依据折叠保留。
- 登记表单分为节点、清单、命名三段；增加本地`.json`文件读取，限制256KiB，继续使用既有严格清单解析器。文件和文件名均不上传，明确登记时只发送原合同字段。
- 错误与输入关联，读中禁止保存，最新文件错误不会被旧解析错误遮住。清单替换、迟到读取、人工改名和读失败都有明确处理；原草稿保留。
- 保存入口位于独立操作区，表单内容单独滚动；375px下键盘焦点不被操作区遮挡。操作成功反馈只表示原写入回执，不替代当前派发资格，且按用户、组织和项目隔离。
