## 当前实现

界面在发布候选中提供轻入口、目录和单一详情；固定版本、制品与独立包测试按需展开，原计划双向追溯。写入保留原请求和操作，当前set/member/候选/制品/环境逐字段核对回执，允许原计划已推进但拒绝错配成员。拒权清除受保护结果，冲突保留草稿并显式读取新依据，中英文成对。
