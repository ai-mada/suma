- 浏览器家族固定 7 日，组织切换不续期；独立批准的项目 token 固定 24 小时，普通浏览器退出不撤销它。旧会话／scope 保留审计，缺可信来源或 Grant 时要求重新登录／发行。
- 工具、自动化、签名入口和共享执行池保留真实持久来源；退出交互会话不冒充撤销已有批准，但后续激活仍检查当前批准者及来源版本。
- 文件、制品和外部检索在锁外执行 IO，返回前重新授权。工作区恢复必须有真实受理记录；legacy prepared 状态不伪造接受。SSE 不在网络等待时持有 SQL 事务。
- Web 请求闭包固定原页面账户／组织；未知结果保留原 caller、key、正文。CLI 增加显式原视图参数，不自动获取新身份。中英文目录、错误与工具说明保持版本、原文、业务内容和机器码。
