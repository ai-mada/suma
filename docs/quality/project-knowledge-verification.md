## 本阶段交付

项目记忆、规范和技能共用一个资料工作区，具备草稿、提取、审阅发布、退役、来源版本核对和不可变历史。
任务仅显式引用已发布、来源有效的修订；预览和启动复核同一批准快照，Agent 工具只读明确发布引用。
技能是文本 SOP；提取是来源原文提取，未称为模型总结、插件安装或新增执行权限。

| 方面 | 已实现和验证的行为 |
|---|---|
| 权限与事务 | 当前 Actor／同事务 proof、项目隔离、浏览器批准、API 草稿权限、Agent 发布只读；成功回执先核验当前权限 |
| 版本与来源 | CAS、稳定 key、追加修订；新草稿不替换旧发布，来源变化／退役／新发布阻止旧未启动预览 |
| 上下文预算 | 16 项、正文 16,000 字节、完整 goal 32,000 字节；消费只传一次正文和来源凭证，完整引用原文仍留历史 |
| 恢复 | 原 caller／path／method／body／key 保持；未知后的 403／409 不换新操作；持久化失败先阻止发送；切换范围或卸载后的晚到成功仍可恢复 |
| 界面 | 类型／状态／文本筛选、分页、一个详情、按需历史、草稿与发布对照、来源预览与显式采用、冲突时保留编辑内容 |
| 中英文 | 成对领域目录，复用既有 i18next；用户正文、来源、版本和哈希保持，新增受控后端诊断 36 条 |
