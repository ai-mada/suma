# 任务派发工具选择与预览回执验证

T-TASK-DISPATCH-CHOICE-235 · 速码 1.0.0 · 2026-11-05。 [派发合同](../../contracts/task-dispatch-options.md) · [证据摘要](task-dispatch-choice-summary.json)

任务派发中的“查找兼容工具”允许直接选用任意兼容配置。当前页首个兼容项保留推荐标签，其他兼容项各有选用按钮。不兼容项显示原因。翻页选择可将清单中未加载的配置准确带入表单，模型设置取决于所选配置。手工清单说明库存就绪和兼容待核对。

| 验证 | 结果 |
| --- | --- |
| 定向 Web 回归 | 派发选项、工具交接、讨论派发、回执、Codex 和 OpenCode 共 24 项通过。覆盖第二页的非推荐配置、精确工具版本、同项目异组织响应和禁用原因。现有工具交接用例仍输出 React `act` 提示。 |
| 异常回执 | 修复前，普通工具收到其他工具的成功响应会清除待核对记录。修复后，错配及空响应被拒绝，恢复沿同一请求和操作标识提交，只有匹配的回执才确认。 |
| 浏览器 | 390×844 Chrome 运行实际选项组件和受控只读 HTTP 夹具。键盘选中非推荐项，核对返回的工具及完整版本依据。不兼容项无选用动作，中英文切换后焦点保留。只有一次选项 GET，无溢出及浏览器错误。首次执行的中文选择器文字不匹配，修正夹具后复用同一构建。 |
| 类型与国际化 | Web 全量 TypeScript 检查通过，10,205 对中英文词条通过。附带的两项旧知识选择测试在预览前寻找已被现有知识选择器替换的控件，仍然失败。 |
