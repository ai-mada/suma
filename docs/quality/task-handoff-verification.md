## 本阶段交付

独立交接域支持发起、指定接收人接收／退回及发起人撤回。固定任务／需求／原责任人与执行交付依据、真实账号与可选团队版本；当前权限先于幂等回放。接收在原 authority transaction／项目 guard 中原子更新 owner、任务版本与资格失效、交接／槽位／操作回执，保留原运行、测试和评审，不自动创建执行或验收。

任务详情增加默认折叠面板，展开才请求；新来源与历史分页、未知原操作恢复、冲突保留草稿、当前动作与接收影响确认均复用现有客户端机制。中文和英文、真实资源空态、时间／数字格式已接入。CLI 使用同一 API 与身份，不替接收人创建权限。
