## 交接规则

1. 原问题完成包测试复验和人工关单，当前权限与证据允许交接时，工作台提供发布候选入口。
2. 发布页重新读取该问题的准确轮次，锁定已验收任务、制品和证明，展示核对依据。操作者填写名称后明确创建。
3. 原候选创建事务重新验证当前轮次和任务版本。另一个同提交、同清单的制品也无法代替本轮的精确制品和证明。
4. 候选保留问题、轮次、任务、人工验收和制品来源。重开后，前向发布重新核对并阻止旧候选继续使用，原候选和回执保留供追溯。历史部署与回滚沿原事实核对。
