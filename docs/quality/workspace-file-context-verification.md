## 交付范围

读取与保存使用同一Go类型生成的公开合同。文件快照绑定租户、项目、正式绑定身份与实际打开目录的OS身份；内容相同、目录同名或A→B→A不能使旧草稿重新有效。保存仍检查当前权限，已完成原操作恢复持久原回执，已受理且来源无法证明的操作保留待核对。

界面区分内容冲突与工作区变化，展示当前与草稿来源，保留草稿及Monaco编辑模型。工作区变化不自动读取新目录或重定向保存；用户先读取当前文件，再明确采用当前来源并保留草稿或载入当前内容。账号／组织切换隐藏旧编辑状态；返回原范围可从有界进程内存恢复未完成草稿与原保存请求。刷新、关闭或超出保留窗口不提供持久草稿保证。

只修改当前1.0.0新库结构，不迁移或重写用户现有数据库。已声明但缺少必需列的结构在初始化写入前拒绝。本次实际服务使用独立忽略目录，不覆盖用户活动预览、数据库或桌面安装产物。
