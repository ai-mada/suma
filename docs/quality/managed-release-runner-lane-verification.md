# 共享池项目的专用发布通道验收

速码 1.0.0，`T-MANAGED-RELEASE-RUNNER-LANE-257`。关联需求为多项目分布式调度、制品发布、权限隔离及回滚。 [发布控制合同](../../contracts/release-control.md#专用项目发布执行通道) · [资源池合同](../../contracts/execution-pools.md#应用构建制品与独立包测试)

## 设计与操作

项目可持续使用默认共享池完成开发、构建和独立包测试。受管部署、回滚和有序发布由服务端创建项目专用运行，保留原审批、提供方授权及环境代数。子发布继承固定根路由。发布预览、计划和执行确认展示通道，实际启动和领取按已有授权与配额核对。

共享池领取仍以原池授权和固定运行路由为准。默认路由无需切换，已存在的发布操作继续恢复原回执。操作只在隔离测试环境验证。
