# 桌面返回前台时刷新工具发现

速码 1.0.0，`T-LOCAL-TOOLS-FOREGROUND-261`。关联需求为本机 CLI 自动发现、桌面配置、低成本探测和中英文交互。 [发现合同](../../contracts/local-tools-discovery-experience.md#返回桌面时核对安装变化) · [交互设计](../design/local-tools-discovery-experience.md)

## 实现与设计

安装或升级工具后回到已打开的桌面扫描区，界面可发起一次普通扫描。先复用当前观测的有效期，到期后仅在可见、聚焦且允许扫描时刷新。无持续轮询，手动重检保留原入口。自动刷新不预选工具；暂时失败时保留带参考提示的原观测。作用域变化或停止结果未确认时沿现有保护处理。

参考 Multica 在不重启守护进程的情况下重新发现安装与版本变化的做法。速码桌面采用前台事件与已有有效期，复用自身 Electron 扫描桥接和快捷接入权限。 [Multica 固定参考](https://github.com/multica-ai/multica/blob/e8b6a97643ccc35efbcf2a4675c8d088a288ed6e/server/internal/daemon/agents_refresh.go#L10-L62)

## 阶段验证

- 5 个受影响的 Web 测试文件共 42 项通过，其中 6 项新增回归覆盖前后台、连续焦点事件、禁用及未确认停止、选择与焦点、访问变化和时钟回拨。修正现有解析校验，拒绝缺少安装事实却附带可执行文件、版本或摘要的记录。TypeScript 与中英文目录检查通过。
- Windows 原生扫描的 20 项 Node 测试通过。通过生产桌面扫描控制器与实际 Go Runner 子进程，确认 59,999 毫秒普通请求复用原报告，60,000 毫秒发起新扫描并发现真实 Codex CLI。更换账号后旧报告未返回。权限请求使用隔离测试数据。
- Chromium 在 390 像素中文和 1280 像素英文下验证已过期观测从后台返回后只刷新一次、原工具和键盘焦点保留、无横向溢出。浏览器使用桌面桥接测试数据。证据保存在本地忽略目录 `.cache/q261/native/` 和 `.cache/q261/foreground-browser/`。

本阶段分别验证原生控制器与界面。完整 Electron 窗口跨平台联调、真实账号与模型服务仍沿原验收范围。
