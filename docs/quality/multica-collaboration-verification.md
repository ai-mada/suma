## 发现及针对性修正

1. 第一批Web检查因命令面板测试worker异常耗尽内存而整体失败；其他三个导航文件及MyWork文件已完成的结果分别保留，不能把整批写成通过。单文件及限定512MB探针定位到native Response解析尚未回到组件阶段；完整假时钟冻结响应流／React调度。只模拟setTimeout／clearTimeout后，同一用例在512MB条件下156ms通过，未提高堆上限或修改产品行为来规避。
2. 命令面板后续12项中11通过；一项测试误以为重读按钮文案是“重试”，实际成熟组件为“重新读取”。修正测试定位及原查询重放断言后，仅该项复测通过。诊断console全部移除。
3. 语言门禁发现搜索别名的中英文本在纯模型内；别名全部迁入配对目录，纯模型接收翻译后的字符串，新增中英交叉别名定向检查通过。当前语言门禁6885项、生产硬编码0。
4. 独立复核发现仅六状态白名单会拒绝真实分配的draft或自定义状态。增加draft筛选，返回状态与筛选枚举分别验证，All保留实际状态与计数；增加真实HTTP和DOM／模型回归。没有把未知状态改写成todo或丢弃记录。
