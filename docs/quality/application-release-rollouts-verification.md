## 实现与门禁

版本集的有序发布复用唯一Go DAG和原`subworkflow`，固定最多16个成员的准确原计划、审批、预留子运行及依赖。服务绑定不能由普通流程复制或伪造；直接操作受保护父／子运行不能绕过领域权限。开始及恢复须明确预览和确认，原批准、权限、来源、环境代数及预算仍按当前事实核验。

下游只在依赖子流程完成且原部署真实生效、健康、环境代数和制品均准确时启动。环境按成员就绪后预留，等待下游不提前占用部署屏障或执行进程。暂停停止新成员派发，在途子流程继续排空；未知或失败保留原事实并暂停，不自动制造新操作或重派副作用。原部署核对与明确恢复父流程分别记录；已健康成员沿原身份保留。

后台回调在既有事务和有限权威窗口内取得准确组织锁，重新核验实际持久浏览器凭证与当前角色；用户标识、机器凭证、已有deadline或其他组织的锁都不能作为授权。命令许可绑定当前实际事务与准确领域命令，使用后销毁。出站部署及核对仍由原Runner／提供方协议负责，不在调度事务内执行HTTP。

界面在原计划组中默认收起，按需读取所选运行，通过已有事件流刷新。一步显示应用、依赖、原计划、执行、生效及健康；依据和保留身份按需展开。中英文完整，历史直链通过准确运行及其原计划组读取，不扫描历史猜测归属。回执同时核对Go一致摘要及原成员身份，未知请求保留原请求恢复；未创建的子运行不提供失效链接。

## 验证范围

通过15项不同Go顶层检查、4项受影响Web行为及最终完整Web类型检查；655个生成模型、302条API、6042对中英文键（生产硬编码0）、文档链接／Schema与1.0.0版本检查通过。只运行本阶段受影响检查；首次Web行为失败及定向修复回执保留，详见机器摘要。

实际旅程确认：依赖应用真实下载期间，下游没有部署操作、执行资格或环境屏障；手动暂停后在途应用继续健康完成。明确恢复启动下游，真实提供方接受部署后丢失回执，原Runner回写未知并使父流程暂停。恢复连接核对同一原操作，再明确恢复，最终两个原子运行和真实静态内容均健康。两个原部署POST各一次，原未知执行结果及各自唯一批准记录保留。全部模型调用0，Web构建1次，未重复构建SDK或源码解析器。

真实运行是本地隔离的两个静态演示应用，包含源码、独立Worker同提交JUnit、测试账号明确Review、两项构建／包测试及原提供方实际HTTP部署。故障仅由测试私有传输注入：阻塞真实下载；真实部署已接受后丢失回执与观察。禁止直接写成功SQL、伪造审批／健康观察或加入生产强制成功开关。

首次故障注入过早丢弃异步部署POST的接受响应，Runner进入未知及父流程暂停先于提供方取得当前效果授权，因此正式门禁正确阻止了尚未授权的操作，测试未得到预期健康结果。修正仅限私有测试代理：原POST仍实际执行，等待真实提供方的已知终结事实后再丢响应；失败同样立即保留并报告。没有放宽暂停、授权或结果判断。仅重跑这一条真实旅程，首次回执保留。前端分别修正计划组校验标识、成熟刷新队列的清理调用及最后一项测试自身的crypto夹具，仅重跑对应失败用例，4个不同用例的有效结果分别列在摘要中。

完整旅程归档时又发现当前未知状态的展示仍沿用旧部署观察中的`queued/not_started/not_checked`。修正仅作用于版本集读取投影：原DAG已确认结果未知时显示`reconciling/unknown/unknown`，不重写部署或提供方历史。随后仅复验同一真实旅程，断言未知成员、健康兄弟与原历史各自正确；没有再构建Web或再开浏览器。浏览器保留的是修正前同旅程的最终健康事实，这条终结分支未改变；当前源码的未知投影复验单列回执，不将两次不同运行混作同一证据。

浏览器只读检查这些真实结果，包含中文、英文、390宽度、键盘、刷新与原计划／原运行追溯。受保护业务计数与内容摘要在检查前后保持一致，浏览器不启动、批准、登记或恢复业务操作。源码归档、数据库、原未知回执、制品及截图的摘要保留于证据索引；临时产物不进入Git。

## 剩余范围

已知失败需要新修正计划及对应批准，当前不支持原地改写或反复自动重试；整个版本集自动回退、任意提供方部署类型、多来源／不同提交的复合应用构建尚待实现。完整Octop CLI／GUI、厂商账户、物理多主机、OceanBase／PostgreSQL矩阵、跨平台签名安装、全部P0–P7及需求1–26保持待办。本地实际HTTP、测试账号Review和只读界面均不代表生产批准、客户签收或完整平台验收。

新增有序发布界面中英文成对。全平台运行文案仍需继续核对：英文原计划的已执行阻塞保留了中文消息，通用事件列表对`bound_execution_paused`暂显示技术事件名。词条静态检查不证明所有服务端运行内容均已翻译；这两个实际发现保留于浏览器摘要及后续待办。
