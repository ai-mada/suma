## 实际交付

工作区入口只读取元数据，删除递归遍历和旧 flat files 响应，不再返回绝对宿主根路径。独立目录接口使用当前项目权限、根约束、稳定文件身份和目录元数据快照；游标固定原调用者、项目、绑定、目录与快照。目录变化要求从第一页刷新，不拼接不同时刻的页。单目录最多扫描10000原始项，单页1–200项；此为实现界限，本次未做万项容量测试。

IDE侧栏提供面包屑、上一级、当前目录、已加载范围筛选及加载更多。导航／刷新不卸载编辑器；重新激活时先清旧目录并复核当前读取权限。CLI `workspace files`使用同一接口和原凭证，不读取客户端文件系统、不自动循环翻页。全部新增平台状态和错误成对中英，文件名和代码原文保留。没有新增表、第三方依赖、调度器或模型调用。

## 实际本机路径与界面
