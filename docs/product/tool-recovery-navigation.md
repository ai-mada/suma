# 工具诊断到连接准备

速码1.0.0 · T-TOOL-RECOVERY-NAVIGATION-217；负责人：工具工作台／主集成。领域依据见[合同](../../contracts/tool-recovery-navigation.md)，完整31项／P0–P7继续。

工具失联或库存过期时，用户应能从准确工具的诊断建议继续处理，知道目标机器和下一步，不必从添加工具重新找起。本阶段复用原诊断、项目节点、配对、准备指南、上报反馈和配置换新；不新增检测服务或修复执行器。

## 简洁操作

1. 打开工具详情。调整、启用／暂停、移除、用于任务等原操作先显示，诊断和历史继续按需查看。
2. 在该工具的有效诊断中打开执行节点。当前工具的公开草稿、原配置来源和准确Worker一起保留。
3. 在目标节点选择“准备连接”。系统重读当前诊断；若已有待核对检查或未知执行，先打开原核对记录。
4. 支持的普通项目工具继续原准确协议指南；身份阻塞时进入原明确配对流程。共享Pool不生成普通项目身份，按原所有者授权处理。
5. 用户在目标机器明确准备与启动，再沿原新上报反馈回原Quick核对配置。新建暂停配置、明确换新与启用仍是独立决定。

打开指南、复制命令和生成配置不代表已经执行、恢复健康或启用。系统不自动登录、安装、调用模型、发任务或停止进程。自动化体现在准确匹配当前工具／节点、保留公开填写信息和定位原操作；没有厂商通用自动修复声明。

先读当前profile版本／SHA、Worker和真实诊断，优先恢复原未确认操作。对同adapter／protocol使用原目录的唯一准确描述；通用command或未支持协议不得猜一个其他工具指南。当前账户、组织、项目、API调用者或配置改变后，旧异步结果失效。只把准确目标的新报告交回原Quick；该报告不是启用或测试验收证据。
