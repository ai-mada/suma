# 桌面本机连接

T-MULTICA-DESKTOP-153，速码 suma 1.0.0。用户在“添加工具”选择工具后，可明确点击“连接本机”，让桌面保存本机凭据并启动当前项目节点，继续已有工具配置流程。目标是减少复制 token、编辑清单和拼接启动命令。[合同](../../contracts/desktop-managed-runner.md)定义准确能力边界。

## 用户闭环

1. 选择 Codex JSONL、CodeBuddy CLI 或 DeepSeek Harness multica 入口；桌面读取原连接状态，不自动发行或启动。
2. 缺少项目目录时，使用现有原生目录选择器明确选择并绑定当前项目。目录须已是真实 Git root，存在完整 HEAD，且 `.cache/runner/worktrees` 被 Git 忽略；平台不代用户初始化或修改仓库。
3. 点击“连接本机”授权启动当前项目节点。页面显示准备、启动及等待新鲜报告；仅真实匹配报告到达后显示已连接。
4. 快速配置刷新私有／共享节点，选中准确本机节点并采用真实库存；“登记配置”仍保持暂停，另行明确启用。

即使已有旧登记节点但尚未上报工具，本机连接仍可进入。已有新鲜可用远程配置时，本机管理收起为次要入口；完成配置登记后仍能找到“停止本机节点”。

## 恢复与用户反馈

| 情况 | 用户看到的下一步 |
| --- | --- |
| 发行或连接结果未知 | 核对原连接，必要时明确恢复原连接；本机保留原请求，不悄悄另建节点 |
| 工具未安装／固定协议不可用 | 检查安装情况后重新读取；安装不表示已登录供应方 |
| 当前权限不足或已撤销 | 恢复当前访问权限；不继续提供连接启动操作 |
| 原 token 丢失／OS 存储不可用 | 明确不可恢复；原节点处置和续权的完整交互仍待办 |
| 项目目录、提交或服务地址变化 | 停止采用旧连接，明确核对原绑定和原服务 |
| 已停止／停止未确认 | 分别展示；任务结果继续打开原运行核对 |

## 当前限制

当前是桌面内置 loopback SQLite 控制面的三工具薄纵向；不代表远程 SaaS 自动连接本机、多主机管理或全部工具接入完成。原 Grant 有效期24小时，历史回执不会延长有效期；到期不自动换 token，明确续权交互仍待交付。

默认本机地址为 `127.0.0.1:4319`，启动进程可明确指定1024–65535端口；占用时报告失败，不随机换地址。改变服务 origin 不会静默复用原加密记录。

Windows Electron35.7.5软件离屏环境的17项实际检查已限定通过，覆盖真实 DPAPI、正式 Go Worker、本机连接、一次暂停登记／独立启用、停止及同节点恢复；中文1366和英文390图片已目视。首次 GUI 在小数秒库存解析处失败，修复后沿原凭据和节点续验，详见[验证记录](../quality/desktop-managed-runner-verification.md)。

本轮只运行合成 CodeBuddy 兼容探测，0任务／0运行／0模型调用。原生目录签名与绑定真实，但系统目录对话框固定返回自有 fixture 路径，未验系统选择器界面。真实供应方、强制崩溃恢复、macOS／Linux系统凭据存储、安装包、多机、规模及生产仍待验。连接成功不代替供应方登录、模型权限、预算、任务成果、独立测试或人工验收。
