# 目标工具上报反馈

版本：1.0.0；阶段：T-TOOL-REPORT-FEEDBACK-204；负责人：主集成代理。状态：本阶段实现与限定验证通过。关联[合同](../../contracts/tool-report-feedback.md)、[架构与AI SOP](../architecture/tool-report-feedback.md)、[交互](../design/tool-report-feedback.md)。

## 用户目标

用户在原接入指南生成目标机器命令后，可以直接检查当前工具清单，或明确等待新上报，再回到准确工具和节点核对配置。无需手动寻找原配置入口，也不会把旧清单当成刚复制命令的执行结果。

## 交付范围和验收

| 操作 | 可见行为与约束 |
| --- | --- |
| 检查上报 | 只读当前项目、明确节点和准确协议的正式目录与库存；展示未上报、过期、当前清单、不可用原因或未知。 |
| 等待新清单 | 明确点击后固定服务端时间基线，最多等待60秒，每3秒查询；隐藏页面暂停查询，总截止不延长。可随时取消。 |
| 收到新清单 | 新鲜观察时间严格晚于等待基线，保留纳秒精度；旧ACK、相同时间或时间回退不视为新上报。 |
| 核对配置 | 从当前未过期且可用的准确条目返回原快捷连接；节点、协议、命令准确带入，仍重新检查权限和正式事实。 |
| 调整配置 | 编辑工具、路径、身份、控制地址等字段，或重新采用配置，立即清除旧反馈和等待；普通重渲染保留人工输入。 |
| 授权失效 | 401、403、404停止等待并清除观察；网络异常表示状态未知，保留明确重新检查入口。 |

清单只表示服务端接收到的工具观察。复制、文件生成、原回执恢复、工具可用、配置登记和启用分别判断。当前清单也可能来自持续运行的Worker，本功能不宣称与某条命令、某个文件形成严格因果关系。

## 原流程继续复用

准确目录匹配、完整能力校验、已有配置核对、创建暂停配置、独立启用、Doctor、换新与撤销仍使用原领域能力。不会自动登记或启用，不增加表、业务API、连接服务或第二调度器。九种已支持本地工具均可采用同一反馈流程；具体工具支持范围以正式适配目录为准。

完整平台与真实厂商、多机、跨库及生产验收继续按原实施计划交付。本阶段证据见[限定验证](../quality/tool-report-feedback-verification.md)。
