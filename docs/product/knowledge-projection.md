# 知识索引同步与当前授权检索 PRD

状态：本阶段限定实现并验证；suma 1.0.0；T-KNOWLEDGE-PROJECTION-197；负责人：平台集成。复用[已发布知识发现](knowledge-discovery.md)、原发布审核、准确修订预览与任务引用。完整31项及P0–P7目标继续。

团队需要让已经审核的知识自动进入可核对的检索索引，在重新发布、退役、服务重启或嵌入配置变化后保持准确。知识发布成功、索引投递、当前检索覆盖及任务采用分别展示证据。

| 编号 | 用户场景 | 验收结果 |
| --- | --- | --- |
| R197-1 | 发布、重新发布或退役 | 业务操作、固定事件及原回执同事务保存；网络投影在事务外执行 |
| R197-2 | 文档与知识使用相同来源ID | 领域身份贯穿事件、目录、分块、删除与检索，互不覆盖 |
| R197-3 | 编辑未发布草稿 | 旧审核发布仍可检索；事件顺序与发布修订独立，不把草稿版本当发布依据 |
| R197-4 | 丢失回执、重复或乱序事件 | 准确操作可幂等恢复；退役墓碑阻止旧发布复活，冲突内容不能覆盖原记录 |
| R197-5 | 使用索引检索 | 真实全文与配置的向量检索按实际方式返回；服务失败保留原输入，明确切换关键词检索 |
| R197-6 | 预览命中段落 | 来源、修订、摘要及Unicode码点范围准确；原文重建片段，明确选入原任务引用 |
| R197-7 | 发布或权限发生变化 | 远端结果返回后重新核验当前项目及原来源，过时或不可访问内容不返回用户／模型 |
| R197-8 | 查看索引状态 | 展示该领域真实投递计数、处理代次与观察时间；局部水位不冒充全项目完整覆盖 |
| R197-9 | 更换处理配置或重启 | 依据固定快照有界重建，保留墓碑和失败；完整切换前明确重建状态，预算与截止可配置 |
| R197-10 | 工作台、CLI与智能体协作 | 同一正式来源与原任务门禁；查询不自动采用、批准或启动开发 |

原始知识与来源继续保存在事务数据中。索引是派生数据，按处理代次可恢复；原16引用与32000 UTF-8字节任务输入约束保持。外部记忆系统、双向同步、物理多机共享索引和完整规模验收分别交付。

限定实现与实际边界见[验证报告](../quality/knowledge-projection-verification.md)。
