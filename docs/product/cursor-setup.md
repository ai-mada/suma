# Cursor 独立节点配置 PRD

状态：限定实现与验证通过；suma1.0.0；T-CURSOR-SETUP-191。负责人：主集成代理；关联[合同](../../contracts/cursor-setup.md)、[架构与AI SOP](../architecture/cursor-setup.md)、[交互](../design/cursor-setup.md)及[证据](../quality/cursor-setup-verification.md)。原31／P0–P7完整目标继续。

用户从工具管理高级入口选择Cursor，填写目标Shell、官方包目录、完整核对版本、准确模型ID、凭据环境变量名及全新命令文件路径，即可复制真正可执行的准备命令。此操作只生成本机私有配置，不要求手工计算摘要、编辑JSON或提供密钥值。客户端调用速码的Cursor MCP配置与速码派发Cursor是不同方向，不混用入口。

| 步骤 | 验收结果 |
| --- | --- |
| 选择工具 | 原工具入口直接打开唯一Cursor配置面板，保留当前账号／项目／目标范围 |
| 填配置 | 固定包Node由目录派生；严格字段／长度／路径／环境引用校验，不接任意argv／hash |
| 复制准备命令 | PowerShell／Bash准确引用并传UTF8；未完整填写时不能复制；失败保留原文 |
| 在目标节点运行 | 原Go核完整包并O_EXCL写全新文件；不覆盖、不取token、不启动模型或自动连接 |
| 交给执行节点指南 | 明确将shell／文件路径非权威草稿用于原节点流程，不重复身份，不再生成Cursor缺参数命令 |
| 登记与启用 | 用户运行原describe／report后按真实fresh库存暂停登记，再单独明确启用；不是复制即成功 |

准备命令不探测真实版本／凭据／模型；版本字符串是管理员声明，后续原原生检查才证明实际事实。文件准备、节点连接、可派发库存、模型配置ACK、代码候选、独立测试和验收分别记录。

Cursor ACP是服务，成功RPC后可由速码受控结束宿主。仅当准确请求完成、没有pending／截断／未知写、当前执行未取消／到期、配置未变及进程树停止有实证时，该停止可保留成功操作结果。界面仍显示真实非零宿主退出值；这不是CLI自然退出0或native取消ACK。

用户取消、超时、未回答、权限拒绝、流错误、部分写及不能确认树停止继续unknown，不自动重答或新开Prompt。真实厂商账号／模型、Unix当前未证明的后代约束、跨平台安装及完整平台仍独立验收。
