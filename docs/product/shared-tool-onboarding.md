# 共享工具发现与接入

速码1.0.0 · T-SHARED-TOOL-ONBOARDING-219。依据[领域合同](../../contracts/shared-tool-onboarding.md)，完整31项／P0–P7目标继续。

共享Pool节点已经支持原安装检测、持续维护、授权与库存上报。本功能补齐检测之后的接入路径：保留选中的工具、节点和项目，进入准确的资源池拥有方准备流程。共享机器使用Pool身份，不再出现普通项目Runner身份指南。

## 用户步骤

1. 在准确共享节点的安装检测结果、接入提示或Quick高级准备中选择工具。检测只能说明观察到的安装情况，不能替代完整工具配置。
2. 在共享节点提示中继续准备连接。系统重新核对当前目录、节点与选择来源；入口不可用时提示重新核对，不切换为普通身份命令。
3. 拥有方工作台读取准确Pool、Runner和项目授权，再明确打开原准备表单。预选公开项目标识，机器路径、Shell、输出文件与配置参数仍由用户填写。
4. 已有配置生成器可提供离线准备命令及所选输出路径。复制路径不读取远程文件，也不证明文件已生成；须在目标机器明确生成、核对，再填入原Pool配置。
5. 沿原连接区检查与明确启动。核对到期时保留同来源表单输入，禁用生成、复制及继续；在弹窗内重新核对后再操作。
6. 当前权限允许打开项目时，返回原Quick并预选准确工具与Worker。登记仍要求完整新鲜库存和原matches核对；新建档案默认暂停，启用需要独立确认。

未登记工具使用独立的新接入定位，不制造旧ToolProfile或换新来源。已有配置的诊断恢复继续[共享节点恢复流程](team-workstation-recovery.md)，保留准确旧版本／SHA；明确换选项目则按新的通用接入处理。

## 权限与使用边界

项目工具管理权不能替代Pool管理权。拥有方受限、项目不可读、授权未批准或身份失效时，沿原受限说明、授权、轮换或配对流程处理，不自动切组织或扩大Grant。原未确认写入及未知检查始终优先。

Pool拥有方可为当前已批准的跨租户Scope离线准备配置，无需取得消费项目读取权；此时不读取项目数据，也不提供返回项目链接。当前拥有方读取明确返回401／403／404时，关闭对应准备弹窗并清除其中私有草稿，显示受限状态；普通到期或临时网络失败仍保留同来源输入并禁用操作。

导航、复制、配置准备和安装观察都不等于实际恢复、在线或可派发。本阶段不自动安装、登录、执行命令、登记、启用或调用模型；真实远程机器、厂商执行和完整平台验收仍需独立证据。

## AI操作与维护

先读取当前账户、项目、准确Worker与原操作记录，再使用正式工具目录的准确协议。共享节点必须进入原Pool身份链；新接入与已有配置恢复分别处理。只把当前完整库存交给原登记流程，不从安装元数据猜命令、模型、凭据或私有路径。复用已有维护、配置和执行能力，不增加第二套权限或调度权威。

服务端成功响应中明确报告授权撤销、节点或凭据失效时，同样撤下准确旧准备来源；只有项目不可读不视为离线准备授权失效。
