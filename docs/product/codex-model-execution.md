# Codex 任务模型配置 PRD

状态：1.0.0／T-P4-041，限定单任务实现；Owner：研发平台。需求9、12、14、18、21、22。[合同](../../contracts/codex-app-server.md)、[实现与证据](../quality/codex-app-server-verification.md)。

目标：开发者在现有任务中选择真实CLI支持的模型、推理强度及可选用量提醒，查看固定依据后明确启动；运营者能辨别配置确认、实际代码效果、部分用量、正式质量门禁和未知费用。

## 用户流程与验收

1. 任务详情→安排工具执行：选择已发布流程和当前工具。只有经过实际协议发现且仍符合授权的工具可用；失效说明可下钻工具设置。
2. 选择模型后展示实际支持的推理强度；可选提醒渐进展开。当前不开放无法保证的费用／步数／输出硬上限；项目enforce策略不能用此工具派发。
3. 固定预览保存完整任务及需求、知识、工具／目录摘要、模型、参数、阈值。语言切换保留草稿；刷新定位准确固定计划。
4. 明确勾选并启动同一计划。资格变化要求新预览，未知结果使用原操作核对，不能自动再次开任务。
5. 运行详情展示原进展、配置ACK、尝试、候选、提醒与部分用量；代码交付继续经过独立测试及人工验收。厂商实际模型和价格未知时明确表达。

团队逐任务原生配置已由040支持；外部Codex团队／修复选择尚需单独合同。完整远程IDE和其他工具继续按总计划推进，不用此单任务交付替代完整能力。
