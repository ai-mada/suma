# WorkBuddy 项目账号授权

T-WORKBUDDY-CONNECTIONS-147，速码初始产品1.0.0。本页定义当前连接体验；字段与状态以[领域合同](../../contracts/workbuddy-connections.md)为准，模块边界见[架构](../architecture/workbuddy-connections.md)。产品说明不代替实现或验收证据。

用户在当前项目中管理自己的 WorkBuddy 授权，选择权限、完成官方确认，再查看授权结果。云任务的派发资格在对应任务或运行中核对。WorkBuddy 云服务与 CodeBuddy CLI 分别管理。

## 身份与可见范围

连接绑定当前租户、项目和所有者。列表、连接详情只展示当前所有者的连接，项目管理员不能借此读取其他人的私有授权。两者需要当前项目读取权；发起、完成授权、刷新和本地断开需要当前项目写资格。读取仍可能返回私密链接的原授权实例，还须具备原浏览器会话及当前写资格。外部账号ID不赋予速码身份或项目权限。

权限、服务配置与授权状态分别表达。服务端返回当前允许动作，界面据此提供入口；有一条连接记录、配置了应用或显示“已授权”，均不表示工具可派发、模型健康或远端任务已停止。

## 明确完成一次授权

1. 在当前项目的工具设置中展开“WorkBuddy账号授权”。默认收起，展开才加载当前所有者的分页连接。
2. 首次连接时直接勾选要申请的权限。已有记录时，可添加账号或从原记录重新授权。每项权限旁有用途说明，初始均未选。
3. 点击“继续授权”。速码准备本次授权实例，并将焦点移到 WorkBuddy 授权入口。
4. 打开官方授权页，核对账号和权限。浏览器使用新标签页，桌面使用同会话的隔离子窗口。也可以返回连接列表，查看原待授权记录。
5. 官方返回独立安全回调页。回调核对原浏览器会话、当前项目资格及绑定的授权实例，再返回原项目的连接面板。用户也可按原连接ID查询结果；查询本身不完成未知操作。

新授权绑定原浏览器会话，换账号、换组织或重新登录后不能沿用旧链接。若链接丢失或过期，可在原连接上重新选择权限并生成链接。生成后旧链接失效。若原兑换已经开始，则继续核对该操作。拒绝官方授权只取消原待办，不调用令牌兑换。

## 桌面会话与返回

桌面授权沿父窗口同一Session；平台先核对当前本人及原授权实例，再打开官方页面。子窗口不继承父窗口preload或Node权限，普通额外弹窗仍拒绝。回调只能回到原项目／原连接，关闭子窗并聚焦父页，保留原文档与草稿。

窗口打开、关闭或返回都不等于已连接。仅在没有表单草稿、未确认写入或打开中操作时，页面才GET核对准确原连接；不自动reload，不用另一条同项目连接代替。桌面能力缺失时仅提供平台地址，让用户在普通浏览器自行登录并开始新的授权，不转移Cookie、state、code或token。

## 连接事实与后续动作

| 状态 | 用户应理解的事实与动作 |
| --- | --- |
| 等待授权 | 原实例尚待官方确认；通过仍有效的原链接完成，或读取当前状态 |
| 已授权 | 已保存供应方授权并展示实际权限与到期时间。到对应任务或运行核对云任务派发资格 |
| 正在刷新授权 | 已准备一次刷新；等待原结果，不重复发起 |
| 授权／刷新结果未知 | 供应方可能已处理；查看原连接或恢复原操作，不把超时当成失败重发 |
| 需要重新授权 | 旧资格不能继续使用；按当前允许动作重新选择范围并明确确认 |
| 已本地断开 | 速码不再使用该连接；不表示供应方撤权或远端任务停止 |

“刷新列表”只读当前事实；“刷新授权”才是明确的令牌操作，两者不能混用。普通刷新沿原连接推进令牌代次；重新授权是新的授权决策。实际授予范围可小于请求范围，不能静默扩大。重新授权不能把原连接换绑到另一外部账号。

本地断开须勾选说明并确认。它清除本地凭据、使旧活动资格失效，迟到响应不能恢复连接；服务配置失效时仍可在当前资格下本地断开。远端授权和任务应分别在供应方核对。

## 恢复、分页与交互状态

操作结果未知时保留原账号、组织、项目、版本、操作标识及原JSON，先读取当前状态或恢复原操作。恢复核对原回执，不取得第二次供应方兑换／刷新发送许可；不能通过修改范围、版本或新操作标识把恢复变成重试。

加载、空列表、服务未配置、读取错误、权限失效与版本冲突分别反馈。列表默认每页20条，提供明确前后页，不用当前页推算总数。账号、组织或项目变化隔离迟到响应；失权隐藏受保护事实和旧授权链接。未保存的范围选择、断开确认沿原离开保护处理。

界面提供中英文、明暗主题、窄屏排布、可见焦点及至少44px操作目标。账号ID、修订、实际scope等原始事实保持准确，不被翻译或改写。具体交互和安全回调见[交互与AI SOP](../design/workbuddy-connections.md)；[English](../en/workbuddy-connections.md)。
