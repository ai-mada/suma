# 1.0.0 产品与设计基线

更新：2026-10-28。产品名称：速码一栈式智能研发平台，简称速码，英文 suma。当前统一开发版本 **1.0.0**；完整平台仍在实现与验收中，生产集成尚未完成。

本页统一产品范围、初始化策略与工程约束；[实施计划](../delivery/implementation-plan.md)是完整 P0–P7 待办台账，[交付状态](../delivery/status.md)说明当前能力，[文档索引](../README.md)连接各领域设计、合同与专项验收。

## 单一当前设计与初始化

接口、数据模型、模块与交互直接采用当前最合理结构，删除冗余历史兼容分支，不增加旧字段别名、双写、旧版本协议转换或重复业务中心。数据库采用单一新库初始化，不保留旧库升级链、历史调度回填或旧凭证分类迁移。

既有运行数据、凭据、业务版本、原始结果、日志与审计证据保持原件；版本统一不授权清库、覆盖旧目录或删除用户文件。使用明确的新数据目录初始化 1.0.0，旧库不会自动迁移。跨后端数据迁移、备份与恢复仍属正式产品能力，须单独设计和验收。

产品 release SemVer 固定为 1.0.0；第三方 SDK／CLI 版本、API／执行协议版本、业务修订、数据版本、操作 ID、attempt／fence 及不可变执行证据各有独立语义，不能批量替换为产品版本。当前授权、原操作核对、幂等恢复和安全屏障继续保留。

## 工程与验收纪律

成熟且维护中的工具包、框架和官方 SDK 优先，固定实际参考版本和许可；前后端分离，领域／模块职责清楚，配置、日志及必要代码／接口注释支持人员与 AI 后续维护。共享合同由集成者维护，按明确文件归属并行交付。

默认页面简洁，常见操作直接可见，低频依据按需展开。所有已实现表面纳入 `FND-I18N-001`：初始 `zh-CN`／`en-US`、语言协商与偏好、格式化、界面／无障碍／校验／错误／诊断／通知／CLI／桌面／扩展／文档；用户正文和不可变证据保留原文，不能以目录键数代替完整验收。

只验证新增行为、权限、事务、一致性和代表性交互；有效且未变的证据可复用，不重复模型调用、完整套件或设备矩阵。源码实现、本地协议、真实厂商、正式业务验收和生产交付分别记录；未配置、未知与未验证必须明确表达。Git 保留历史，专项报告保留原证据，当前入口只维护一个事实基线。
