# 执行工作区：产品与交互规格

状态：1.0.0／T-P4-037，本地功能实现；真实界面证据以[验证报告](../quality/workspace-observation-verification.md)为准。负责人：平台集成。关联需求：远程工作区、分布式CLI／智能体执行、简洁IDE与完整中英文。合同：[读取协议](../../contracts/workspace-observation.md)；实现：`RemoteWorkspacePanel.tsx`、`remote-workspace-model.ts`、Go控制面及Runner同名模块。

## 用户目标与入口

用户在项目开发IDE切换“本地工作区／执行工作区”。本地工作区继续编辑现有项目文件；执行工作区只读查看当前运行中的原生工具尝试，适用于控制面没有本地文件绑定的部署。候选列表表示当前授权资格，不能显示成“已连接”或推断模型健康。

1. 打开IDE，选择“执行工作区”。
2. 从列表明确选择节点／运行／attempt。列表刷新保留仍有效的选择；没有目标时展示原因与刷新入口。
3. 选择目录、按页列出文件，选择文本文件。主面板展示路径、行号、只读代码和读取时间；完整文件摘要折叠显示。
4. 长文本按段读取，下一段携带原完整文件摘要；文件变化时要求从首段重读，不拼接不同版本。
5. “查看运行”进入对应run／node／attempt。源码快照不等同候选、测试、验收或发布证据。

## 状态与交互规则

| 状态 | 用户反馈与动作 |
|---|---|
| 加载目标／无目标 | 加载反馈或说明启动已批准原生任务后刷新；不自动派发任务 |
| 请求中／排队／读取 | 明确显示正在提交、等待执行节点或读取；同一面板同时只有一个读取 |
| 已完成 | Monaco只读、无保存动作；文件列表和正文各自到期清除，不被后续读取延长 |
| 断线或回执丢失 | “核对原读取请求”使用原操作标识或原请求ID；不自动创建新请求 |
| 目录／文件变化 | 提示重新列目录或从首段读取；不保留伪装成最新的旧正文 |
| 身份／项目／尝试变化 | 同步隐藏旧内容，中止旧请求并忽略迟到响应 |
| 执行结束／权限撤回／到期 | 后续授权核验停止披露，客户端清除可见内容；到期后需明确刷新 |

仅UI来源与目标标识保存在当前会话偏好中；源码、凭据和读取回执不进入浏览器持久缓存。读取到达控制面后有60秒总有效期，已完成面板每3秒用不含正文的元数据核验当前权限；这不是权限变化与浏览器像素同步清除的承诺。Runner私有重传journal的清理规则见运维文档。

## 国际化与可访问性

新增平台文案使用`remote-workspace`中英配对领域目录；错误使用服务端稳定消息键，不翻译用户代码、路径、工具名和机器状态。日期与数字遵循所选语言；新语言可按现有目录与语言注册机制扩展。

来源标签支持方向键／Home／End、正确焦点与tab／tabpanel关联；选择框、目录、分页和展开摘要均可键盘操作。窄屏自动改为上下排列，目录独立限高，代码区域保持可操作。沿用深浅主题、加载、空态和错误组件。Monaco内置菜单仍英文，平台显式说明该边界。

## 当前范围和后续验收

本阶段交付原生当前attempt的`list`／`read`及同控制API的CLI。未交付远程写入、Git写、PTY、LSP、DAP、持久草稿、离线文件同步或完整远程IDE。官方MCP SDK用于既有本机原生工作区，浏览器不会直接取得其端口或凭据。真实物理多机、TLS部署、OceanBase并发／容量、厂商工具与完整平台验收继续列入总计划。
