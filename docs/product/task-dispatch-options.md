## 用户目标与范围

用户已在任务中选择固定流程版本和接收上下文的开发 Agent 节点，需要从真实工具清单中找到当前兼容的配置，了解阻断原因，再明确准备预览与启动。

本阶段增加只读推荐与现有派发入口的连接，不替代正式派发、独立测试、人工验收、预算或执行授权。沿用既有控制面、工具库存、工作流构建器与执行路由；不安装额外工具，也不通过关键词、虚构评分或新模型调用猜测推荐。

## 操作流程

1. 在任务派发弹窗选择固定流程版本与开发节点。
2. 明确展开“查找兼容工具／Find compatible tools”，按需读取当前任务及版本对应的一页候选。
3. 查看本页工具、版本、执行节点及不兼容原因。当前推荐是本页按稳定 ID 排列的首个兼容项，未比较其他页。
4. 点击“采用当前推荐／Use current recommendation”，只填写既有工具选择；保留返回配置的准确 ID、版本及摘要，避免同 ID 的旧列表项替代它。
5. 用户明确准备原有执行预览，服务器重新授权并固定任务、需求／设计、基线、知识、工具、流程和路由依据。
6. 用户按原流程确认并单独启动。推荐读取与采用不会自动创建计划、运行、模型调用或资源预留。

仍可使用原有工具选择入口。推荐不要求用户新增配置，也不改变已有待恢复写入的请求内容。

## 业务规则

| 主题 | 必须表现 |
| --- | --- |
| 当前兼容 | 仅表明当前清单、授权、流程和路由兼容；不代表机器空闲、预算充足或可以立即执行 |
| 候选排序 | 稳定 ID 顺序；当前页首个 eligible 项作为推荐，不称全局最优或 AI 评分 |
| 模型 | 由管理员授权的准确工具配置固定；不能在同一配置摘要下私自更改模型参数 |
| 费用 | 当前无价格估算依据，显示未知；不能等同免费或“最便宜” |
| 分页 | 界面每页读取最多50项，显示当前页、页内数量和总配置数；总数不是兼容数、执行槽位或可用容量 |
| 版本 | 请求绑定项目、任务及版本、流程及版本、Agent 节点；返回外层和任务上下文、路由均须匹配后才展示 |
| 范围切换 | 输入依据变化立即隐藏旧推荐与旧选择；晚到读取不得覆盖新范围 |
| 权限变化 | 401／403 清除推荐事实；没有待恢复写入时清除当前采用选择，不从旧页面继续授权 |
| 正式门禁 | 预览、启动和后续领取沿用各自正式检查；额外知识、32 KiB 上下文限制、预算等不会由推荐读取代替 |
| 未知写入 | 已发出的请求按原调用者、path、body 和操作标识恢复；推荐不改写、重新生成或自动提交它 |

## 状态与验收条件

- 默认折叠且不发起推荐请求；只有已选实际 Agent 节点后出现入口。
- 展开显示加载；刷新从首页重新读取并清除旧观测；读取下一页替换本页，不混成全局排序。
- 空列表和本页无兼容项分别说明；失败可明确重读，不以空列表伪装服务异常。
- 响应作用域、版本、候选唯一性、页内推荐或分页结构错误时，拒绝展示候选。
- 待恢复写入期间推荐操作不可用，保持原请求；中英文切换仅改变呈现，不重复读取或提交。
- 操作采用按钮、表单与可展开区域，复用当前成熟组件、错误展示和设计令牌；窄屏保持同一操作顺序。
