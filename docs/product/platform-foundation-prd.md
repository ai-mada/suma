# 平台基础能力与专业体验需求

状态：目标需求，分阶段实现；日期：2026-10-24。负责人：产品／平台／UED。关联：[总PRD](prd.md)、[工程架构](../architecture/platform-engineering.md)、[设计规范](../design/workbench.md)、[实施台账](../delivery/implementation-plan.md)。编号用于设计、接口、代码和验收追踪，不表示全部已完成。

## 用户与目标

FND-I18N-001：所有实现支持多语言国际化，首次 `zh-CN` / `en-US`；界面、无障碍、校验、错误、诊断、配置、通知、CLI、桌面和接入说明纳入验收。语言偏好与业务时区分离，用户内容及不可变证据保留原文。见[国际化规范](../design/internationalization.md)，不能仅有切换按钮就视为完成。

组织管理员可视化配置身份、角色、执行资源和扩展；项目负责人可明确授予项目范围，审阅计划与执行依据；成员可在稳定项目上下文中高效完成需求、开发、测试和交付；执行节点、智能体及第三方入口能够复用相同业务合同。基础能力应支撑后续业务接入，避免新模块重建登录、权限、配置、审计与错误处理。

## 功能需求与明确验收

|---|---|---|
| FND-ID-001 | 管理员配置OIDC提供方，成员在浏览器完成SSO；身份使用issuer+subject，受控账号关联 | 正确issuer/audience/nonce/PKCE/state、过期／重放拒绝、撤权及IdP不可用恢复；至少一个真实企业IdP旅程 |
| FND-ID-002 | 用户／角色／权限可管理；组织身份、项目授权、资源目录与机器委派独立 | 自定义角色／资源动作、最后所有者保护、跨租户拒绝、当前撤权竞争、服务入口一致；界面不能靠隐藏按钮授权 |
| FND-EXEC-001 | 拥有方创建共享执行池，项目请求授权，拥有方批准，项目选择固定默认路由 | 双边版本与审批、独立机器身份、两项目实际并行、准确占用与当前阻塞；池拥有方不会获得项目业务读取权 |
| FND-EXEC-002 | 分层加权公平与项目内优先级／等待规则可配置、可解释 | 有持续积压的权重分配、重新活跃、资源不足、能力不匹配、最后额度竞争及崩溃恢复；不能将配置权重当作ETA |
| FND-EXT-001 | 注册版本化插件／技能，配置秘密引用、访问范围、探测与启停 | 配置Schema校验、超时／取消、权限隔离、版本固定、卸载／撤销后禁止新调用；真实执行证据独立于探测 |
| FND-MCP-001 | 管理MCP连接、能力与授权，在统一工作区使用工具／资源 | 官方SDK、当前协议版本、发现／调用／错误／取消、最小资源权限、秘密去敏、断线恢复和审计 |
| FND-A2A-001 | 发现智能体能力、提交任务、等待输入、查看产物及请求取消 | AgentCard与认证、远端任务映射、幂等重发、流／轮询回写、结果未知核对、撤权；远端成功不自动验收需求 |

## 关键旅程

1. 组织管理员进入设置，创建资源池并配置容量；登记执行节点，凭证首次显示后由受控本机配置使用。丢失响应恢复元数据，再通过明确轮换恢复秘密。
2. 项目负责人使用已知池标识发起授权，看到待批准状态；拥有方审阅具体组织、共享项目名、范围和版本。批准后项目预览并采用默认路由，既有运行保持原路由。
3. 多项目任务进入池；成员看到自己项目的实际节点与证据，拥有方看到共享聚合占用。暂停只停止新派发，取消与实际停止分别可追溯。
4. 后续SSO接入时管理员先测试提供方；成员登录后进入明确组织。没有项目权限时提供可理解的入口，不自动授予所有项目。
5. 后续插件／MCP／A2A接入时，先配置、探测与授权，再通过真实任务验证；失败保留输入，权限变化阻止新调用，未知外部效果进入核对。

## 交互完成标准

每个页面包含可操作的加载、空态、无权、失败、断线、冲突和未知回执恢复。关键动作可用键盘操作；弹层焦点返回原控件；窄屏有完整等价入口。刷新、分享与浏览器返回恢复项目、过滤、运行、节点和尝试，不把敏感字段放进URL或持久浏览器存储。

主要事实优先显示；高级配置可展开，使用中文名称与单位，保留必要原始诊断码用于排查。所有图表能回到授权范围内的正式对象；配置容量、实测负载、当前资格、历史执行、业务验收及发布状态分别表达。视觉完成需要实际浏览器四宽度、主题及键盘证据，组件快照与编译不能替代这些检查。

## 交付规则

每个编号需要关联PRD、领域与流程设计、请求／响应合同、实现入口、测试和实际验收摘要。源码完成、模拟通过、真实集成、正式生产验收分开记录。第三方账号、IdP、商户、签名证书及规模环境缺失时标明依赖，同时继续完成不依赖外部账户的必要工作。
