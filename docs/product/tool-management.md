# 工具管理：快速接入与维护 PRD

状态：限定实现与验证完成；suma1.0.0；T-TOOL-MANAGEMENT-193。负责人：主集成代理；关联[合同](../../contracts/tool-management.md)、[架构与AI SOP](../architecture/tool-management.md)、[交互](../design/tool-management.md)与[验证](../quality/tool-management-verification.md)。原31项需求、P0–P7完整目标保持active。

本阶段面向管理多个开发工具及执行节点的项目管理员、开发者和只读成员，解决入口分散、重复填写、状态难以判断，以及停用或移除后不清楚影响范围的问题。目标是用一个协调入口完成连接，并让每个维护动作具有明确含义。

## 用户旅程与验收条件

| 场景 | 操作与可观察结果 |
| --- | --- |
| 首次连接 | 由“连接工具”进入Quick流程；高级配置按需展开，保留当前项目、方向和准确目标 |
| 自动读取与扫描 | 区分本机原生扫描、已授权节点状态读取和已有上报；浏览器读取不能显示为本机扫描或安装成功 |
| 补齐配置 | Advanced接续公开草稿；不要求重复建立身份，不保存凭据值、私有路径、argv或过期库存作为已检测事实 |
| 避免重复登记 | 先查原精确matches；已有接入可直接查看，新的执行配置仍按原库存暂停登记，再单独启用 |
| 查看当前接入 | 默认active，只含enabled与paused；按需查看revoked或all，状态不等于在线或模型健康 |
| 搜索与翻页 | 对名称、命令ID、worker ID、adapter、protocol执行字面包含检索；改变筛选或范围清空旧分页，迟到结果不混入新范围 |
| 诊断下一步 | Doctor保留授权、worker、库存、profile四个前提，给出准确目标的一项下一步，不跳转空白表单 |
| 调整与停用 | 不原位改历史配置摘要；沿本机新配置及真实上报复用或登记新档案。停用使用原pause |
| 移除接入 | 使用原永久revoke，从当前列表撤下，保留运行和证据；不提供物理DELETE或虚构配置PATCH |
| 判断影响 | 展示当前项目活动运行中已观察的准确引用与覆盖范围；撤销不代表外部进程已停止 |

只读成员可查看当前权限允许的列表、详情和诊断；创建、启用、停用与撤销仍由原服务端角色、CAS和稳定操作ID控制。协调入口或公开草稿不能授予额外权限。

## 数据与状态约束

原列表GET新增state与query筛选，默认每页50、最多200；检索输入最多120 UTF8字节。游标绑定当前actor、组织、项目及规范化state/query，不能跨范围复用。检索只查公开字段，不对原始配置JSON、凭据或私有路径做搜索。

影响说明只覆盖当前项目running、paused、cancelling运行，最多检查200个运行及2000个节点，按原ToolBinding精确匹配profile ID和SHA。最多展示5项引用；pending、ready、running、waiting、reconciling节点可列出，未领取节点的attempt/fence可为0，worker可为空。

complete只表示上述范围内完整；超限为partial，来源无法解析为unknown。observed计数是已观察事实，未覆盖部分不能推断为0。草稿、未启动计划、历史运行和未知外部进程均不在该覆盖范围内。

## 失败与交付边界

复制、读取、扫描或修复失败保留草稿；未知副作用先核对原操作，不能换新操作ID盲重。刷新读取不等于原生重扫，配置可解析不等于可派发，重扫也不等于安装或修复成功。

本阶段复用原创建、matches、详情、diagnostics和命令接口，新增API路径与业务表均为0。实现、定向检查、真实HTTP、代表性中英文界面及生产验收分别记录；本文不宣称完整平台或全部工具已完成验收。
