# Claude SDK 原生开发协作 PRD

状态：限定实现与验证通过；版本：suma1.0.0；阶段：T-CLAUDE-SDK-192。负责人：主集成代理；关联[合同](../../contracts/claude-sdk.md)、[架构与AI SOP](../architecture/claude-sdk.md)、[交互](../design/claude-sdk.md)和[验证](../quality/claude-sdk-verification.md)。原31／P0–P7目标继续。

目标用户是统一管理本地或远程开发工具的团队管理员、开发者及验收人。既有Claude CLI已能正式派发；本阶段解决SDK执行中遇到工具许可或结构化问题时，无法沿平台继续原任务的问题。配置、授权、执行、代码、测试与验收分别表达，不能用一条“已连接”替代全部状态。

| 用户操作 | 可观察验收结果 |
| --- | --- |
| 选择SDK入口 | 与前台CLI、反向MCP客户端区分；原项目和账号范围不变 |
| 生成本机配置 | 填Node、SDK宿主、原生CLI、准确模型、环境变量名及全新文件；固定版本清晰展示，不填hash、argv或密钥值 |
| 登记节点 | 运行原describe／report，按fresh库存暂停登记，再明确启用；准备文件不显示模型健康 |
| 派发原任务 | 预览固定SDK配置，原权限、预算模式、依赖、工作区和最大重试0在Start／Claim重验 |
| 确认一次许可 | 完整查看原工具参数，明确仅此一次允许或拒绝；绑定原native request，不产生永久规则 |
| 回答原问题 | 无预选单／多选、完整原文字、明确取消；答案不授权其他命令 |
| 断线再打开 | 恢复原请求与原操作事实；未知写入先核对，不用新操作重答旧问题 |
| 完成开发 | SDK完整result、回调闭合和停止是执行事实；正式候选、独立测试和人工验收仍独立 |

默认只使用固定已审SDK与CLI、显式API key环境引用、准确完整模型名及observe_only用量模式。组织或项目硬预算策略不适用于本入口，必须在派发前明确拒绝。SDK估算不等于厂商账单。

本阶段固定原生问题子集：1–4题、每题2–4选项，支持单选／多选及取消。空answers对象可保留，非空预填、预览扩展、自由文本和新原生扩展不静默降级。工具权限只对准确SDK回调生效，既有本机管理员策略与系统执行边界分别记录。

错误场景覆盖来源／模型变更、撤权、暂停、过期租约、未知写、重复请求、SDK错误、取消和进程树无法证明停止。原草稿及证据保留，拒绝／取消不能被Worker虚报成功绕过。中英文、键盘与390px操作共用同一数据和状态。

真实供应方账号／模型、完整安装、多机、其他OS约束及生产验收仍在原完整计划中；受控本地SDK旅程不作为其替代。

源码部署时先安装锁定工作区依赖，再运行 `pnpm --filter @suma/claude-runtime build`，宿主及完整资产清单位于 `packages/claude-runtime/dist/runtime/`。在工具高级入口选择该目录中的 `suma-claude.bundle.mjs`、本机Node及明确的原生CLI2.1.314；生成新配置后沿原执行节点流程连接。构建宿主不安装原生CLI或登录账户；当前安装包的SDK专用资源集成继续单独交付。
