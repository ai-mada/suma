# 配对收件箱与执行接续

状态：1.0.0 当前实现；负责人：控制面／Runner／Web；需求：T-RUNNER-INBOX-185。合同：[runner-inbox](../../contracts/runner-inbox.md)；证据：[限定验证](../quality/runner-inbox-verification.md)。原31项与P0–P7完整目标继续。

项目管理员能在原工具登记窗口查找既有配对，不必为另一位管理员或刷新后的浏览器重新登记。默认显示有效待办，可按状态和机器名称／ID搜索，按页继续。列表为实时数据，过期由数据库时间判断；总数覆盖完整筛选。

主要旅程：打开项目工具管理 → 远程配对 → 创建或选取既有记录 → 目标终端执行 → 核对完整指纹并明确批准 → 返回准确节点 → 分别准备工具、上报工具、启动执行。每一步均可查看原范围与结果；批准不等于机器在线，上报不等于配置启用，启动草稿不等于已经执行。

常用命令通过 `--paired-runner ID` 复用该机器默认位置的现有公开身份记录和系统凭据，减少路径输入。自定义身份文件仍由高级路径入口准确指定。浏览器不接触 token，不替用户执行终端命令。

验收：当前管理员方可查询；筛选／分页无跨项目或跨用户游标复用；选取记录重新读取详情；未知写入与持久化失败时禁止切换；审批仍需原版本与人工核对；地址变化时只能关闭待办，不能批准；错误身份在读取凭据、网络、日志目录变更前拒绝。中英文具有相同功能。

本阶段不替代物理多机、厂商登录／模型调用、部署、规模及跨平台安装验收。
