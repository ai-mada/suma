# 开发工作空间：Git审阅与可靠保存

状态：T-P4-035／1.0.0，限定本地功能及主预览已验证；全平台继续实施。负责人：工作台／控制面／执行节点。关联需求：14、15、21、22；[合同](../../contracts/workspace-git.md)、[模型选择后续设计](../architecture/035-model-selection-design.md)。完整平台范围保持不变。

## 用户旅程

开发人员在项目工作空间编辑真实文件，通过左侧“文件／变更”切换审阅磁盘Git状态，不离开当前项目。变更中区分暂存区与工作树；点击文件在成熟Monaco DiffEditor中查看真实原文与修改后内容。返回文件区时编辑模型及未保存草稿仍在，Ctrl/Cmd+S通过Monaco原生动作保存。Git视图明确说明未保存草稿不包含在磁盘观察中。

“暂存区”比较HEAD与index；“工作树”比较index与磁盘。新增、删除、重命名、未跟踪文件及同路径暂存删除后重建均保留真实来源。二进制只展示不能文本预览；冲突不伪装成普通双栏差异，用户可返回原编辑器处理。已删除且未重建文件禁用“在编辑器打开”，仍可查看准确删除差异。

## 交互与验收条目

| 场景 | 必须观察到的结果 |
| --- | --- |
| 编辑后切换变更再返回 | 原编辑器模型与草稿保留；未提交新的保存请求 |
| 一个文件同时有暂存与未暂存变更 | 两个来源按钮分别显示准确两侧内容与摘要，不能用HEAD代替index |
| 暂存删除后同路径重建 | 唯一文件记录保留D／?事实；暂存区为原文件→空，工作树为空→新文件 |
| 源码读取或Git基础变化 | 旧差异隐藏，409明确要求刷新；不自动写入或套用新基础 |
| 权限／身份／项目变化 | 立即移除旧代码及路径，取消读取；迟到响应不能覆盖当前选择 |
| 快捷键保存 | 使用最新草稿及原保存恢复语义；忙、冲突、无文件、无修改不新写，同轮多次按键不重复派发 |
| 刷新、空列表与大列表 | 保留仍有效选择及位置；真实清洁空态，200项上限和受限项总数明确展示 |
| 中英文、键盘及窄屏 | 平台文案配对；左侧tab可用方向键切换；窄屏DiffEditor采用成熟内联视图 |

Git入口仅提供当前授权的读取，不提供任意shell或Git子命令。本阶段不暂存、提交、切分支或合并；正式候选与独立测试仍使用已有执行及验收合同。这些动作后续须基于准确代码依据与操作回执独立实现，不能将只读能力描述为完整版本管理已验收。

## 执行资源准确性

原生开发节点的流程步数与输出额度必须真实到达SDK，不能在重建工作区输入时丢失后退回更大默认值。明确错误在工作区、MCP和主进程之前拒绝；已经验证的修复协议才能使用修复步数及单次额度。该修正解决资源控制链路，不意味着当前可写模型已具备独立选择或计价。
