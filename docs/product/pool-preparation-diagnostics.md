# 本机配置诊断与修复指引

版本1.0.0；阶段T211限定实现与验证通过。负责人：Runtime／工作台。关联：[合同](../../contracts/pool-preparation-diagnostics.md)、[原配置准备](pool-config-preparation.md)、[验证](../quality/pool-preparation-diagnostics-verification.md)。完整31项／P0–P7继续。

## 用户旅程

多项目配置复制命令后，目标机器能明确告诉用户哪个项目行、哪个字段有问题。例如第二项目的命令文件不是有效JSON时，返回“项目范围2／命令配置文件”的安全原因与处理建议；不再只让用户逐个猜文件。CLI继续根据当前语言输出说明。

准备失败后展开一个帮助区，粘贴单条诊断并点击定位。只有报告与当前输入和输出目标匹配，界面才展开准确项目的高级选项、聚焦字段并显示当前界面语言的建议。改项目、路径或节点后旧报告立即失效；其他项目行保留。报告不能导入新配置值或执行修复脚本。

## 必须满足的边界

- 原六字段成功回执、配置格式、私有输入、根目录锚定、新文件拒覆盖和权限保持。
- 不在错误中泄露本机路径、允许命令、模型参数、环境或秘密；机器错误链也不透传。
- 无法读到完整输入时仅关联输出目标，明确限定范围；未确认写入引导检查原文件，不自动改名、覆盖或重试。
- 报告是历史事实与静态建议，不证明当前文件已修复、节点在线、工具可派发或任务验收。

## 验收

一次真实CLI失败报告与生产表单联调，核对第2项目准确字段，明确修正本机夹具后用原命令生成配置；中英文、异步来源变化和报告闭形拒绝有定向证据。实际工具、模型、分布式运行和完整平台另按原计划验收。
