# 本机工具发现体验 PRD

阶段：T-TOOL-DISCOVERY-202；产品：速码 suma 1.0.0。负责人：主集成代理；文档：并行文档代理。状态：阶段实现与限定验证完成，见[验证报告](../quality/local-tools-discovery-experience-verification.md)。关联[交互合同](../../contracts/local-tools-discovery-experience.md)、[架构](../architecture/local-tools-discovery-experience.md)、[交互设计](../design/local-tools-discovery-experience.md)、[English](../en/local-tools-discovery-experience.md)。

## 问题与结果

原本机扫描同时展示九个适配入口，未安装项占用首屏，用户难以识别本机已发现什么、哪些事项需要处理、下一步在哪里完成。目标是在原“连接工具”流程内减少浏览负担，保留每个适配协议和已有能力，不新增工具中心。

主要用户是首次连接开发工具的桌面用户，以及检查本机安装变化的项目成员。成功表现为已发现、异常和当前选择先出现；其他未安装工具仍可展开查看。安装数量不解释为在线节点、模型认证或可派发任务数量。

## 范围与确定规则

| 输入事实 | 展示位置与行为 |
| --- | --- |
| `installed=true` | 主列表，保留准确协议、版本、原因和原操作 |
| `installed=false` 且原因不是 `not_installed` | 主列表，保留异常解释；不能把失败隐藏为未安装 |
| 未安装且当前选中 | 主列表，选择依据持续可见 |
| 未安装、原因恰为 `not_installed`、未选中 | “其他工具”原生折叠区，默认收起 |
| 主列表为空 | 简短说明；调用者提供原节点接入动作时展示该入口 |
| 无合法唯一适配描述符 | 保留扫描事实，不猜测配置或连接动作 |

两组保持原扫描顺序和对象，不去重、不合并同产品的 CLI 与 SDK。已发现数量只统计 `installed=true`；待处理数量只统计 `installed=false && reason_code!==not_installed`，不因选中未安装项而增加异常数量。

## 用户流程与边界

1. 进入原连接工具页面，沿原身份、项目和桌面扫描流程读取安装观察。
2. 先查看主列表及真实数量；按需展开其他工具或单项检测依据。
3. 选择准确适配入口，继续原快捷配置、安装指南或已有连接查看；选择本身不连接、不配置、不安装。
4. 需要更新本机观察时，明确使用原重新检查动作；展开、选择不增加探测或 HTTP。
5. 后续连接、等待新鲜库存、暂停登记和独立明确启用继续原流程，不能跳过原确认与当前权限。

保留原加载、忙碌、缓存、过期、失败、无桌面桥接和身份不可用状态。过期观察不能显示为当前已验证安装；扫描失败不能替换为零安装。身份、组织、项目或调用者代次变化后重置折叠状态，旧响应不得接管新界面。选中项跨组后仅保留该明确操作原有焦点，外部选择不得抢焦点。

Claude SDK 的不支持版本使用既有准确提示。原生 CLI 安装、SDK 资源、凭据和模型认证、节点连接、正式登记、启用、执行、测试与人工验收分别表达，不能相互代替。

## 验收标准

以下要求已由本阶段定向检查和代表组件界面覆盖；验证范围及原失败记录见报告。

| 场景 | 可观察结果 | 状态 |
| --- | --- | --- |
| 九项均未安装且无选择 | 主列表为空，其他九项默认折叠，可键盘展开 | 限定通过，见验证报告 |
| 已发现、异常和已选未安装混合 | 主列表完整保留这些项，原顺序与协议不变 | 限定通过，见验证报告 |
| 展开、选择、查看已有配置 | 不额外扫描；动作继续使用原准确适配对象 | 限定通过，见验证报告 |
| 切换作用域或迟到结果 | 不复活旧结果，折叠状态重置，原权限不变 | 限定通过，见验证报告 |
| 中文/英文、390/1366 布局 | 文案完整、焦点可见、至少44px触达、无横向溢出 | 限定通过，见验证报告 |
