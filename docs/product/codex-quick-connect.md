# Codex原生快速连接需求

T-CODEX-QUICK-CONNECT-175；suma 1.0.0；2026-10-31。负责人：工具接入、桌面、Runner及工作台。关联[合同](../../contracts/codex-quick-connect.md)、[架构与SOP](../architecture/codex-quick-connect.md)、[交互](../design/codex-quick-connect.md)和[验证](../quality/codex-quick-connect-verification.md)。

现有原生执行已支持模型目录、技能和一次工具确认，但快捷入口只能连接Codex JSONL模式，用户还需手写执行配置。本片把这些既有能力接到同一快速连接流程；工具安装、配置核实、执行节点连接、平台注册及启用分别展示。

| 用户需求 | 实现及验收依据 |
| --- | --- |
| 自动识别本机原生Codex | 固定PATH／包入口解析、真实原生字节和版本；不执行shim、不发送开发目标 |
| 少填配置 | 同一卡片填写提供方、Responses地址、可选环境凭据引用及必要Windows实现，免手写commands文件 |
| 真实能力 | 明确读取model/list，展示实际目录；正式任务继续用原模型／推理档位选择器 |
| 可靠连接 | 当前身份、项目与工作区重核；仅启动后的准确新库存可显示connected |
| 可调整配置 | 节点明确停止后才可提交新配置；未结操作和普通重连保持原配置及原登记标识 |
| 易懂诊断 | 缺运行环境、未完成配置、安装格式不支持和原操作未知分别给下一步 |
| 可控使用 | 新配置先暂停登记，再明确启用；不自动安装、不借用户登录、不悄悄降级隔离 |

当前平台版本仍为1.0.0，无旧wire回退或升级兼容。JSONL是另一独立执行协议。连接不证明供应方授权、实际模型成功、价格或硬预算；原生工具的observe-only限制和正式质量门禁继续执行。完整多工具、分布式和31／P0–P7目标继续交付。
