# Claude SDK 快捷连接 PRD

状态：T-CLAUDE-SDK-CONNECT-201限定实现与验证完成；[验证报告](../quality/claude-sdk-quick-connect-verification.md)；suma 1.0.0；负责人：平台集成。关联[合同](../../contracts/claude-sdk-quick-connect.md)、[架构与AI SOP](../architecture/claude-sdk-quick-connect.md)、[交互](../design/claude-sdk-quick-connect.md)。完整31项／P0–P7继续。

现有Claude SDK可执行正式开发，但桌面用户仍需手工定位Node、SDK宿主和CLI、生成文件再登记。本功能将这些宿主配置工作移入既有可信桌面接入流程，用户只选择原生安装、填写固定模型及凭据环境变量名称。平台继续区分原生已安装、资源已核、节点连接、库存、登记、启用、模型认证和业务质量。

| 需求 | 可观察的结果 |
| --- | --- |
| R201-1 被动发现 | 单项及批量扫描包含第九项SDK用途，返回原生CLI版本与摘要，不执行模型或猜测SDK资产就绪 |
| R201-2 简单配置 | 仅固定模型／环境名称等公开输入，主进程决定所有路径和受信资源；不输入或返回密钥值 |
| R201-3 准确连接 | 重新核对用户选择的CLI摘要、版本、Node及完整SDK资产，漂移或缺资源在发行新身份前拒绝 |
| R201-4 原生命周期 | 复用原私有工作区、HMAC身份、加密Journal、续权、停止、未知回执与机器当前资格 |
| R201-5 固定依据 | 连接回执明确区分原生CLI摘要和Node摘要；完整配置摘要沿原Go算法和现有执行能力 |
| R201-6 不误用状态 | 只有明确新connect的成功回执能关联当前setup；status不能猜出新的环境引用，草稿／scope变化使旧证明失效 |
| R201-7 正式登记 | 本次启动后的fresh完整库存逐项匹配准确worker、Node、runtime与能力才登记paused；启用独立确认 |
| R201-8 可部署 | 正式资源准备与打包包括Node许可证及完整独立host资产；原生CLI由已有安装提供 |
| R201-9 双语与恢复 | 中文／英文和窄屏可操作，缺资源、版本不支持、未知、原恢复和手工高级入口均有准确反馈 |

固定模型是管理员选择的配置，不等于供应方已确认可用；observe_only不承诺硬预算。SDK模型交互、权限问答、候选和同提交独立测试仍沿[T192](claude-sdk.md)，本轮不重复执行。真实厂商账号／费用、其他OS运行／安装、物理多机、规模及生产仍需独立证据。
