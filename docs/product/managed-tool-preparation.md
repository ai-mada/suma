# 远程工具快速准备与接入

速码1.0.0 · T-MANAGED-TOOL-PREPARATION-224 · 负责人：平台能力组 · 状态与证据见[验证报告](../quality/managed-tool-preparation-verification.md)。关联[合同](../../contracts/managed-tool-preparation.md)、[架构与AI SOP](../architecture/managed-tool-preparation.md)、[交互](../design/managed-tool-preparation.md)及[English guide](../en/managed-tool-preparation.md)。

工具管理沿原接入入口完成一条简单路径：准确机器扫描 → 填写固定模型和凭据环境变量名称 → 明确允许本次配置写入 → 等待执行节点接纳和库存确认 → 保存暂停配置 → 独立启用。用户无需手工编辑机器路径或JSON，也不会因检测成功就自动获得任务执行权限。

## 当前范围

自动准备只覆盖实际能力中声明的 Qoder ACP 与 Cursor CLI；沿用原成熟ACP准备器，其他七项手工目录与现有SDK入口保留。机器须独立开启 `--allow-tool-preparation` 并允许已安装工具检测，默认关闭；普通节点和共享资源池指南均可明确选择该权限。维护模式仍不领取业务任务。

配置表单只收模型和凭据环境变量名称，不收密钥值、程序路径、脚本、命令参数或下载地址。Qoder允许空凭据引用，Cursor保持原要求。扫描绑定准确安装文件、版本和完整摘要；来源变化提示重新扫描。不会安装或下载工具。

## 操作与验收

1. 在原扫描结果的工具行展开配置，填写模型和凭据引用，勾选本次机器写入确认；仅满足当前权限和真实节点能力才可提交。
2. 准备、节点接纳、库存确认分别展示。等待库存时不能跳过到登记；失联或未知效果保留原操作，先核对，不能换一个操作重复写入。
3. 完成后重新核对同项目、同节点、同命令及完整配置摘要，再回原快速接入。相同命令换模型或摘要也要求明确重选。
4. 维护节点不可执行时，准确已接纳的配置仍可保存为暂停，保留真实不可执行原因。启用、任务派发和模型实际运行继续各自原门禁。

验收条件：权限与机器opt-in不能互相代替；两个已提交回执丢失后恢复同一正文和操作；旧worker/旧来源不能完成新配置；原关联库存与completed同事务；未确认期间不能派发该scope；中英文支持相同动作与错误。完整厂商登录、模型、分布式Pool实机与其他七种自动准备仍为后续验收，不将准备完成当作全平台完成。
