# 智能体回复开发与AI SOP

状态：1.0.0，T-REPLY-128；关联[合同](../../contracts/task-conversation-replies.md)、[架构](../architecture/task-conversation-replies.md)、[实际验证](../quality/task-conversation-replies-verification.md)。

1. 先保存人类提问，再检查准确任务、当前消息头和要回复的序号。正在编辑或回执未知的消息不能被默认为已进入模型上下文。
2. 选择实际可用的专用只读工具档案及模型部署。检查上下文窗口、单步／输出限制、Token／费用上限和费率依据；未配置价格不显示虚构估算。明确授权才创建。
3. 上下文范围为显式近期1–20条；超限时减少范围或调整任务内容，不能静默删减。来源哈希与覆盖范围随运行保存，不修改进行中的定义。
4. 领取与心跳走当前注册节点和原DAG资源；SDK只获得本机临时网关连接，不获得提供方密钥。使用原模型／预算合同，禁止环境回退或另一套派发器。
5. 只从精确回执发表助手消息。首次结果回执丢失时恢复原操作，不重新调用模型；结果未知、停止请求、实际停止、消息发表和业务验收分别处理。
6. 后续提问创建新轮次；助手原文只是建议，文件／命令／测试／发布通过各自正式计划与权限执行，不把回复正文作为可执行命令。
7. 变更后仅验证受影响的当前权限、固定预算、只读合同、消息去重和界面所有者／草稿保护。SDK只构建一次到进程指定的绝对忽略目录，避免覆盖活动Runner所用的安装包。
8. 实际旅程分别记录受控本地提供方协议、真实OS／SDK／HTTP、外部供应商、物理多机及生产范围。保留失败现场及哈希，精简摘要随代码提交，缓存／凭据／数据库／原始日志／截图不进入Git。

构建时可使用进程局部`SUMA_NATIVE_RUNTIME_OUT_DIR`输出原生bundle和manifest；值必须为绝对路径。未覆盖时标准包输出仍为`packages/agent-runtime/dist`。测试编译使用独立目录，依赖只连接到已安装的固定包；清理链接时只解除任务链接，不遍历目标。

新增用途需同时检查私有和Pool领取／心跳／结果、只读完成核对、当前模型选项、账务及专属命令入口，不能只增加SDK枚举。错误和显示键从Go权威目录生成，用户消息与原模型输出保留原值。
