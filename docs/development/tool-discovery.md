# 执行工具自动检测与接入

进入「工具管理 → 执行工具」，先登记执行节点，并在节点本机使用本次凭据启动已配置的 Runner。登记配置时选择节点，页面会自动读取它最近上报的工具；唯一可用工具会自动选中并建议名称，可自行修改。无需复制清单，也不会自动安装或启用工具。

核对后保存为暂停配置，再通过「核对并启用」确认权限。启用和实际可派发分别判断；平台在派发时继续检查节点凭据、路由、配置摘要与最新观察。已安装或已配置模型不代表登录、调用或验收成功。

- 尚未上报：确认 Runner 已启动、连接本项目且使用当前节点凭据，然后重新检测。
- 上报过期：检查节点连接与凭据，恢复上报后重新检测；不会采用历史工具清单。
- 已上报但没有工具：检查节点本机的命令配置和安装。
- 有工具但不可用：查看每项实际原因，在节点处理后重新检测。
- 读取失败或授权无法确认：重试读取或刷新节点列表；没有确认当前权限时不能登记。

远端或离线接入可展开「手动粘贴或导入 JSON 清单」。在节点本机运行 `suma-runner --describe-tools`，已有命令配置应使用同一 `--commands` 文件和已批准的执行策略；将完整输出粘贴或保存为 JSON 导入。页面仅本地读取文件，清单不含工具路径、参数、环境变量或第三方登录文件。最多128项、256KiB；超限需缩小本机工具清单，不能截断为成功。

人工清单和改名不会被后到检测覆盖；需要恢复检测内容时点击「使用检测结果替换当前清单」。更换节点会清除先前自动填入的配置。检测结果会在原上报60秒期限后失效，重新检测只读取真实上报，不远程执行命令。
