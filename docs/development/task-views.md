# 任务工作台与个人视图

在项目内打开「开发协作→任务」。搜索覆盖当前有权访问项目的全部任务标题、描述与编号；业务状态、负责人和优先级可组合。排序可选最近更新、最近创建、标题升序或优先级。列表与看板使用同一查询，切换不会扩大筛选范围。

手机上从「筛选与视图」展开条件和保存列表，收起后优先阅读任务；按钮显示当前筛选数量。选择任务后才出现团队批量安排入口。新建／编辑中的前置任务独立读取完整项目候选，可继续加载，不受主列表当前筛选影响。

看板和列表可按业务状态、负责人或优先级分组。每组“已载入”只计算当前加载的记录；页脚同时显示全项目匹配数。点击加载更多继续当前条件。多人同时编辑可能改变后续页的内容和顺序，刷新重新读取；界面不把多页称为固定导出快照。

选择「保存视图」，输入名称；后续可从「已保存视图」恢复，也可明确覆盖或另存。名称和条件只保存在这个浏览器，按账户、组织和项目分开，不同步到其他设备。删除前会确认名称。另一标签页修改保存列表时，当前筛选保留，需明确载入最新列表；损坏内容经确认才能重置。

点击任务标题进入原对象详情，继续编辑、讨论、查看依据或团队安排。浏览器返回保留原条件。任务选择只为后续团队计划提供输入，改负责人和切换视图都不启动Agent，也不能产生测试通过或人工验收。

读取失败使用原错误旁重试；失去权限后受保护内容清除。成员目录按需分页，未加载的负责人显示原标识，不错误改成未指派。键盘可以进入每个筛选、视图按钮和任务标题，保存弹窗使用原焦点与关闭机制。

给AI／CLI：使用 [GET任务工作台合同](../../contracts/task-workspace.md)读取当前项目，不用已加载100条做全项目结论。所有修改继续使用原任务命令及版本／操作ID。正式接入范围、源码采用和后续共享视图见[复用说明](../integrations/multica-reuse.md)；[English](../en/task-views.md)。
