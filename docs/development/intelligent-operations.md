# 统一智能输入与草稿计划

适用：T-INTENT-114，速码1.0.0。当前将一次自然语言输入转成可编辑的需求、设计及项目知识草稿计划。完整需求26仍进行中；实际验证范围见[阶段报告](../quality/intelligent-operations-verification.md)，接口与安全边界见[合同](../../contracts/intelligent-operations.md)。[English](../en/intelligent-operations.md)。

## 从目标生成计划

在当前项目的智能输入入口描述要形成的草稿，例如：“为工单处理增加分类与验收标准，形成产品、体验、技术设计，并整理项目规范草稿。”只填写目标和必要事实，不粘贴密码、Token、私钥或带凭证的地址。

可选0–8个当前项目的文档、需求、任务或问题作为依据。需要修改现有需求的设计时，明确选择该需求；未选来源不会由模型自行检索。来源版本与实际引用由服务端固定，资料超出上下文预算时减少范围或选择片段，不会静默截断验收条件。

选择真实可用的专用只读智能操作工具，查看固定模型与地址，设置输出预算，并明确确认把本次目标／选定资料交给模型。当前一次分析只调用一次模型；工具探测或已启用状态不表示模型账户健康。没有合适工具时先沿工具设置完成接入。

提交后保留分析和运行入口。页面显示真实running／failed／reconciling等状态；模型成功返回不代表计划合法或已创建任何草稿。刷新读取同一分析，勿重复提交来探测上次是否成功。

## 审阅、补充与预览

计划最多8步，只能创建需求草稿、保存需求设计草稿、创建memory／spec／skill项目知识草稿。设计可引用本计划前序新需求，也可引用明确选中的现有需求。设计任务仍是提案，不会自动成为正式任务。

核对摘要、理由、依赖、正文、验收条件及知识来源；原模型内容和手工修订分开保留。如果计划列出待补充问题，先补足事实并明确修订提案，问题未解决时不能采用。主机标签支持中英文，目标、资料和模型原文不随语言切换重写。

保存修订后生成预览，逐项查看实际目标、现有版本、将写入的草稿、所需权限和默认值来源。预览不写业务数据。修改提案、来源或作用域后旧预览与确认失效，需要重新核对；来源已变化时保留原件供阅读，采用被阻止。

## 明确采用本批草稿

确认预览后选择采用。确认只覆盖本次显示的草稿批次，不会启用长期自动批准。服务端在同一数据库事务内重核权限、来源和版本：全部步骤成功才写入；任一步失败全部回滚。

成功后从真实结果进入需求、设计或知识草稿继续审阅。结果保留当时的对象ID、版本、修订和来源；后续编辑不改写这次采用记录。需求发布、设计发布、任务提案正式采用、开发启动、知识发布及人工验收仍是各自独立操作。

## 冲突、断线与取消

| 现象 | 处理 |
| --- | --- |
| 生成失败或模型输出非法 | 查看真实运行和诊断；保留原件，不自动重调模型 |
| 来源或目标版本变化 | 保留编辑内容，读取当前依据，明确修订后重新预览 |
| 采用请求超时／结果未知 | 保留原账户、项目、请求正文、版本和操作标识，恢复原操作；成功恢复使用同一批对象ID |
| 权限撤销／会话过期 | 恢复当前合法身份；旧成功回执也需要当前权限，不能换标识绕过 |
| 运行中需要取消 | 进入实际运行的现有取消流程；不要用关闭提案冒充进程已停止 |
| 采用后对象又被编辑 | 采用结果仍是历史事实，下一次编辑读取当前版本，不沿用旧保存版本 |

当前支持同库草稿的原子采用，不执行代码、外部命令、配置修改、删除、外发或部署。通用自动配置、多端完整智能旅程与持久自动采用策略仍按[完整实施计划](../delivery/implementation-plan.md)继续交付。
