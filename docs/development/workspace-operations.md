# 查看工作区操作

状态：当前1.0.0工作台；负责人：执行／工作台。关联需求13、23。依据：[合同](../../contracts/workspace-operations.md)、[验证](../quality/workspace-operations-verification.md)。[English](../en/workspace-operations.md)。

1. 在“开发 → 运行”打开确切节点和尝试记录。
2. 展开工具事实内的“工作区操作”。默认只显示简短摘要，展开后查看真实读取、修改、检查、合并和封存调用。
3. 使用失败或结果未知筛选定位异常，展开一条记录核对策略、请求摘要、世代和时间。工作区序号与平台接收序号各有含义，网络重传可能改变接收顺序。
4. 若检查详情仍与这次调用完全匹配，可打开原检查结果。详情不可用时，不以另一轮同名检查代替。
5. 需要更早记录时进入现有“尝试历史”，按确切attempt逐页读取。当前窗口、分页水位及本地采集范围分别显示。

“检查已结束”需要结合退出码、停止标志和结果未知判断；修改或封存不等于独立测试与人工验收。显示“重用了原操作回执”表示没有再次执行该效果。结果未知时按原工作区核对流程处理，不能仅通过刷新重复执行。

不存在操作覆盖信息表示当前执行未提供，不表示零次操作。断网或撤权可能使本地记录尚未确认，平台已载入的页也不代表所有本地记录。切换项目、节点或尝试后只展示其自身范围。
