# 离线同步与冲突合同

状态：完整产品目标，尚未实现自动跨设备同步。当前本机数据库持久化不等于离线同步完成。

## 同步单元

所有已授权项目自动同步业务操作、协作文档更新和制品manifest。数据库文件与Lance目录不直接复制。每个设备保存稳定身份、收发游标、操作ID和已确认摘要；删除通过墓碑传递。

## 合并

协作文档采用Yjs更新；互不冲突业务字段可合并，同字段/语义冲突保留双方版本并请求明确选择。代码草稿与正式磁盘保存分开，保存使用文件摘要前置条件；Agent代码通过隔离工作树进入审查合并。

## 授权

同步密钥与模型/商户凭证分离，秘密不随业务项目复制。团队派发、正式审批和生产操作在线核实。服务端撤权立即限制在线请求，离线设备重连后接收撤权；本地副本的边界需在设备策略中明确。

## 恢复与清理

重复/乱序操作幂等处理。墓碑仅在活动设备全部确认或设备进入强制全量重同步后压缩。旧游标设备不得重新上传已删除内容。离线编辑期间的权限变化、设备丢失和密钥轮换必须独立测试。
