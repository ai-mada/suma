# 多模态数据与知识检索

状态：分层设计；实现与验证参照 packages/knowledge 和交付状态。

## 存储合同

正式业务与来源版本在事务库；完整原件位于本地/对象存储；知识索引保存可重建派生信息。每条结果包含 tenant、project、source_id、revision、chunk、模型配置、定位信息及原件摘要。

| 内容 | 原件 | 派生与定位 |
|---|---|---|
| 代码 | 仓库/工作树/提交和文件摘要 | 符号、代码行、分块、语言、分支 |
| 文档/办公 | 原文件与不可变修订 | 页码、段落、表格/幻灯片定位 |
| 图片/PDF | 原图/扫描件 | OCR、区域、缩略图、视觉向量 |
| 音频/视频 | 原媒体与摘要 | 转录、说话人、时间段、关键帧 |

文档解析器、OCR、转录和跨模态模型按已安装能力启用；缺失解析能力显示失败/未配置，不能静默截断或宣称完成多模态理解。

## 索引流水线

源业务写入与 IndexOutbox 同事务。投影按来源修订幂等执行：解析→分块manifest→嵌入→新版本替换→记录水位。文档变短必须删除旧尾块；删除保存墓碑；旧事件不能越过墓碑。模型/维度/分块配置变化使用新索引配置与代。

Lance 是数据格式，LanceDB 是嵌入式检索库。当前本地检索服务使用原生全文/向量接口。OceanBase 使用原生 VECTOR 和全文索引，不能读取有限行在内存排序后宣称分布式向量检索。

## 检索与授权

默认当前项目；扩大范围需要当前访问权限。索引查询带服务端范围，返回内容进入摘要/模型前重新核对来源权限与修订。排序分数不能解释为答案可信度。检索服务不可用时明确告知关键词模式及覆盖范围。

## 备份与恢复

清单包含事务水位、原件摘要/对象版本、索引配置与代、恢复验证记录。索引可重建，原件与来源版本必须可恢复。数据库备份成功、原件完整和恢复演练通过为三个独立结论。
