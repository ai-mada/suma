# 统一智能输入与配置采用架构

状态：1.0.0 目标设计，`FND-INTENT-001`／需求 26 待实现；不是新增运行能力或生产验收。来源与 S01–S12 映射见[两份分享规划采用](../integrations/shared-roadmap-adoption.md)，全范围见[产品基线](../product/v1-baseline.md)及[实施计划](../delivery/implementation-plan.md)。

## 所有权与唯一执行路径

自然语言输入、补全、CLI 命令和配置表单共用现有应用服务。智能层提出结构化草稿、解释默认值和影响，领域层拥有正式事实、权限与版本；执行仍提交现有唯一 Go DAG。它不拥有第二套任务状态、调度队列、授权或自动批准能力。

```mermaid
flowchart LR
  U[Web / CLI / 桌面输入] --> C[当前授权上下文]
  C --> P[现有规划与模型端口：结构化草稿]
  P --> V[共享合同校验 / 差异与影响预览]
  V --> A[当前策略 / 权限 / 必要人审]
  A --> D[既有领域命令 / 版本 / 原操作回执]
  D --> G[唯一 Go DAG / Runner / 正式提供方]
  G --> E[实际结果核对 / 固定证据]
  E --> R[业务事实与恢复状态]
```

| 边界 | 当前可复用基础 | 第 26 项仍需交付 |
| --- | --- | --- |
| 输入与上下文 | 项目身份、页面范围、CLI／MCP 合同、固定知识与设计上下文 | 通用意图目录、跨场景补全、必要字段追问及默认值来源 |
| 规划与能力选择 | 单次智能规划、模型选择、工具推荐、专家预览 | 可编辑多步操作计划、文件冲突／影响说明、策略化低风险自动采用 |
| 正式变更 | 现有需求／任务／配置领域命令、当前授权、CAS、原回执 | 跨领域计划的明确分步采用与后验核对，不伪造跨事务全局原子性 |
| 执行与证据 | Go DAG、独立 Runner、候选／测试／Review、发布 operation | 全场景 Web／CLI／桌面统一旅程及真实目标结果验收 |

结构化提案至少固定意图类型、来源主体／租户／项目、来源版本与摘要、目标资源、建议参数及默认值来源、影响、依赖、预算／模型依据、所需权限和待确认项。正式身份和可信摘要由服务端读取；提示词、模型或客户端不能自授权限。缺失会影响执行的字段才追问，其余默认值明确标注并可审阅；超限拒绝，不截断验收条件。

低风险自动采用必须有当前项目策略及实际主体权限，策略固定到本次计划。扩大权限、团队治理、生产部署、数据删除和外发等动作继续走各自真实批准边界；自然语言目标不新增授权。模型／工具调用在事务外，采用前重新核对当前来源、版本、许可和预算，已有计划不因“最新”配置静默漂移。

## 配置领域与成熟框架

统一配置视图应管理模板、实例、秘密引用、验证观察和变更计划。来源提出的 `ConfigTemplate`、`ConfigInstance`、`SecretReference`、`ConfigValidationRun`、`ConfigChangeSet` 在此是待实现的领域职责，不表示已有五套通用服务或表。工具、模型、执行池、存储等现有领域继续拥有各自正式配置；共享视图引用它们的版本、差异和结果。

表单及高级 JSON／YAML 使用同一服务端合同和校验；优先复用 Go 类型／生成 Schema、现有 React／Radix 控件、官方模型／工具 SDK 和现有 CLI。来源中的 Pydantic、Rich／Typer 是候选示例，不替换当前 Go／Bubble Tea CLI，不为统一输入再引入一套运行时。秘密只使用受控引用；预览、模型上下文与日志不得展示明文秘密。

配置采用顺序为：读取明确范围 → 提案／补全 → Schema 与领域校验 → 差异／影响预览 → 当前权限及必要批准 → 原操作应用 → 实际连接／目标核对 → 保存结果。配置已保存、连接探测、目标健康与业务可用分别记录。验证失败保留已发生效果；回退使用明确的新变更和当前权限，不把不可逆副作用包装成自动撤销。

## 恢复、观察与验收

计划生成、等待批准、已应用、部分应用、失败和效果未知分开。网络超时保留原主体、路径、正文、预期版本和操作 key；先恢复原回执，再核对实际状态。多步计划逐步保存完成事实；后一步失败不抹去前一步，不自动重跑已有副作用。只有瞬时且幂等失败可有界退避，同类智能修复三轮失败转阻塞，沿现有 SOP 保留诊断和尝试。

可观测记录关联需求／计划／任务／run／attempt、原操作、固定模型／工具、已知 Token 与费用口径、延迟和实际结果；缺失用量与未知费用不记零。语言目录使用 `zh-CN`／`en-US`，正文和原证据保留；前端显示来源、待批准与未知状态，不以模型描述生成成功提示。

需求 26 必须逐项证明：结构化参数；当前项目授权及提示词越权拒绝；原操作幂等；失败／未知恢复；重要变更预览、批准和审计；中英文；真实用量与结果；Web／CLI／桌面共用领域 API。代表性旅程覆盖创建、设计拆解、能力选择、诊断、配置验证及知识草稿；数据库、代码、测试或目标系统的持久事实才是后验结果。当前验收追踪仅推进 REQ-008／QA-001 的已有领域基础，不完成本项或完整测试／应用版本生命周期。
