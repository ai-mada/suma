# 远程工具检测交互设计

版本1.0.0；T-REMOTE-TOOL-SCAN-205；负责人：工作台代理／主集成代理；状态：本阶段实现与限定验证通过。关联[PRD](../product/remote-tool-installation-scan.md)与[架构](../architecture/remote-tool-installation-scan.md)。

## 一处入口与渐进呈现

工具快捷连接在明确Worker后提供“在此节点检测”入口，复用同一组件，不新建中心。默认当前所选工具，一次明确操作也可检测该节点许可的固定集合。先读能力；未声明或过期时解释原因，并准确定位原指南的允许项，不替用户勾选或启动。

列表先呈现已安装、异常和当前关注项，其余按需展开。每行显示正式目录名称、准确协议、观察版本与准备原因。安装但需配置的SDK仍可明确进入对应Guide；未找到和未确认探测不会显示可派发状态。

## 状态、恢复和控制

创建中禁止重复发起；回执未知优先显示原操作核对按钮，即便只读历史已看到完成，也不悄悄丢掉写入恢复依据。pending、claimed、completed、failed、unknown及closed_unknown表达不同事实。限时停止页面等待不取消机器；重新打开可读取原请求。历史选择使用明确列表，当前范围改变不沿用旧选择。

用户切走标签页时，自动读取暂停，已开始的读取可以完成。返回后在原等待期限内跟踪同一个检测请求。等待到期与手动刷新可以并行处理，刷新继续返回完成、失败或无权读取等实际状态。页面重挂载后按当前节点重新读取。此处沿用“重新读取”入口和现有状态区，详见[恢复验证](../quality/remote-tool-installation-scan-verification.md#读取恢复补充验证)。

切换历史记录会接管旧明细读取。在准确记录核对前，状态区显示正在读取，准备和配置入口暂时收起。“重新读取”可接管后台轮询或正在切换的明细。刷新完成后仅呈现当前选择；迟到的旧明细不会改写当前观察或重新启动轮询。 [阶段验证](../quality/wake-and-scan-recovery-verification.md)

completed完整观察的准备按钮只带准确adapter与worker进入原Guide；不复制内部Command、不注册、不启用。当前来源变化和机器撤销立即撤下旧观察的继续资格，但保留当前人有权读取的不可变历史；当前人失去项目访问权才拒绝历史读取并清呈现。原机器未知占用保持可解释，不提供会掩盖真实进程的“强制成功”。

原Remote指南的允许检测项默认未勾选；“仅启动节点工具检测”命令带明确maintenance-only，不要求开发仓库。原开发启动与单次上报分别保留，避免让用户误以为复制命令就是安装或运行成功。

## 视觉与国际化

沿原令牌和原生控件，44px操作、窄屏单列、长标识换行和清晰状态区域。动作名称直接表达检测、核对和配置，技术原始依据收起；中文和英文共用语义键。键盘触发、焦点、加载、空态、无权限及断线恢复沿现有组件。
