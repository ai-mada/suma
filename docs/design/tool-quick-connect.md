# 工具快速接入交互与AI SOP

T-TOOLS-151。目的：用户选工具后直接看到真实配置和下一步，减少先理解节点、协议及清单的负担。[产品](../product/tool-quick-connect.md)、[合同](../../contracts/tool-quick-connect.md)与[架构](../architecture/tool-quick-connect.md)共同定义当前范围。

## 主操作与信息层级

“添加工具”先选择产品的具体执行入口。节点读取完成后，唯一活动节点自动采用，多个节点显示选择框；唯一新鲜可用配置自动选择并建议名称。用户核对名称、节点、版本和写入方式后点击“登记配置”。成功区域明确“已登记，保持暂停”，提供单独“启用工具”，进入原确认界面。

协议、配置摘要和本机路径放在技术详情；手动清单和本机命令说明放在“高级接入”。它们保留既有能力，不作为默认首屏步骤。所有新文案保持中英文对应，沿现有明暗、焦点和窄屏样式。

| 当前事实 | 界面反馈与下一步 |
| --- | --- |
| 节点读取中／失败 | 显示读取状态或针对原读取重试，不能用旧节点继续登记 |
| 没有活动节点 | “连接执行节点”进入既有登记；桌面另可检测本机安装 |
| 节点未上报／报告过期 | 解释连接或配置需求，提供重新读取 |
| 新鲜报告无匹配配置 | 提示检查该节点的安装、协议和工作区，保留高级接入 |
| 多个可用配置 | 明确选择，不能代替用户挑选写入策略 |
| 登记已确认 | 显示原准确暂停档案，独立核对启用 |
| 写入未知／版本冲突 | 保留原操作核对；不能用新请求覆盖不确定结果 |

## 本机安装区域

仅在桌面桥接有效、工具属于固定三项且当前项目暂无活动节点时显示。“检测本机安装”由明确点击启动；探测中禁用重复点击。结果使用“本机已检测到安装”“未检测到安装”或检测未完成。已找到但固定协议探测未通过时提示确认启动方式，不能显示已连接或已可派发。

本机安装不会填入Runner固定Profile，也不能启用“登记配置”。账号、组织、项目或工具切换使原区域卸载；迟到结果不进入新区域。原生层还在结果返回前复核原账号与项目，取消后未确认子进程关闭仍保持占用。

## 操作与恢复约束

AI与自动化可以读取目录、当前节点及原新鲜报告，提出准确候选；不得从安装结果猜测供应方登录、在线节点或执行授权。自动建议名称可编辑，已有人工草稿不能被迟到读取覆盖。

登记必须保留原Profile和稳定操作标识，启用必须沿当前版本独立确认。超时先核对原回执；失权停止后续操作，切换身份不能恢复原写入资格。高级接入中的配置、清单和未确认操作沿原离开保护。

后续托管Runner应让用户核对安全节点事实后明确授权，本机组件完成加密凭据交付与恢复；浏览器不提供复制secret的捷径。当前未提供该托管能力，也不能将本次安装检测呈现为其完成。
