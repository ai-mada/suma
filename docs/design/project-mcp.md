状态：T-P4-019 限定本地已验证；真实浏览器中英、键盘和390英文窄屏通过。更新：2026-10-26。Owner：工作台与国际化；集成 Owner：平台主集成。关联需求：紧凑项目工作台、当前身份、FND-I18N-001；[产品范围](../product/project-mcp.md)。证据见[阶段验收](../quality/project-mcp-verification.md)。

## 信息顺序与操作

沿用“设置 → 项目令牌”，不新增菜单、向导、连接管理页或自动测试按钮。页面顺序固定为：

```text
创建项目接入令牌：绑定项目 → 备注 → 用途范围 → 明确创建
原一次性结果／原操作未知回执
原接入说明
开发者接入                         刷新接入详情
  客户端连接未验证
  绑定项目／可信端点／地址来源     复制端点
  Codex 配置模板                   复制配置
    可选择的原文配置＋进程环境与原视图说明
  ▸ 查看工具目录（13）             默认折叠
  Agent／API／批准与执行边界
```

“客户端连接未验证”是声明，不因复制、签发或元数据读取成功而变为已连接。优先让用户核对项目、地址并复制配置；13 行目录只在原生 `details/summary` 展开后可见。摘要数量来自返回目录，使用 `formatNumber`，不写死为 13；展开后按 MCP 名称、canonical 名称、用途、只读／草稿写入和凭证范围展示。

端点只使用元数据 `endpoint_url`。`configured` 表示管理员公开配置，`listener_loopback` 明确只供本机可达客户端，`unconfigured` 显示原端点路径及管理员配置指引，不提供猜测的配置或复制连接 URL。页面不采用 `window.origin`、代理 Host 或 Forwarded 拼接凭据目的地。

配置使用已核实的 Codex `url`、`bearer_token_env_var` 和 `http_headers`，秘密仅由客户端进程环境 `SUMA_MCP_TOKEN` 提供。账户／组织 ID 是固定原视图约束；语言头跟随当前界面语言。页面只复制用户明确选择的端点或配置，不自动改用户 Codex 配置，不把令牌插入模板。

## 状态与保留规则

| 状态／触发 | 界面与下一步 |
|---|---|
| 未选择项目 | 保留既有“请先选择项目”，不读取元数据或创建凭据 |
| 首次加载／手动刷新 | 隐藏旧目录和配置，显示既有加载状态；只读元数据不证明客户端连通 |
| 有效声明 | 显示当前项目、可信端点与未验证说明；按需展开工具目录 |
| 空目录 | 摘要显示真实零数量，展开后明确“尚未声明工具”，不填入示例工具 |
| 地址未配置 | 显示端点路径与 `SUMA_PUBLIC_URL` 指引，隐藏连接模板和复制端点操作 |
| 网络失败／格式不符 | 显示具体错误或合同不符提示，允许明确“重新读取”；不自动重试业务命令 |
| 401／403 | 清除旧目录、配置与权限事实，再显示错误；旧成功结果不能继续充当当前授权 |
| 项目／账户／组织切换 | 立即失效旧快照，取消原读取并拒绝晚到响应；新身份重新读取，不借旧身份补齐 ID |
| 配置复制成功／失败 | 成功仅反馈“已复制”；失败保留可手动选择的配置，既不调用工具也不写浏览器持久存储 |
| 语言切换 | 原 DOM、目录展开状态及原值保持；重算配置语言头，撤销旧“已复制”状态，忽略晚到的旧复制反馈，不重新请求元数据 |
| 签发中／未知回执 | 沿用原表单 busy 和未知操作锁；仅保留非秘密原操作提示，不自动重发或伪造令牌恢复 |
| 一次性令牌／改用途范围 | 秘密仅在原签发视图短暂显示，显式复制令牌仍是独立操作；改范围／身份清旧结果，身份变化后的晚到秘密不显示 |

模板和目录不接收凭证输入。新增接入区不写 localStorage、配置文件、URL 或日志；原签发未知回执继续按既有会话规则保留非秘密标识，不能与令牌值或连接健康混为一谈。

## 中文、英文与后续语言

当前只启用 `zh-CN` 与 `en-US`，沿用 i18next／react-i18next、统一语言偏好和[全平台国际化规范](internationalization.md)。接入区文案位于现有 workspace 成对领域目录，包含加载、错误、复制、来源、只读／草稿、权限和辅助名称，不在组件增加逐语言分支。

工具用途来自服务端同源目录的 `description_key=application_tool_<canonical点号换下划线>`；界面用 `formatServerCatalogMessage(key, [], {})` 按当前语言显示，目录缺失或不兼容时保留原 `description`。晚到语言目录只更新解释，不改变工具目录、身份、业务结果或自动发起调用。

| 内容 | 显示规则 |
|---|---|
| 导航、操作、状态、目录摘要和来源解释 | 使用稳定目录 key，数量经当前语言格式化；真实零与未知分开 |
| 配置语言头 | 仅 `X-Suma-Language` 随当前语言重算；固定账户／组织 ID 与 URL 保持 |
| canonical／MCP 名称、协议字段、scope 枚举、原始 source 值 | 作为机器身份保留；只翻译对应解释，不改写服务端值 |
| URL、项目／用户／组织 ID、SHA、正文、原始诊断与凭据 | 保留原值；不按中英文句子猜测、递归翻译或解析为 HTML |

增加语言时先扩展统一 BCP 47 注册、协商、语言类型及回退规则，再补齐相同 workspace key 和服务端工具说明；复用 Intl 格式化，不改变协议枚举、排序、版本或幂等正文。必须检查成对 key、占位参数、缺项回退、长文案、错误恢复及切换保留。新语言上线应覆盖 Web、CLI／SDK 对人说明等相关表面，不能只添加选择器即宣称完成。

## 窄屏、键盘与动效

沿用既有主题、颜色令牌、焦点和减少动效规范。设置面板保持现有宽度；小于 600px 时事实改为单列，按钮和目录摘要保留 44px 操作高度。URL 与配置可换行，表格限定自身滚动，不让页面产生横向溢出。390px 下仍先看到项目／端点与复制操作，目录默认折叠；真实字体、长英文和两语言布局由 Root 浏览器检查。

使用原生按钮、`details/summary`、表格表头与可聚焦配置原文；Tab 顺序跟随可见文档顺序，摘要通过 Enter／Space 展开与折叠，保留可见焦点。复制反馈用现有 `role=status`，失败用 `role=alert`；不新增自动聚焦、展开动画或连接成功动效。减少动效沿用全局规则，不另加动画覆盖。组件检查不替代实际浏览器、读屏软件或完整 WCAG 验收。

## 实现与交付接缝

页面入口为 `apps/web/src/Tokens.tsx`；视图、校验／配置投影及样式分别为 `DeveloperConnection.tsx`、`developer-connection-model.ts`、`developer-connection.css`，词条位于 workspace zh-CN／en-US。元数据接口为 `GET /api/v1/developer-connection?project_id=…`，调用端点为 `/api/v1/mcp/projects/{project_id}`；声明含 `client_connection_verified=false`。
