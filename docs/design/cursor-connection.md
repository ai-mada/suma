## 入口与主要动作

工具工作台→快捷接入→Cursor。主内容先说明“编辑器与Agent不同，当前尚不能派发”。浏览器提供准确官方指南并说明需要桌面端才能检查当前电脑；桌面提供一个明确的“检查当前电脑”按钮。不会自动检查、安装或打开登录流程，不出现虚假的登记／启用／派发入口。

检查旁始终标明“仅当前PATH，仅读取固定名称文件，不运行Cursor”。此次发现不代表远程Runner或整机安装状况；候选绝对路径只放在可展开技术详情中。没有版本时不显示推测版本。

## 状态与恢复

| 状态 | 可见内容与动作 |
|---|---|
| 未检查 | 范围与官方指南；按钮可操作 |
| 正在检查 | 撤下旧事实，保留范围说明；不显示虚假百分比，不重复发起 |
| PATH未发现 | “此次检查未发现”，可重新检查；不声称整机未安装 |
| 仅编辑器 | 明确编辑器不能当作Agent，提供CLI指南 |
| 原生候选／启动脚本 | 文件存在但尚未核验或不支持执行；路径渐进展示 |
| 不完整或失败 | 原因与重查动作；不降级成未安装或继续展示旧成功 |
| 无桌面桥 | 浏览器指南与边界；不伪造检查按钮和本机结果 |

显示观察时间，避免把旧发现当成实时健康。每次重查建立新范围；账号、组织、项目或工具变化及卸载使旧响应失效，包括迟到的错误。切语言只重显说明，不改变路径、事实、planned状态或发起执行。
