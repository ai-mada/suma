## 入口与结构

保留任务列表当前已载入任务的选择列和“安排团队执行”入口，最多 16 项。
原 `TeamTaskDispatchDialog` 增强为同一计划的准备、明确启动和跟进；`ExpertTeamPanel` 继续只管理专业配置。
依赖任务和独立任务不分为两个产品。URL `panel=expert-team:<id>` 恢复原计划，清空定位不产生准备或派发请求。
关闭后不读取，切换账号／组织／项目卸载旧范围；待恢复写保留原调用身份与操作标识。

主路径为“选择真实任务与职责 → 核对固定依赖预览 → 明确启动 → 按任务跟进”。
详情顶部显示团队、来源修订、计划状态和明确进度计数；中部使用拓扑顺序的简洁任务卡片。
不增加可拖动依赖画布，不在浏览器改写实际依赖图，不用多个进度页面承载同一计划。
当前动作在列表后集中显示，来源／摘要／历史默认折叠，专业上下文按需打开。

## 固定预览

每项显示任务原题、固定职责／资源、任务版本及直接前置依赖标签。
所选依赖可使用列表内原题，外部依赖显示服务端事实和真实 task ID，不猜测未授权名称或隐式扩选。
标签同时说明是否所选、当前正式验收和阻断原因；详情可查看外部验收 run 的固定依据。

未派发项显示“尚未派发”，实际 run／dispatch plan 为空时不生成预留运行链接。
确认说明根项可先进入队列，后继须等待本计划准确前置运行的正式人工验收，且后续仍重核当前权限和来源。
预览不等于运行，启动不等于所有任务同时执行。

## 进度与事实状态

| item 状态 | 展示含义 |
|---|---|
| waiting_dependencies | 等待具体前置正式验收，未派发、不占机器槽位 |
| ready | 依赖已满足，等待服务端按当前资格派发 |
| queued | 已绑定实际 run，等待既有调度资源 |
| executing | 原运行正在执行；用实际 run 状态辅助说明 |
| awaiting_review | 原运行完成，等待对准确 run 的正式人工验收 |
| accepted | 本计划实际运行的正式验收有效 |
| blocked | 显示来源、凭据、失败或未知等真实阻断理由及原入口 |
| stopped | 未开始工作已停止；不代表已有进程关闭 |

进度使用服务端 `progress` 的总数、等待、就绪、执行、待验收、已验收、阻止、停止计数。
不将 queued 视为成功，不将 succeeded 视为 accepted，不根据局部列表补零或推导平台完成率。
实际任务和 run 可打开既有详情／质量入口；正式验收仍在原任务评审界面，计划不提供人工改 accepted 的快捷控件。

## 明确管理与修订

当前 `allowed_actions` 决定可见命令，不从本地角色或状态名称推断权限。
pause、resume、stop、revise 均填写理由、明确确认并携带预期版本与稳定操作键。
暂停说明“只暂停后续派发，现有运行继续”；停止再次说明“未开始项停止，运行需另行停止／核对”。
恢复说明将使用本次当前主体的实际凭据更新激活，后继仍逐项复验；不宣称注销后仍有无限期自动授权。

修订表单只允许选择未开始项、当前任务版本和已发布配置的职责。
切换配置版本时需显式选择全部未开始项；已启动项作为只读固定集合，不能移除、换职责或替换原 run。
保存形成新来源修订和图摘要，不静默把旧确认绑定到变化后内容。历史分页及单修订只读，无当前写动作。

## 恢复、读取与可访问性

409 保留用户理由和修订选择，明确读取当前版本后重新确认；来源发生实质变化仍须显式修订。
未知响应恢复原 path／body／key，不自动重建计划或重新启动。外部未知回到原 run／attempt 恢复，不从界面猜测结果。
版本／修订／权限变化清除确认勾选。跨范围请求 Abort 且旧数据立即隔离；同路径刷新可保留可读内容，但禁用过期写动作。

只对当前打开的活动计划使用有界 GET 刷新，因为人工评审和未派发项没有可依赖的 run SSE。
定时器在关闭、终态或页面不可见时停止，读取串行且可取消；没有全项目轮询、浏览器派发循环或每次刷新创建业务版本。
存在合法非空期限时显示本地年月日和时分；没有期限的来源快照不显示“到期时间：未提供”。历史修订显示真实修订时间，原值与 hash 保留在折叠依据中。

所有新增输入、下拉、复选和命令从首版提供明确可访问名称，逐任务职责名称包含原题以区分重复控件。
沿用 Radix 焦点恢复和键盘关闭；未知写入保留离开保护。状态除颜色外均有文字，窄屏单列和 44px 触点，长 ID 可换行。
控件、状态和受控宿主理由使用成对中英文目录；任务、职责、工具、知识与原始证据保持原文，不猜译。

必要交互验证聚焦依赖预览／明确启动、等待正式验收再跟进、准确管理语义、修订的 started 集合保护、
当前权限、原请求恢复、范围隔离和可取消刷新，已有通过记录。实际界面完成固定预览、启动、待人工验收、暂停后的原根验收、
