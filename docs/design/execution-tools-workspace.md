# 执行工具工作区

2026-10-29 · T-TOOLUX-129。范围为组织与项目设置中的执行工具及现有登记、探测、复核流程。复用[工具执行合同](../../contracts/tool-execution.md)，不新增执行或授权通道。

当前交互迭代为 **T-TOOLUX-130**，限定验证见[深化报告](../quality/execution-tools-refinement-verification.md)。已配置项目默认收起接入步骤；详情先呈现派发条件与操作，协议、指纹和原始依据按需展开。登记表单按节点、清单、命名分段，支持≤256KiB本地JSON文件、就近错误和下一步提示；内容独立滚动，保存区持续可见且不遮挡焦点。明确提交后显示当前用户／组织／项目范围的原操作反馈；本地读失败保留草稿，迟到读取不覆盖新清单或人工名称。

## 使用流程

1. 首次接入时，页面直接提示登记执行节点；已有私有或项目授权共享身份时，引导登记配置。
2. 接入指南保留现有本机配置模板和只读探测命令。浏览器不会扫描机器、安装程序、读取第三方凭据或启动模型。
3. 粘贴真实非秘密清单后，使用同一严格解析器自动校验。只有一个可用项时自动选中并建议名称；多个可用项仍由用户明确选择。用户修改过的名称保持原样。
4. 选择已登记执行身份，保存为暂停配置。继续核对版本、权限和实际观察，再明确启用。原 CAS、操作标识及未知结果恢复机制保持有效。
5. 页面根据已加载配置提示优先处理阻塞、复核暂停配置或返回任务派发。建议仅来自当前读取的确定性规则；不会调用模型、修改配置或自动启用。

## 信息与交互

- 无选中配置时，列表占完整宽度；选中后显示列表与详情。窄屏显示详情，保留返回列表入口。
- 全部、可派发、待启用、待处理、已撤销筛选与名称、节点、命令、适配器搜索组合。数量只统计当前已加载窗口；总量与分页范围另行显示。
- 列表直接展示状态与已本地化阻塞原因，详情保留原始原因和观察。身份数量仅表示登记状态，不推断在线、模型健康或实际执行结果。
- 读取中、失败以及失败后的重试期间均显示状态待确认；保留的数据不恢复为当前派发资格。详情读取中同样不显示已确认资格。
- 独立刷新栏同时服务列表与详情。每10秒统一读取配置、私有身份、授权共享节点和所选详情；隐藏页面跳过轮询。暂停影响全部周期读取，手动刷新仍可用；分页加载会暂停轮询以保留窗口。
- 保留项目既有紫色视觉、主题变量、简体中文和英文目录。键盘可操作，动态识别结果有状态提示；390px下筛选换行、详情及刷新控制可用。
