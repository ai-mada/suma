# 通用CLI准备卡与原指南交接

版本1.0.0 · T-LOCAL-TOOL-PREPARATION-220。依据[合同](../../contracts/local-tool-preparation.md)，用户步骤见[产品说明](../product/local-tool-preparation.md)。

## 两字段主操作

准确工具由原指南选择，卡片只呈现目标Shell和新输出JSON路径。复制命令与采用路径分别操作，采用不依赖剪贴板成功或文件生成结果。当前命令预览随输入更新；手动JSON移入默认折叠的高级示例，避免与主要操作争夺注意力。五种专用协议及内部模板不改变原义。

卡片复用原字段、按钮和焦点风格，局部控制高度44px；窄屏顺序排列，命令和长路径可换行。未完成、复制中、失败和仅复制成功分别说明，不显示“已连接／已生成”之类超出证据的状态。

## 分层与准确采用

| 层 | 职责 |
| --- | --- |
| 原Go准备器 | 固定PATH发现、被动原生版本／帮助探测、原CommandSpec及有界处理；使用受锚定目录与`O_EXCL`独占新建，拒覆盖和链接。 |
| 纯模型 | 从原目录准确选择四个非special协议，验证闭形三键draft，复用公共路径校验和Shell字面量生成原CLI模式。 |
| 准备卡 | 两字段、明确复制／采用；绑定caller、user、org、工具和单调字段revision，不发API或执行命令。 |
| 原指南 | 严格读取`{shell, commands, localTool}`，核对当前所选协议及来源，再复用原nonce交接。 |

普通指南只采用原Shell／commands／localTool字段，不改变身份、项目、Worker或执行参数。共享指南不呈现普通项目身份命令，只显示当前输出引用供用户明确复制；不自动写Pool表单、不上传本机文件或读取远程文件。

## 生命周期与原能力边界

字段A→B→A、工具或账户切换、API caller变化及disabled往返都使旧剪贴板完成失效。异步完成只更新仍属于当前revision的提示，不自动采用路径。组件只保存当前表单状态，不建立安装、连接或执行权威。

父指南继续核对当前source owner、epoch、navigationNonce和selectionNonce。默认Codex尚无显式导航选择时，首次明确采用创建新的当前选择代次；不能把没有来源的旧请求放宽为可重放。实际权限、版本、库存、登记、暂停／启用和任务质量门仍沿原系统处理。

## AI SOP与验证

维护先确认准确协议和原操作，再复用模型生成命令，不拼接自由flag或自行推断私有路径。目标Shell引用、原生探测、新文件写入、路径采用、库存登记与模型任务分别记录证据。只复验变化的模型、卡片和指南接缝；不以组件检查宣称实际厂商、跨平台安装或完整31项／P0–P7验收完成。
