# 知识索引检索与准确定位交互

状态：本阶段限定实现并验证；负责人：工作台代理；T-KNOWLEDGE-PROJECTION-197。[需求](../product/knowledge-projection.md) · [架构](../architecture/knowledge-projection.md)。

沿现有资料、任务与讨论的共享发现入口增加明确检索方式，保留输入、类型及已选引用。索引状态按需展开，界面不增加第二个配置中心。未配置向量时按实际全文模式显示；服务错误提供明确切换关键词入口。

| 事实 | 用户反馈与动作 |
| --- | --- |
| 已选关键词模式 | 沿原有界游标查找，保持T196准确发布语义 |
| 已选索引模式 | 显示实际全文／混合方式、代次与观察信息；不静默替换检索方式 |
| 投递等待或失败 | 展示该知识领域的计数与准确范围，刷新仍为只读 |
| 正在重建 | 显示实际状态，保留查询和引用；完成前不提示空项目或已追平 |
| 命中准确区间 | 原修订正文安全标记范围并定位；内容、版本、摘要及来源保持 |
| 区间或引用不一致 | 明确定位失效，允许核对原文；不做模糊查找或转入最新草稿 |
| 当前资格失效或撤权 | 清除不可访问结果，保留准确引用解释变化；重新选择仍由原任务门禁复核 |

中文、英文和窄屏复用同一状态与权限。技术字段折叠，业务原文不翻译；键盘可操作检索方式、结果、原文定位和返回，减少动效设置保持。选择操作只传原id／revision／sha256，不把片段、评分或索引代次当作任务批准依据。

限定实现与实际边界见[验证报告](../quality/knowledge-projection-verification.md)。
