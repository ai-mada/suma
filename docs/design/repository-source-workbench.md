## 入口与操作

在任务「交付与质量」展开「核对仓库来源」，选中已登记目标，再打开「准备候选」。仓库检查仍可单独使用。准备候选直接读取所选目标对应的任务版本、原运行、尝试和当前审批权限。

1. **留存来源**。同时显示来源和可信基线的完整提交。审批人确认后保存原 Git 包，或者显式选择此前留存的回执。实时仓库不可用时仍显示当前可用的留存回执。
2. **预览独立测试**。从当前路线的可用档案选择导入与测试 Worker。当前导入 Worker 自己的测试档案不可选。预览显示固定来源和工具版本。
3. **启动执行**。重新读取已保存计划并核对当前状态后，审批人确认启动。成功后通过原运行入口查看候选和测试进度。正式验收仍沿任务的现有验收入口处理。

## 异常与恢复

- 审批权限不足时显示原因，用户仍可使用既有授权的来源查询。缺少发布用例、活动终端、没有独立 Worker 时，面板说明阻塞条件。
- 浏览器按用户、组织、项目、任务、原尝试和目标版本保存操作标识。响应无法确认时，恢复会发送原路径、正文和标识。恢复启动前先读原计划，并核对响应的租户、项目和运行 ID。
- 外部 Git HEAD 更新会提示再次核对。此前留存的包仍显示确切提交，选择旧回执需要看见它所绑定的版本。
- 面板随键盘焦点进入；在窄屏纵向排列步骤和选择项，长提交可换行。按钮、说明和错误状态使用现有中英文体系。
