# Cursor 高级配置交互

状态：限定实现与验证通过；suma1.0.0；T-CURSOR-SETUP-191。负责人：工作台代理；关联[PRD](../product/cursor-setup.md)、[合同](../../contracts/cursor-setup.md)和[证据](../quality/cursor-setup-verification.md)。

沿原工具高级入口显示一个Cursor表单，不落回通用JSON导入，也不把反向MCP客户端指南当执行配置。六项字段采用现Field与统一设计令牌；目标Shell由用户明确选择，不能根据浏览器OS猜测远程机器。

包目录派生固定Node名称；版本、模型和环境变量名分别标注来源。界面不接密钥值、argv或手算摘要。固定参数和边界默认折叠；准备命令保留可选择原文，仅准确复制成功后显示已复制，编辑后撤下该反馈。

明确按钮把当前文件路径／Shell草稿用于既有执行节点指南，沿用账号、项目、配对目标及身份流程。换账号、项目或目标不能复用过期草稿；用户主动输入过的新目标不被迟到回调覆盖。Cursor不能出现缺少本机参数的generic prepare死路，已有文件的report／start继续原语义。

文件准备、连接、库存、暂停登记、明确启用及实际执行分别表达。不得以已复制、路径存在或配置可解析显示模型健康／可派发。遇已有文件、源改变、权限不足或未知回执，保留原文并引导核对原对象。

执行依据显示真实host退出值与准确RPC后受控停止说明；不把非零值改为0，不把cancel通知写出显示为供应方ACK。完整user_inputs证据严格校验原session、配置、typed ID及原输入送达，不因为新字段而隐藏190真实执行依据。

中英文使用相同控件、占位符与状态。正文14px、可触达动作44px、390px单列，长目录／命令可滚动和选择；键盘、焦点、复制失败和disabled沿成熟组件。仅验证关键配置、节点草稿衔接及一组真实证据视图，不重整套矩阵。
