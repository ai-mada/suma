# 工具档案复用交互

T-TOOL-PROFILE-REUSE-180；suma 1.0.0。依据[冻结合同](../../contracts/tool-profile-reuse.md)，参见[产品流程](../product/tool-profile-reuse.md)与[架构](../architecture/tool-profile-reuse.md)。当前实现中，尚未完成实际交互验收。

在原快捷接入中增加已有配置结果，不增加连接向导。用户选定工具、节点及准确新鲜库存后自动只读查找；主要区域只展示当前事实、一个明确下一步和必要详情。

## 结果与下一步

| 当前事实 | 展示与操作 |
| --- | --- |
| 正在查找 | 显示忙状态，阻止登记及父级切换 |
| 查询失败／响应不完整 | 显示准确错误和“重新查找”；不显示可直接新建的空态 |
| 完整空集 | 说明没有相同配置，提供“新建并暂停登记” |
| 一个暂停匹配 | 展示原名称与暂停状态，明确“使用已有配置”，再进入原启用确认 |
| 一个已启用匹配 | 展示原名称、当前 `Available`／`Reason`，明确“打开已有配置” |
| 多个可复用匹配 | 必须先明确选择，不默认第一项 |
| 只有撤销历史 | 展示撤销状态并说明不可恢复，允许明确新建 |
| 创建遇 409 | 保留名称草稿，重查已有配置，不冒充本次创建成功 |
| 原写入待核对 | 优先显示原创建／启用恢复入口，阻止新登记及父级切换 |

“匹配”只说明完整配置相同。“已启用”表达原授权状态，“当前可用／不可用”表达此刻条件；不将三者合并成一个成功标记。已启用但不可用时，保留原原因与下一步。

## 明确采用与启用

采用原档案保留其 ID、名称、版本和配置，不复制档案、不自动改名。名称草稿只服务可能的新建，不参与相同配置判断。

暂停档案复用后进入原启用确认，提交准确 `expected_version`。选择、连接或匹配不会触发启用。已启用档案打开原详情，不额外发送启用命令。撤销记录只读，不能作为可选复用项。

## 异步与原操作

匹配请求属于当前账号、组织、项目、adapter、worker、完整 Profile、库存截止时间和 API caller。任一变化都使旧响应失效，不能由迟到响应重新选中原档案。

原 pending 写入先于匹配处理。新的只读结果不能清除日志、改写原请求或换 key 重发；原操作恢复完成后再读取当前匹配。读取超时显示只读错误，不显示“创建结果未知”。

启用冲突、权限撤销、节点或配置变化时，保留准确错误并重新读取当前事实，不自动创建替代档案或重新启用。原草稿和连接恢复语义保持。

## 中英文与可达性

中文“使用已有配置／打开已有配置／重新查找”对应英文“Use existing configuration／Open existing configuration／Find again”。只有完整空集或仅撤销历史时显示明确新建入口；已有可复用档案时与新建入口互斥。

结果使用原表单、状态、按钮和焦点样式。窄屏按名称、状态、当前原因、动作顺序纵向排列，长配置内容放详情；选择控件和按钮保持键盘可达、可见焦点及原触控尺寸，不能仅靠颜色区分状态。

CLI 返回同一完整集合，由调用者明确后续选择；不自动创建、启用或默认选择首项。本片不改变真实执行、候选、测试和验收入口，也不扩大其已验收声明。
