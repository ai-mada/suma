## 讨论交接

入口保留在已完成助手回复旁。用户先看到准确来源，再编辑开发目标与补充验收条件，选择流程／开发节点及原 dispatch-options 当前确认合格的可写工具。工具列表复用普通开发资格，涵盖 suma、codex、harness、codebuddy、固定 Qoder ACP、Claude、OpenCode SDK、Octop；仅安装检测的入口不会混入可执行选择。

模型区域复用原选择组件：原生／Octop 选择原部署和预算；Codex App Server 选择当前目录模型、推理强度并展示用量观察边界；固定配置工具展示既有模型依据，不要求无意义的额外选择。用户确认真实工作区执行后创建预览；核对来源和固定执行事实，再单独确认开始。

| 状态 | 展示与操作 |
| --- | --- |
| 来源仍有效 | 展示准确回复和版本，允许审阅目标并准备预览 |
| 来源、工具、目录或任务依据变化 | 保留草稿，刷新当前依据后重新核对，不自动采用新版本 |
| 创建／开始响应未确认 | 显示原操作恢复入口，使用原正文与键；阻止通过新选择重复执行 |
| 预览就绪 | 来源正文、审阅目标及固定工具／模型事实可展开查看；开始需要独立确认 |
| 原计划已开始 | 打开原运行，展示真实进展；恢复只定位原计划／运行 |
| 权限失效或计划不再有效 | 显示当前原因，阻止依赖写入，保持已取得的历史事实 |

知识来自准确回复的已核验引用，用户无需复制知识正文或重选技能。消息、上下文与技能包一致进入预览。审阅补充条件不会替换任务或已发布测试；运行、候选、同提交独立测试、Review 与人工验收分别展示。

## 远端执行节点指南

指南按“准备配置 → 单次上报 → 原页面核对／启用”组织。先选择 PowerShell 或 Bash，再填写公开定位信息：可达控制面地址、项目／执行节点、全新配置文件、原状态目录、仓库及完整基线。凭据仅引用目标机器已有的 `SUMA_RUNNER_TOKEN`，不在浏览器输入、展示或复制实际值。命令为可审阅草稿，不自动运行或安装工具。

准备区提示父目录必须已存在、无链接且文件尚未存在。当前自动生成项仅 Codex JSONL、CodeBuddy、dsh、Claude；选择其他项时明确说明仍需配置或当前不支持。零项可生成时显示未准备原因，不把空文件当作成功。

上报区在公开字段齐全、仓库与完整基线有效时才给出命令。`--allow-exec` 的说明紧邻命令：它授权实际程序／协议／工作区探测，不代表模型登录。回环地址显示仅限本机提示，异机需安全、可达的控制面地址。配置文件生成、库存 ACK、连接运行和启用各自保持独立。

回执未确认时，引导保留原状态目录并以原控制面／项目／执行节点恢复。原单次操作恢复后停止，不自动发新清单、不启动持续运行。日志缺少作用域摘要或与当前作用域不符时展示拒绝事实，不建议清日志、回填或改键绕过。

## 双语、简洁性与 AI SOP

中文／英文表达相同执行事实；主界面保持目标、工具选择、预览与明确开始四个重点。来源正文、技术摘要和详细依据放入可展开区域；固定模型不出现错误的必填字段。异步读取结果只作用于原任务、工具与版本，当前响应不覆盖其他范围的草稿。

AI 不从讨论文字推导额外 shell、目录、工具、预算或验收权限。预览前核对来源；未确认操作先恢复；来源、库存和路由由服务器判断。配置帮助只生成命令草稿，不把本机检测、上报成功或进程退出写成完整开发验收。

现有定向后端、Runner 和组件检查已覆盖关键分支；代表浏览器、完整登录桌面与异机旅程按专项报告分别记录。真实厂商工具／模型、物理多机、全设备主题、安装和生产验收继续待办，完整 31 项／P0–P7 目标保持。
