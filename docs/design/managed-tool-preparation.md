# 工具快速接入交互

速码1.0.0 · T-MANAGED-TOOL-PREPARATION-224 · 负责人：工作台组。关联[产品](../product/managed-tool-preparation.md)、[合同](../../contracts/managed-tool-preparation.md)与[验证](../quality/managed-tool-preparation-verification.md)。

原工具管理首屏和添加入口保持；在准确远程扫描行按需展开一个小表单，不新增导航或配置中心。首要信息为工具、机器、固定模型、凭据名称和本次写入确认，机器路径与实现摘要不要求用户填写。节点缺能力时返回原接入指南，普通／Pool指南中的独立准备权限默认不勾选。

| 状态 | 呈现与动作 |
|---|---|
| 可准备 | 说明本次将写入机器配置；确认前不能提交 |
| 等待节点／正在准备 | 显示原操作和等待原因，避免重复创建 |
| 等待库存确认 | 保持等待，不能登记或启用 |
| 已完成 | 当前重读准确库存，再采用该配置 |
| 未知或读取失败 | 原已提交操作保留，只提供原核对与明确重试 |
| 来源变化 | 保留原观察；禁用新登记，明确重新选择 |
| 当前不可执行 | 说明真实原因，只允许准确完成配置保存暂停 |

目标、扫描或会话切换递增来源代次，迟到回调不能打开旧工具；A→B→A也不能恢复旧授权。未知提交的请求／地址／操作标识优先恢复，不被新目录、失败读取或另一个项目覆盖。完整profile摘要绑定选择，最新时间戳不能把不同配置变成已确认。

可访问性沿用原对话框、标签、焦点和反馈组件；表单键盘可操作，明确确认与主要操作触达不小于44px，窄屏纵向排列。中文／英文使用同一模块词条、状态和校验，不把机器回传原因伪装为本地化平台文案。代表界面验证与实际执行验证分别记录，完整App／设备／主题矩阵留待发布验收。
