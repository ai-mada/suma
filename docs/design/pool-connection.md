## 渐进展开的主流程

保留原配置准备入口。有效准备预览之后才出现可展开的“连接这台机器”，不另建常驻向导或综合健康面板。常用输入为控制地址、身份文件及用途；状态目录使用配置文件派生值，允许明确修改，不猜测用户目录。单次核对与前台启动分别复制，邻近文案说明复制不执行。

默认维护用途。安装检测须明确选择后才能复制维护启动命令；切到任务用途才加入执行开关，安装检测保持独立同意。任何准备内容、节点、项目、来源或字段变化立即使旧命令／读取失效；A→B→A也不能接收旧异步结果。

## 事实与下一步

| 页面状态 | 呈现与动作 |
|---|---|
| 尚未读取 | 展示准确项目选择与刷新，不提前标记连接成功 |
| 读取中／读取失败 | 使用原加载与错误状态，允许明确刷新，不隐式启动机器或工具 |
| 无当前项目权限 | 只显示共享Grant事实；隐藏库存依据和项目工具链接，不自动切组织 |
| 尚无库存／库存过期 | 说明缺少哪一项当前报告；历史联系时间仍明确标为历史 |
| 维护来源未知／不相符 | 展示固定原因，不把旧凭据或不同报告组合成当前状态 |
| 当前来源相符 | 展示服务器读取时间、历史联系和当前库存数量；按观察／失效时间自动撤销当前标记；真实0条与未报告分开，数量不表示可执行 |
| 期限已结束 | 撤销当前标记并提示刷新，保留原时间说明 |

日期时间按当前中英文locale呈现年月日和时分秒；只做展示格式化，不改变原RFC3339Nano值、来源比较或期限判断。不会用时间截断制造“新报告”。

项目工具链接只采用当前服务端`can_open_project`，用受限`pool-tool:POOL:RUNNER`定位准确项目的原共享Worker。进入后由原当前目录再次核验，仅打开原Quick／Guide；登记、启用、检测和派发均保留原明确操作。既有未知写入继续原恢复入口，不因导航或折叠而被隐藏、丢弃或重新创建。

## 易用性与验证边界

中英文使用相同信息层级；窄屏单列，键盘可展开、选项目、复制、刷新及进入工具，操作目标沿原44像素规范。不要靠绿色数量、历史时间或“已配置”徽标表示整体可用。

一次真实后端旅程验证中文1366和英文390代表界面、当前报告、原Quick准确交接与明确用途切换，原两图由主集成查看。浏览器外壳和剪贴板桥属于自有测试夹具；未证明真实桌面IPC、复制的前台启动命令执行、全设备矩阵或生产安装。完整平台能力继续按原计划交付。
