# 工具设置、任务派发与运行事实

状态：T-P4-004 组件、类型、实际React DOM及本机部分浏览器旅程验证完成；完整体验矩阵继续验收，见[阶段报告](../quality/tool-execution-verification.md)。负责人：工作台代理、主集成。关联：[执行架构](../architecture/tool-execution.md)、[合同](../../contracts/tool-execution.md)。源码：`ToolWorkspace.tsx`、`TaskDispatch.tsx`、`ToolFacts.tsx`、`ToolBindingStatus.tsx`、`ToolNodeFields.tsx`。

## 信息架构与主要流程

执行工具位于项目设置，管理已有执行节点、固定工具档案和当前探测；任务详情提供“安排工具执行”，运行详情展示本次执行及恢复事实。协作负责人、机器执行者和工具配置分别显示，不用成员资源名称直接派发。

1. 登记执行节点身份，或选择已有节点。一次性凭证只在当次弹窗内存显示，关闭后不可恢复；未知网络结果必须恢复同一操作，不能用新身份假装原操作未发生。
2. 粘贴本机`--describe-tools`产生的非秘密清单。解析器拒绝原始可执行路径、参数、环境值及任意额外秘密字段，展示协议、命令、版本和配置摘要。未安装／未支持项保留不可用原因。
3. 创建暂停工具档案，核对后显式启用。启用与现场可用分开：可能已经启用但清单过期、节点撤销、启用者权限失效或实际摘要不一致。不可用状态不显示绿色成功提示。
4. 在任务详情选择已发布流程版本、真实主开发节点及当前可派发的隔离写工具。先预览完整任务、需求、验收条件、固定流程和独立候选测试；后显式开始。只读工具、缺少对应候选测试、版本冲突均阻止开始并保留选择。
5. 成功回执打开正式运行。工具活动、来源会话／请求、实际Token报告、受控DAG、独立测试与人工验收分层显示。失败可以继续打开正式问题并去重回流需求；未知结果只能核对，不能凭来源ID自动重跑。

## 当前资格与历史事实

尚无输出的ready节点也显示固定命令、profile ID与摘要，并每10秒读取当前新派发资格。只根据当前NodeRun的固定配置投影，不依赖编辑草稿或猜测的图连线。当前档案停用不把已成功历史改成失败，也不把运行中节点说成未启动。该资格只解释工具门禁，不能冒充完整资源／预算或依赖诊断。

“查看工具配置”保留原run/node返回上下文；工具页可完整返回原节点。设置页用`view=settings&sub=tools&record=<id>`定位；任务派发使用`panel=dispatch:<plan_id>`，刷新读取不可变计划与当前有效性。页面、组织、用户或项目变化时，迟到请求必须被忽略。

## 读写与错误恢复

| 状态 | 用户可做的事 | 必须保持的依据 |
|---|---|---|
| 首次加载 | 查看明确加载态 | 不用旧项目数据填补新项目 |
| 无工具 | 登记节点、粘贴清单、创建暂停档案 | 不内置假工具或示例健康数 |
| 档案不可用 | 查看原因、配置或现场探测 | 配置、启用、现场和实际任务成功分别表示 |
| 列表更多 | 查看已加载范围 | 进入历史窗口后停止自动覆盖，明确刷新才回首批 |
| CAS冲突 | 保留选择／草稿，读取当前版本 | 不能静默覆盖或自动选择新工具 |
| 网络未知 | 恢复精确原操作 | 稳定body、operation和预期版本按组织／用户／项目隔离 |
| 执行等待输入 | 查看实际来源事实 | 不提供该协议未支持的回复按钮，不释放仍运行进程的槽位 |
| 结果未知 | 核对原进程与候选 | 不因页面刷新创建新attempt或自动resume |
| 无当前权限 | 退出编辑、查看拒绝原因 | 客户端禁用不替代服务端授权 |

普通写入恢复只保留非秘密元数据。执行节点凭证不进入URL、会话存储或恢复对象。工具档案的只读声明属于管理员策略，不能描述成通用操作系统沙箱证明。Token数量来自真实协议字段，不推算成本、完成比例或未报告用量。

## 响应式与可访问性

沿用既有紧凑深浅主题、Radix弹窗、明确中文状态、键盘操作与关闭回焦点。窄屏按单列显示完整任务依据和工具动作；长ID与摘要有界换行，不能撑宽页面。真实浏览器需要验证工具详情返回、任务预览刷新、计划失效、未知回执、无输出等待与终态事实，并保存实际DOM宽度及原图。

组件／模型测试只证明数据表达和恢复规则，不证明布局、浏览器焦点或完整WCAG。本机已另做390/768节点列表、1366/1920依赖图、深浅主题、Enter进入详情、返回列表与Escape回焦点、固定计划刷新和精确需求链接实测；实际资产、原图和范围见[浏览器证据](../quality/evidence/tool-browser-visual.json)。完整四宽度五旅程仍以总验收矩阵为准。
