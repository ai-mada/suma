# 任务列表与看板批量选择

任务列表和看板共用当前视图的选择。用户最多勾选 16 个已加载任务。卡片复选框独立于详情按钮，勾选后用边框、底色和勾选状态共同表达。列表与看板上方使用同一批量操作栏，显示已选数量、分配负责人、调整迭代、安排团队和清除选择。滚动时操作栏停留在顶部导航下方，390px 使用两列触屏按钮。

切换列表／看板、排序、分组或刷新时，界面核对最新加载结果，期间暂缓批量提交。只有当前仍加载且任务版本一致的行保留选择。变更筛选或搜索时直接清除选择，即使某项任务仍恰好匹配新范围。账号、组织、项目和访问变化清除旧范围。清除操作后焦点回到布局切换。

选择保存于当前工作区内存。共享视图只保存查询与显示偏好。详情独立读取的记录不会自动加入选择。负责人、迭代和团队操作沿原合同确认。批量迭代提交还核对独立的排期版本与目标迭代版本。原写入响应未知时仍能找到原操作的核对入口。
