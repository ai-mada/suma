# 统一体验、智能协作与可靠自动化

状态：已接受的全平台增强设计，分阶段实现；2026-10-29。

本设计补充现有领域合同，完整交付范围继续由 `docs/delivery/implementation-plan.md` 管理。页面、智能策略、离线协作和多端设计不代表已经实现；实际证据单独记录。

## 产品原则

项目为中心；简洁专业、逐层展开；按项目策略自动化；Web、桌面、CLI与移动共享领域事实；跨设备离线工作必须使用明确范围、期限与联网接纳合同。

## 视觉与工作区

保留紫色品牌和明暗主题。常规正文14px、辅助12px、长文16px，标题24px／18px；4px间距尺度，桌面控件36px、触屏44px。默认舒适密度。图表都有文字、范围和明细，未知不显示零或成功。

项目首页以真实待处理、交付事实、里程碑和风险为主。需求设计使用章节、正文和依据面板；排期三视图共享草稿。IDE使用紧凑上下文、文件／任务／Git、中间编辑器、可收起讨论与底部执行区，证据按需展开且不重挂载编辑器。

## 智能与自动化

入口引用已有讨论、目标或事件；AI仅形成结构化方案，服务端检查当前授权、来源、预算和固定策略；正式计划沿唯一Go DAG执行。重规划仅调整未开始部分。默认辅助模式，受控执行及自主维护须显式授权。自动修复默认一次、最多三次，同一失败连续两次停止；未知副作用先核对。

## 领域与协作

身份、项目规划、执行、质量交付、知识、能力连接、配额计费、协作通知各自拥有正式状态。原子业务更新与授权、回执和outbox同事务；检索、通知和统计采用投影。结构化业务命令不用CRDT自动合并。

文档使用Yjs协作草稿，正式版本与发布独立。桌面／CLI的离线执行许可默认4小时，可收紧，绑定设备、计划、工具、目录、额度与截止时间；不因重启延长。云模型仍经在线网关。重连重新授权、核对候选并独立测试，不直接验收。离线撤权与缓存删除不能声称即时生效。

## 全量实施分组

1. 公共体验、服务端查询、首页、IDE与排期交互。
2. 稳定验收项、结构化设计、用例库、团队负载、跨项目组合及发布扩展。
3. 智能策略、事件自动化、知识／技能分发、能力连接与成本治理。
4. 多设备同步、离线许可、移动、渠道、SSO、商业连接和分布式验收。

成熟组件按需采用：TanStack Table、Tiptap／Yjs／Hocuspocus、ECharts；既有ReactFlow／ELK、Monaco与领域合同继续复用。不得以组件安装冒充完整能力。

## 验收

每阶段验证当前授权、来源变更、CAS、原操作恢复和相关用户旅程；代表性中英文、键盘、390px与桌面、明暗主题。真实提供方、物理多机、跨数据库、移动真机和生产分别留证。保护既有用户数据和活动预览，构建输出只进入任务忽略目录。
