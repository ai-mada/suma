# 平台说明的显示身份与图交互

状态：T-P4-013 限定范围代码、独立复核和实际本地交互已有验证证据。负责人：控制面、工作台、主集成。需求FND-I18N-001；[冻结合同](../../contracts/platform-display.md)、[实施计划](../delivery/platform-display-plan.md)及最终质量证据共同决定验收。当前页面不表示完整国际化或完整平台通过。实际覆盖与缺口见[专项验证](../quality/platform-display-verification.md)。

## 三类内容的生命周期

| 内容 | 权威来源 | 显示原则 |
|---|---|---|
| 当前工具资格 | 本次授权事务内的凭证、权限、固定档案、库存及时钟 | 可附加受控显示身份；原始reason保持，不将上次资格当成本次派发承诺 |
| 持久执行原因／原始输出 | 具体attempt的Result、Journal、DAG及事件 | 后续按生产者、脱敏及完整原文绑定贯通；不能只按英文句子反向匹配 |
| 系统生成问题／需求 | 系统生成操作及受保护来源记录 | 后续加入普通API不可伪造的逐字段来源，用户编辑撤销身份；不相信可写data.origin |

第三方控件文案由控件自身的官方本地化接口负责。用户标题、代码、目录、外部原因、协议状态、用量与原件保留原语义。翻译只改变解释，不改变许可、状态或验收。

## 工具资格：显示、原文与未知

进入组织设置→执行工具，选择固定配置；配置列表、详情、运行固定工具依据、启用／暂停对话框采用相同显示适配器。正常情况下显示当前语言的资格解释，原始原因在独立原生披露中保留。无hint、未知key／version、参数或规范原文不符、目录尚未到达时直接显示原文，不能吞掉未知原因。目录到达后可重显，原文披露、当前焦点和未提交表单保持。

16类当前资格来自同一Go权威目录。模板、参数种类和完整规范原句仅对批准的display.tool域生成到客户端；不是把全目录原句暴露为通用匹配表。浏览器先证明同对象reason与生成模板完整相符，再用同参数合同的当前目录呈现。外部不可用原因是普通文本参数，不递归执行它包含的键／模板／标签；超过既有Text边界的原文完整保留，只省略无法证明的hint。

GET与新命令响应保留原始Reason；历史回放不重算资格、不更新原响应。严格metadata验证与耐久资源解码分层：不能因为可选hint未知而损坏完整业务回执，也不能把真实业务字段或JSON损坏当成可忽略显示问题。语言切换没有新读取／写入；既有周期库存刷新另计。

“已报告可领取”只表示该次身份、固定程序和库存满足新派发条件。模型登录、工具任务、测试和人工验收分别证明。暂停只阻止后续派发，不能翻译成已停止运行。共享池与项目Runner遵循各自当前凭证和授权，不以显示元数据替代服务端校验。

## React Flow内部语言与真实操作

当前旧版12.4.4缺少内部文案的公开配置，本轮采用官方12.12.0及匹配system0.0.83，通过public ariaLabelConfig配置节点／边键盘说明、移动播报、控制按钮、缩略图和连接点。官方接口说明见[AriaLabelConfig](https://reactflow.dev/api-reference/types/aria-label-config)和[可访问性交互](https://reactflow.dev/learn/advanced-use/accessibility)。版本、安装字节、许可与兼容性以本项目固定包和真实验证为准，官方说明不能替代验收。

自有画布／节点／边名称继续带真实业务标识与状态；库内节点／边role description使用公开domAttributes覆盖。方向及坐标只用于读屏解释，保留实际值。固定12.12.0在调用moveSelectedNodes之前向公开移动播报回调提供坐标，因此文案明确标为“移动前坐标／Starting coordinates”，与当前键盘事件节点的原始ID绑定；不把这些数值当成移动后位置，也不读取私有store或估算步长来改写它们。

自有连接点通过Handle的公开aria-label属性区分“输入连接点（目标）／Input connection (target)”和“输出连接点（来源）／Output connection (source)”，均带同一节点未经翻译的名称与原始ID。连接点与八处已确认同类名称入口共用[封闭静态字面值模块](ui-literal-values.md)：通过i18next公开getResource取得当前语言的批准模板，验证精确参数合同，再以一次replace回调只替换模板自身的占位；不会再次扫描插入值。名称或ID中的变量标记、$t嵌套语法、替换元字符、引号及HTML样式文字均逐字保留为数据，不进入翻译／嵌套执行或HTML解析，也不改变全局i18n配置。该模块不接受display.tool域或任意后端键，工具资格仍独立核验完整来源。语言或资源恢复只改解释，保留Handle元素、草稿、布局、选择与焦点；全局官方handle文案继续作为通用fallback。可见按钮title与辅助名称同时切换，React Flow署名及许可保留。

编辑图保留Enter／Space选择、方向键移动和Escape取消；执行图遵守原只读约束。键盘说明必须与实际模式相符，不能宣称执行图可以删除或移动。更换语言不重挂画布、不自动布局、不清空选择、viewport、脏草稿或焦点。390窄屏如果使用节点列表，应验证列表完整操作，并明确未展示图内部控件，不能把不可见控件计为通过。

## 验收方法与保留限制

单元和真实组件测试分别覆盖source proof、未知／坏参数、外部文本、原文披露、目录迟到、对话框、零额外请求及真实ReactFlow DOM。库内文字验收不能把ReactFlow／Controls mock为空；jsdom布局补齐不等于真实浏览器或读屏软件验收。

最终需独立服务核对工具paused→enabled→fresh→paused，以及可选真实60秒库存过期，不改数据库时间；不得启动模型任务伪造成功。实际浏览器按中英文、主题和四宽度核对title、ARIA、describedby、live announcement、键盘、原始原因、草稿和精确历史选择。数据库、原件、旧回执和执行计数分别对比。

持久NodeRun／Runner原因、系统生成业务记录、Monaco菜单与各语言服务、CLI／安装器／通知／导出／渠道及完整P0–P7仍需实现和逐项验收。当前凭证统一守卫及SSO方案亦继续核验，不用本轮显示功能代替权限基础或生产就绪结论。
