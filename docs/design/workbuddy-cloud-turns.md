# 原云任务继续协作：交互规格

状态：T-WORKBUDDY-CLOUD-TURNS-169限定实现，实际交互与视口覆盖见[阶段证据](../quality/workbuddy-cloud-turns-verification.md)；suma 1.0.0；2026-10-31；负责人：工作台／主集成。关联[合同](../../contracts/workbuddy-cloud-turns.md)、[架构与AI SOP](../architecture/workbuddy-cloud-turns.md)。

原云任务已知时，在原节点工作区提供默认收起的“继续协作”。它与历史加载并列：历史仍是原快照，本模块发送本人明确的新输入。只需一个输入框和一个发送动作，原任务、账号、范围和来源自动绑定；模型由供应方管理，用量未核实的说明放在简短事实区。

展开后呈现当前回合、真实回复和本地保存状态。原始目标不自动回填或重送；新的输入提交前保留原正文及操作key，响应未知时显示“核对原操作”，不能给一个会悄悄换key的重试按钮。刷新与关闭后重新展开读取原Turn及游标，不重新Attach。

| 状态 | 内容与操作 |
|---|---|
| 无本人协作权限 | 只清本模块的受保护正文；原公开节点按自身权限继续显示 |
| 可发送 | 一个目标输入框、明确发送；无额外RPC、模型、预算表单 |
| 已准备／运行中 | 说明原意图已保存／正在收集，不能把202当远端已采用 |
| 等待权限 | 显示准确工具标题、完整安全细节和原选项；仅本次允许／拒绝，无法完整展示时禁止允许 |
| 请求取消 | 说明已请求和当前确认事实；不能显示远端任务已停 |
| 本回合结束 | 显示真实stop reason与保存回复；原任务仍走代码交付及独立质量门禁 |
| 结果未知／租约失联 | 保留原回合，明确核对与部分内容；不开放新Prompt来覆盖原效果 |
| 来源变化／撤权 | 旧内容立即清除，禁止旧响应重新填入；私有拒绝与整个项目拒绝分开 |

权限和取消按钮用原对象身份与版本，不能把多个回合的权限卡混放。默认只显示当前回合；工具／来源／计量等细节按需展开。长回复有界分页，保持用户滚动位置，窄屏单列不横向撑宽；已知时间明确本地格式，未知供应方时间不伪造。

复用现有设计令牌、Dialog／Disclosure、按钮、通知、焦点和写操作journal。中英文状态和动作完全对等；新增语言沿同一namespace扩展。键盘可发送、读取、选择原权限选项、取消及关闭；减少动效遵循全局设置。最终以代表视口与真实接口旅程记录实际覆盖，不以设计图宣称供应方或完整设备矩阵通过。
