# 本机工具发现交互设计

阶段：T-TOOL-DISCOVERY-202；suma 1.0.0；负责人：主集成代理。状态：代表组件界面限定验证完成，见[验证报告](../quality/local-tools-discovery-experience-verification.md)。关联[PRD](../product/local-tools-discovery-experience.md)、[架构](../architecture/local-tools-discovery-experience.md)、[合同](../../contracts/local-tools-discovery-experience.md)与[英文说明](../en/local-tools-discovery-experience.md)。

## 页面层级

保持原“连接工具”页面、工具选择及后续配置，不新增面板中心。扫描区按“标题与重新检查 → 安装观察数量 → 主列表 → 其他工具折叠区 → 事实边界及观察时间”排列。先让用户找到本机已发现或需要处理的工具，高级依据按需展开。

主列表包含全部已发现、异常和当前选中条目。每行先显示产品、安装观察和准确原因，再提供原配置/指南/已有连接动作；协议、版本和原因码可在原检测依据中查看。不要依赖颜色或图标区分 CLI 与 SDK，也不把同产品不同协议合并。

“其他工具”使用原生 `details/summary`，默认关闭，仅容纳未安装且未选中的普通 `not_installed` 行。摘要标明数量，不暗示这些项不可支持或已被删除。展开后使用相同条目结构和动作，不复制第二套配置表单。没有唯一合法适配描述符时仅展示事实。

## 状态与操作

| 状态 | 界面要求 |
| --- | --- |
| 加载/忙碌 | 保留原状态与禁用规则；不重复扫描，不制造安装进度 |
| 主列表为空 | 解释尚无主列表项目；提供调用者已有的节点接入入口，不声称无可用平台工具 |
| 当前选择未安装 | 行仍在主列表，选择样式与 `aria-pressed`明确；配置沿原入口继续 |
| 过期/缓存 | 按原观察时间表述；不能把历史安装记录称为当前连接健康 |
| 扫描失败 | 显示原错误/重试出口，不把失败显示为零安装或隐式强检 |
| 无桌面桥接 | 继续原浏览器提示和节点入口，不模拟本机扫描 |
| 作用域变化 | 重置展开和旧响应归属，不复活前一个身份或项目结果 |

展开、收起和选择是展示/选择动作，不连接、不安装、不发送额外 HTTP。明确重新检查才触发原 force 扫描。当前行跨组后，仅在触发选择的原按钮仍持有焦点或因该行重挂载失去焦点时恢复它；外部选择、用户已移走的焦点不被夺回。

安装数量和待处理数量使用本地化数字格式。安装、SDK资产、模型认证、节点连接、正式登记、启用、测试及验收分别表达；Claude SDK版本不符时使用其既有专用提示，不用通用“未安装”覆盖。

## 中英文、键盘与窄屏

使用既有 `local-tools-scan` zh-CN/en-US目录成对维护，英文长度变化不靠截断处理。建议语义为“其他工具（数量） / Other tools (count)”、“已发现安装 / Installations detected”和“需要处理 / Needs attention”；实际词条由界面目录统一，数量始终表示观察事实。

原生摘要支持 Tab 聚焦和 Enter/Space展开，无需自制键盘树。摘要内不嵌套独立操作按钮；扫描及原配置动作各自提供至少44px触达、可见焦点和准确可访问名称。装饰图标对辅助技术隐藏，状态信息保留文字。结果更新可沿原状态区域播报，不重复朗读每个折叠行。

390px使用单列，操作可换行，长名称、协议和摘要不造成页面横向溢出；1366px保持紧凑阅读顺序。长标识保留完整可读/可选择内容，不能因省略号掩盖协议差异。折叠无需动画；减少动效设置下不强制滚动或播放过渡。展开和新结果不主动跳转视口。

## 设计验收清单

以下检查已在本阶段限定范围内完成；中文1366浅色与英文390深色由实际渲染组件及合成扫描数据验证，完整矩阵独立推进：

- 混合安装/异常/选择正确分组，主列表空态和其他工具完整可达。
- 原按钮、协议和版本提示保留，展开/选择不产生新的扫描或写入。
- 键盘展开、选择跨组焦点保持及外部选择不抢焦点。
- 作用域切换、迟到响应、过期、失败、busy与无桥接状态保持准确。
- 中英文390/1366代表布局无溢出，触达与焦点清晰。

采用受影响组件与代表界面验证，不重复未变更的后端、官方SDK或厂商模型检查；真实 Electron、完整设备/主题和跨平台安装仍是后续独立验收范围。
