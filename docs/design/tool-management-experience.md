# 工具管理：简洁首屏与准确接入

状态：实施中；版本：1.0.0；负责人：主集成代理／Web代理；需求：T-TOOL-MANAGEMENT-EXPERIENCE-206。

## 使用目标

进入“工具管理 → 执行工具”即可看见现有配置、当前读取状态和“添加工具”。主操作继续打开原快捷接入，不另建表单或派发器。高级登记保留在次级入口。配置的安装观察、当前库存、启用状态和可派发资格仍分别展示；缺失依据显示未知。

首屏依次为简短说明与添加操作、紧凑的下一步建议、必须处理的回执／异常、配置列表及筛选。执行节点、共享节点、原云账号授权和更多接入方式随后出现。云账号组件保留原独立折叠和挂载生命周期，不包在新折叠祖先内。更多区域容纳适配目录和完整指南，默认收起，首次主动展开后持续挂载以保留草稿；按需展示降低初次使用的信息负担。DOM顺序与视觉、键盘顺序一致，不采用纯CSS换序。

## 交互与不变量

- 添加工具调用原 `openQuickConnect`；高级登记调用原 `openRegister`，沿当前节点、原草稿和未知写入保护。窄屏选择详情后，添加入口仍在列表隐藏容器之外可达。
- 指南、厂商、客户端、Harness和云授权入口先展开正确区域，再定位准确内容。主动从弹窗转到指南时，关闭弹窗的默认焦点恢复不能把用户带回原按钮。关闭普通弹窗仍保留原恢复行为。
- 操作不确定、当前权限／来源失效、读取错误、过滤空态、首次空态与普通成功分别保留。折叠不能隐藏必须恢复的原操作，也不能自动重放它。
- 检测和维护继续显式触发；本阶段不增加后台扫描、自动安装、自动启用或模型调用。修复建议和明确授权后的执行保持分离。
- 使用原React、Radix、i18next和设计令牌；不增加依赖。控件可键盘操作，触达高度44px；390px单列无页面横向溢出，深浅主题沿原令牌。
- 中文／英文目录同键，未来语言沿原目录扩展。文案、数量和状态均来自当前数据，不用静态演示指标冒充实际健康。

## 验收与证据范围

重点验证首屏主入口、列表顺序、过滤、准确指南展开及焦点交接、窄屏详情下的入口、未知写入保护。复用未改动的Runner、服务端和ToolReadiness验证，不重复探测供应方或调用模型。

整页浏览器验证使用生产ToolWorkspace组件和明确标注的本地合成HTTP数据，选择中文1366px浅色及英文390px深色。它验证界面和原回调连接，不代表真实账号、厂商、任务执行或生产验收。结果进入[限定验证](../quality/tool-management-experience-verification.md)。完整31项／P0–P7目标继续，58限定／34待办／92总项不变。
