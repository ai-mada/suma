# 工具恢复导航与操作层级

版本1.0.0；T-TOOL-RECOVERY-NAVIGATION-217；负责人：工作台／主集成；依据[合同](../../contracts/tool-recovery-navigation.md)。

工具详情先展示当前名称、状态和原action-bar；原Doctor及历史置后。原操作确认、权限、expected_version及ToolWriteRecovery保持原权威，重排不触发写入。目标节点卡只展示与当前公开来源相符的明确连接准备操作，复用现有44px按钮、焦点定位和响应式换行，不增加常驻仪表盘或多层弹窗。

恢复意图复用当前connectDraft／publicDraft／sourceTool与原代次；它只保存公开选择，不保存凭据、私有路径或健康事实。Doctor父闭包捕获当前准确profile，再定位其普通Worker。请求返回须同时满足当前caller、scope、profile ID／版本／SHA、Worker及代次；ABA和迟到响应不能打开旧指南。

准备动作使用原只读diagnostics和adapter目录，原检查／核对未闭合时优先原inspectProfile定位。正式工具目录应准确匹配同adapter／protocol且唯一；只支持原toolPreparationTarget的九种组合。共享Pool保持其原所有者授权流程；身份撤销／到期不得自动复活。

沿原beginPublicDraft保留准确旧配置来源和公开名称／command，openToolPreparation传准确Worker及原同目标保留标识。另一节点的批准信息不进入该机器命令。新报告返回保留原baseline、TTL、当前Guide及nonce约束，额外核对指南保存的expectedWorkerID，不能让报告自己定义期望目标。回Quick后仍重读当前配置与原matches，再明确选择复用、登记或换新。

界面保持中英文完整；状态及失败解释直接说明下一步。对原未确认写入、读取失败、撤权、共享节点和不支持的协议不虚构成功或无影响。只检查新增交接及受影响操作位置，原后端检测／配对／配置／执行算法复用已有有效证据。

指南内明确换选另一工具属于新的接入意图：原Guide按当前localTool和navigation代次核验报告，返回新Quick时清除旧配置换新来源，不把旧source移交给另一工具。未明确选择的迟到跨工具报告仍不得采用；不能仅用报告自己的adapter作为当前来源证明。
