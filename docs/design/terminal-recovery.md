# 终端中断恢复与修改交付交互

状态：T-TERMINAL-130；1.0.0。沿用[终端交互](interactive-terminal.md)的默认收起入口、xterm、紧凑组件、中英文目录与浅深主题。本文描述界面合同；实际执行和浏览器验收由对应质量报告记录。

终端启动授权、原执行恢复、修改交付预览、启动检查与封存、独立测试和人工验收分别保留。不会把未知输入、终端输出或进程退出转写为成功、测试通过或任务验收。

## 原执行恢复

原会话下提供“核对中断的执行 / Review interrupted execution”。处于需要核对的会话默认展开；其他会话由用户按需读取。读取只核对原运行、尝试、栅栏、派发身份与已持久化进程树停止事实。

没有停止证明时只说明等待原执行节点回报，不允许人工勾选来制造停止证明。服务端允许恢复后，每一项交付未知输入分别展示序号、原输入身份和摘要；不展示、存储或重放其原字节。逐项勾选明确接受交付仍未知，不能改为已交付。编辑核对说明、读取新依据或改变未知输入选择后，最终关闭确认失效。

用户填写核对说明并单独确认“按失败关闭原执行”。请求绑定原会话版本、运行版本和完整原执行身份，只能关闭原失败执行。成功反馈仍保留未知输入，说明未重放。网络未知时冻结原请求与操作身份，提供“核对原控制请求”，不能通过另起 Shell 绕过。

## 修改交付

原会话下另设默认收起的“将终端修改交给质量流程 / Send terminal changes to quality checks”。读取真实停止证明；会话未结束或仍需核对时禁止新建预览，并指向上方恢复入口。

展开时从原会话读取最多20项当前授权的既有交付计划；浏览器没有本地定位记录时，只有一项则自动选中读取，多项由用户选择。读取与选择不会创建预览或重新执行。已有已启动计划即使原任务当前运行或验收依据改变仍展示原运行事实与当前原因；停止证明和新建资格只约束新预览。新预览使用独立选项，不以历史读取失败或未找到本地记录为理由自动创建。

选择项来自真实已发布流程和分页执行配置。当前受控切片只提供一个固定命令检查节点和一个读取该候选的独立测试节点。检查配置必须启用、当前可用、可写、为普通 command/text-v1、属于原终端执行节点，并与流程命令完全相同。独立测试的另一执行节点与固定绑定由服务端核验。目录说明已加载范围，支持显式加载更多，不根据缺失选项推断全项目不存在配置。

第一次确认只授权读取停止时的固定修改来源并创建预览，不启动检查或修改任务运行。预览展示原终端运行、原执行节点、基线提交、停止快照摘要、固定任务标准与检查流程。不可变原工作树身份由服务端解析，界面不提供任意目录、提交或脚本输入。

第二次确认才授权启动原固定预览，执行检查、封存与另一执行节点的同提交独立测试。启动后提供原检查运行及任务验收入口；验收、问题回流和后续任务使用已有任务交付链路。启动回执未知时恢复同一原操作，不另建预览或重复启动。

## 已验收基线交接

已启动计划下提供默认收起的“交接已验收基线 / Hand off accepted baseline”。按需读取原任务当前交付摘要与原候选运行，要求正式验收仍有效、运行身份精确匹配、独立测试成功，并显示此运行的真实候选提交。任务未验收、已换运行、测试缺失或事实读取失败均不开放交接表单。

用户从分页真实任务中选择另一未启动任务，再读取目标最新版本和当前基线。理由、明确确认和原候选计划版本绑定同一请求；沿既有任务代码基线命令提交，不创建新业务来源或调度器。绑定只允许 composition 来源对或 terminal_candidate_plan 来源对中的一组，不能混用。成功后展示目标当前基线回读和任务入口，明确后续执行尚未启动；网络未知仍恢复原目标及原操作身份。

## 状态、权限与布局

恢复与候选操作复用既有持久写恢复组件，身份范围含账户、组织、项目、任务、会话。进行中或结果未知时锁定其他会话切换与控制；权限失效立即隐藏受保护事实。版本冲突保留草稿，用户明确读取新依据后重新确认。

两块区域复用原终端边框、语义色、字段、错误提示与可见焦点。按钮具有中英文文本和展开状态；错误及未知交付通过 alert/status 表达。窄屏字段单列，长摘要和身份折行，未知输入清单在自身区域滚动，不让整页横向溢出。没有新的全局导航、外部设计服务或依赖。

完整多控制者、Unix停止证明、物理多机、容器隔离和完整IDE能力继续按平台待办交付；本入口不缩减这些范围。
