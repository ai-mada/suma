# 技能修订比较

T-SKILL-COMPARE-157。用户在共享技能详情中展开“比较修订”，默认以前一个已读版本对照当前版本；版本选择器同时标出目录版本和源修订。每侧显示准确的源SHA，正文按只读差异呈现。历史分页按需加载，折叠后不保留编辑器模型。

默认详情及原有历史浏览不变。比较区域避免增加第二套审批：“采用当前版本”只打开现有原因、草稿确认表单；仅当前有效、服务端允许的版本显示此入口。比较两份历史仅可读取。源变化、退役或撤权不会借比较重新授予资格。

有界状态：收起；读取／重新核对；两个不同修订；仅一个版本；比较器载入；读取或编辑器失败；权限失效。核对中及失败时隐藏比较正文。失败使用现有错误提示与重试；编辑器不可用时提供纯文本对照。窄屏选择器上下排列，Monaco内联显示差异，纯文本对照上下排列；焦点、标签及状态信息保持中英完整。

实现边界：新独立比较组件和模型、本地按需Monaco模块、独立双语domain；仅挂载SkillCatalogWorkspace，不修改App、TaskCollection、Prefs或共享生成物。复用正式历史与采纳接口，不增加依赖。验证先聚焦scope／分页／当前资格／原采纳恢复，再由集成方补真实本地HTTP/GUI与构建，范围分别记录。
