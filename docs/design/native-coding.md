# 原生编码记录交互规范

状态：T-P4-020 已实现并完成代表性交互验证。Owner：工作台与国际化；集成及验收由Root负责。本文描述现有组件及限定范围的交互，完整体验矩阵与生产验收分别记录。产品范围见[PRD](../product/native-coding.md)，权限、工具与封存规则以[实现合同](../../contracts/native-coding.md)为准，真实结果见[阶段验证](../quality/native-coding-verification.md)。

## 信息优先级

沿用既有工作树事实区域，嵌入单段“原生开发记录”，不新增页面、菜单或密集表格。默认依次显示：当前状态、涉及文件数、已报告开发检查的当前成功快照数量、正式测试与验收边界。操作ID、策略／文件／检查SHA及封存依据放入默认折叠的原生披露。

工具档案的 `workspace_tools_version=attempt-workspace-v1` 只显示能力声明，不能当作真实开发记录、当前可用性或运行成功。只有收到当前工作树的 `native_workspace` 才展示记录；旧模式未携带该字段时不显示空卡片或补造数据。

## 六种状态与未知优先

| 状态 | 展示语义 |
|---|---|
| 工作区开放 | 仍在开发，不能推断终态或候选已产生 |
| 尚未封存 | 没有正式封存记录，与没有开发检查分别表达 |
| 已准备封存 | 已有准备记录，最终效果尚未确认 |
| 本地候选已封存 | 只说明当前依据绑定的本地候选，不表示合并、测试或验收 |
| 源码无净变更 | 明确记录零净变更；不造新提交，也不等同未发生过编辑 |
| 效果需要核对 | 未知效果优先，不能继续以旧成功快照表达当前成功 |

根记录或封存状态为unknown、任一检查结果未知时，核对提示优先于其他状态和成功汇总。根记录unknown时，展开区也不再称旧检查是“当前已知成功”。

“依据不完整”是独立显示缺口，不是新的执行状态。未知版本、非法类型／枚举、非安全整数、坏摘要或未声明字段不能渲染为事实。封存策略SHA须与根记录一致；只有记录closed、封存commit精确匹配外层head、tree有效且所报告检查均为当前已知成功，才可显示封存或无净变更。外层head缺失或失配时保持缺口，不从原始seal状态推断成功。空检查列表只说明未记录检查。

## 当前检查与原始依据

成功快照必须同时满足：检查generation等于当前内容代次、退出码为0、未停止且结果不未知。旧代次、非零退出、已停止和未知分别解释；统计仅覆盖收到的记录，不声称所有配置检查均已执行。开发检查始终标明不等于独立DAG测试，候选提交不表示已合并或已验收。

“查看原始开发依据”默认关闭，逐字段呈现路径、操作ID、代次、SHA、退出／停止事实及原封存记录，不输出任意对象JSON。检查输出另设原生披露，只有用户明确展开才挂载原文；使用React文本，不解析标签或模板。空输出的说明置于原文之外，生产者的截断标记明确保留。超过32KiB或格式无效时显示依据缺口，不截断后冒充完整输出。

## 中英文与扩展语言

现有42对词条位于 `native-workspace.zh-CN.json`／`native-workspace.en-US.json`，由领域目录统一装配，复用[国际化规范](internationalization.md)。数量通过当前语言格式化，说明与辅助名称即时切换；路径、ID、操作标识、SHA、协议状态、退出事实及用户／工具原文保持原值，不递归翻译或重新解释。

新增语言先扩展统一BCP 47注册、协商及回退，再补齐相同稳定key与参数合同，不在组件增加逐语言分支。目录、占位符、长文案和原值保留须分别检查，不能仅新增选择器即宣布完成。语言变化不读取接口、不重跑检查；同一记录的展开状态、原文及焦点保持，切换到另一记录时重置披露，避免把旧展开位置套到新事实。

## 390窄屏、键盘与动效

复用现有浅／深主题令牌与工作树样式，小于600px时摘要和事实转为单列；390px下长路径／摘要换行，输出只在自身区域滚动。披露摘要保留44px操作高度，使用原生details／summary与可见焦点；Tab按文档顺序移动，Enter／Space控制披露，可聚焦原文支持键盘滚动。无自动聚焦或新增动画，沿用全局减少动效规则。

实现对应[组件](../../apps/web/src/NativeWorkspaceFacts.tsx)、[样式](../../apps/web/src/NativeWorkspaceFacts.css)及 `WorkspaceEvidence.tsx` 插入点。组件检查不能替代浏览器、读屏或正式验收；390px、真实键盘、主题及纵向证据以Root后续记录为准。架构与AI SOP复用[原生编码指南](../agents/native-coding.md)。
