# 文件编辑与Git审阅交互

状态：T-P4-035／1.0.0。负责人：工作台。关联：[产品](../product/workspace-git.md)、[合同](../../contracts/workspace-git.md)、[验证](../quality/workspace-git-verification.md)。

左栏只有“文件／变更”两个标签，复用已有设计令牌、图标及按钮；无新顶层导航。文件视图保留编辑器、脏标记和保存／原操作恢复。变更视图保持相同布局，在左栏列出真实文件状态及分支，右侧以成熟Monaco只读比较呈现准确原文和修改后内容。宽度不足时使用内联差异；不为追求双栏而压缩代码。

工作树和暂存区是明确的比较范围按钮。状态字母保留Git习惯，鼠标提示与屏幕阅读说明跟随中英文；原始文件名、分支、HEAD、代码与摘要保持原值。重命名来源单独展示；已删除文件仍能比较，但确定不存在时不能“打开编辑器”。

显示观测时间、载入数量、受限文件数量和只读边界；默认折叠细节，避免技术字段占满页面。未保存草稿与磁盘Git观察明确区分。切换时保留同一编辑模型和草稿；刷新保留仍有效选择及列表／差异位置，旧读取清空时不把已保存滚动位置覆盖为零。

| 状态 | 处理 |
| --- | --- |
| 正在读取 | 隐藏旧比较，显示加载状态，当前请求可取消 |
| 无变更／无仓库／无Git | 显示对应空态，不伪造分支或成功状态 |
| 不安全配置／未授权共同仓库 | 明确受限原因，保留正常项目导航，不关闭保护 |
| 冲突／二进制／读取过大 | 提供对应说明，不把缺少原文显示成空文件 |
| 元数据或绑定变化 | 409提示手动刷新，不能自动套用新基础 |
| 身份或权限失效 | 立即移除旧路径及代码，取消读取，迟到结果不能恢复旧内容 |
| 服务未启用本地工作区 | 依据已有`binding_available=false`显示部署管理员配置说明，隐藏无效绑定表单与误导权限原因 |

Monaco使用原生Ctrl/Cmd+S动作，读取最新保存状态；不依赖可能被编辑器停止冒泡的页面事件。左栏标签支持方向键、Home／End及正确焦点。现有深浅主题继续复用，完整主题／设备矩阵仍按发布验收计划进行；平台文件操作为中英文，内置编辑菜单／语言诊断的英文限制明确保留。
