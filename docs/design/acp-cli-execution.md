# ACP 工具接入与一次权限交互

T-ACP-RUNTIME-170；suma 1.0.0；负责人：工作台／主集成；2026-10-31。状态：实现集成，实际覆盖以专项证据为准。关联[合同](../../contracts/acp-cli-execution.md)与[架构](../architecture/acp-cli-execution.md)。

工具管理沿原快速接入：选择Qoder ACP入口 → 配置本机原生程序、明确版本及模型 → 原Runner探测 → 暂停登记 → 真人复核启用。账号、真实模型、协议、执行资格分别展示；环境引用只填变量名，不收集密钥值。复杂JSON默认收起，提供可编辑模板和明确复制结果；原生包装器不适用时显示原因。

任务派发只显示原工具固定模型、配置确认和观察用量说明，不呈现无实际控制能力的模型网关预算表单。预览及Start绑定当前工具／流程／需求／任务版本，已变化时保留草稿并引导重新预览。

运行节点内提供默认收起的一次权限卡，请求绑定原session／tool_call，界面展示工具标题、tool_call、安全细节和原选项名称；session可在原事实来源中查看。`allow_once`及`reject_once`具有准确原ID；always不可执行，细节不完整时允许按钮禁用。状态用短句区分等待决定、决定已保存、来源失效及结果未知；原运行仍可查看日志、代码候选与独立测试。

未知写入保留原正文、key和来源，明确操作恢复原请求；GET或切换视图不会自动确认写入。当前账号／组织切换、撤权或迟到响应不能恢复旧受保护内容；跨attempt历史定位只读取原记录，不能把旧批准移给当前执行。

模型事实显示“请求配置／协议确认／供应方身份未核实”，使用真实presence呈现partial／unreported。运行完成后保留停止与权限记录，不把候选、独立测试或正式验收合为一个成功标记。

中英文共用可扩展namespace；键盘聚焦、表单标签、复制反馈、加载／无请求／断线／无权／冲突态一致。窄屏单列，长原选项和安全详情可换行。刷新按当前可见活动状态有界串行读取；组件卸载、标签页隐藏、终态或失败后停止。折叠面板保留有界读取以更新请求数量；轮询不产生新执行。
