# 终端与讨论开发交接：交互规范

状态：T129当前限定界面；1.0.0，2026-10-29。关联[架构](../architecture/interactive-terminal.md)、[开发与AI SOP](../development/interactive-development.md)及[验证报告](../quality/interactive-development-verification.md)。实际界面结果按报告记录，不把规格当作视觉验收。

## 信息层级

IDE保留文件、任务上下文和原保存CAS。终端在来源区底部，默认收起；用户展开并选定／创建会话后才加载xterm。折叠不停止Shell，当前编辑器路径不成为Shell工作目录。

```text
任务上下文／讨论
编辑器：本地或远程来源
交互终端（默认收起）
  最近会话 · 刷新 · 新建
  原进程状态          连接状态
  原字节输出／输入
  断开查看 · 明确停止
  原运行／目录／机器／到期（详情）
```

列表明确最近20项，Profile另有覆盖标记，不伪造完整总量。创建需要准确任务、当前可用终端配置、时限和明确Shell授权，不提供自由命令／目录输入框。

## 状态与反馈

| 事实 | 界面要求 |
| --- | --- |
| 未选任务 | 提示选择任务，不创建Shell。 |
| queued／running | 等待Runner／Shell运行与连接状态分开展示。 |
| 输入accepted／delivered | 分别说明接收与交给PTY，均不称命令完成。 |
| 输入未知／被拒 | 暂停新输入，说明没有重放；核对后继续仍受服务端允许动作约束。 |
| 输出gap | 持续说明历史不完整，原字节由xterm解析，不用HTML渲染。 |
| 断开／折叠／刷新 | 重连原会话，不自动起新Shell；未知控制沿原key恢复。 |
| stop_requested | 等待真实进程树停止／自然退出／未知结果。 |
| 权限失效 | 隐藏受保护输出，禁用新输入；保留原控制身份，不切换项目恢复。 |

xterm异步解析完成后才ACK原序号。成熟FitAddon负责实际尺寸；输出和前端计时不制造成功状态。Shell原始程序输出不擅自翻译。

## 从讨论转开发

入口位于准确已完成回复旁，默认收起，不增加全局导航。审阅文本、开发说明和补充检查后，选择发布流程／原生智能体及新模型预算，先创建原派发预览，再单独明确启动。

正式任务标准、测试计划与补充说明独立；旧回复预算不继承，用户文字不自动变成Shell输入。详情展示reply出处、固定计划及原运行链接，未知结果核对原请求。

## 响应式与可访问性

复用深浅主题和设计令牌；终端用等宽字体，不新增装饰性指标。390宽度单列，按钮自然换行，长ID／目录在详情折行，终端按实际列数适配，不使整页横向溢出。

展开按钮使用aria-expanded／aria-controls；终端输入有中英文可访问名称，连接与未知输入分别用status／alert。保留可见焦点、键盘选择、减少动效及屏幕阅读支持。切换语言不重起Shell或清空原会话缓冲。

当前创建者固定epoch1，不宣称多人控制接管、完整会话历史、WebSocket或三系统实际体验已完成。完整工作台目标仍保留。
