# 共享执行资源池交互规范

状态：T-P4-006界面与自动化已实现；真实API／Runner及部分响应式旅程见[阶段验收](../quality/execution-pool-verification.md)，完整体验矩阵未完成。日期：2026-10-24。负责人：UI代理。接口依据：[池合同](../../contracts/execution-pools.md)、[内核合同](../../contracts/execution-pool-core.md)。沿用批准的本地紧凑工作台与设计令牌，不向外部设计服务传输项目。

## 信息架构

组织级“共享资源池”独立于当前项目，可在空组织直接进入。池列表 → 池详情（概览、项目授权、执行节点、策略）复用同一详情区域。项目级“执行资源”只展示当前项目申请、批准范围与固定默认路由。团队归属、人的项目授权与机器执行授权分别管理。

组织入口使用 `view=settings&sub=execution-pools&record=pool-id&panel=overview|grants|runners|policy:preview-id`；项目入口使用 `project=p&view=settings&sub=project-execution&panel=route:preview-id`。精确选择、刷新和返回保留URL；切组织隔离请求与状态。浏览器原生修饰键行为保留，普通点击走App统一导航。

## 核心流程

1. 拥有组织创建池，明确配置槽位与累计准入额度；配置不是硬件测量。项目方输入明确池ID与项目权重发起申请，提交前展示将共享的项目名称快照、组织与项目标识，说明不授予需求、代码或日志读取权限。
2. 池拥有方在授权收件箱审阅固定共享名称、请求摘要、版本与权重，显式批准或拒绝。各方只管理服务端 allowed_actions 所列动作。没有业务读取权限的项目不显示可下钻假链接。
3. 登记执行节点仅填写名称、1–128槽位及1小时–30天凭证有效期，worker标识由服务端生成。首次返回的秘密只在当前内存弹窗显示一次，不进入URL、日志或浏览器持久存储；关闭后不能再次查看。
4. 连接中断先恢复原请求与操作标识，不新建同名身份。重放仅返回登记元数据时明确“凭证无法再次取回”，由用户明确轮换；禁止自动轮换或自动启动Runner。轮换／撤销保留当前版本及影响说明，不将凭证撤销称为进程已停止。
5. 策略和项目路由在固定预览后单独确认。改变默认路由只影响未来运行；已开始、子流程及补偿使用原固定路由。暂停池停止新派发，运行中按合同排空；取消和实际停止仍看独立回执。

## 真实事实与密度

顶端紧凑呈现配置槽位、累计额度／已用、版本和读取时间；资源账本默认折叠。没有测量值不显示CPU/GPU使用率；没有在线资格DTO不把登记active或最近联络称为在线可执行。未知保留未知，0与null无限分开。

公平方式和权重来自服务端：份额单位为成功准入次数，不是CPU时长、token或金额。未匹配能力、授权、资源不足和空领取不扣份额；不计算排位、完成百分比或ETA。当前条件与历史attempt分别显示，原始原因放可展开的诊断依据。无业务可见性时只显示被授权共享的元数据和聚合占用。

## 组件、状态与无障碍

独立 execution-pools 领域模块复用现有Radix Modal、Field、ErrorNotice、设计令牌与幂等写入/范围隔离模式，不继续扩大App业务实现。加载显示明确范围；空态提供有权动作；失败保留上次事实但禁用未核实管理；403不猜测旧操作未生效；冲突需重读再审阅；未知结果保留原完整非秘密请求。

390宽度使用完整单列列表与纵向表单，长标识换行；资源表可展开，不依赖画布或横向裁切。Tab与原生按钮/链接可完成全部步骤，弹窗Escape返回发起控件，确认后状态可朗读。自动刷新不覆盖草稿、不移动焦点，不悄悄重排已加载列表。secret弹窗关闭即清内存，未知请求恢复入口放在当前可操作弹窗内，避免被背景inert遮住。

## 验证范围

先运行真正ReactDOM消费者RED，再实现GREEN，包含空组织入口、服务端无权、固定申请审批、一次秘密、丢回执恢复、项目共享说明和失败管理禁用。合成HTTP消费者不代表真实共享调度或机器认证通过。双项目实际执行、分层权重、公平性、失联占用、四宽度及键盘流程由集成验收单列。原始过程仅留本地 `.cache/e2e/pool-stage/`，阶段Git仅包含必要源码、配置与精简文档。

组织池顶栏显示当前组织，不显示“尚未选择项目”的误导上下文。项目申请只固定服务端名称快照，拥有方不能改写项目权重扩大范围；组织权重在池策略中明确配置。节点优先级0–9仅影响同一被选运行内的排序，最多540秒优势，不改变组织／项目份额。

新预览取得精确GET后聚焦审阅区域一次；同ID重读不抢焦点，深链刷新不夺焦。确认期间同一按钮以aria-disabled和处理器防重复，收到成功回执后原DOM变为唯一Continue动作，不再提交；显式继续回首个表单控件。后台读取不覆盖草稿；版本变动先显示当前事实，再由用户明确重基。

运行详情使用保存的池／路由／授权版本；历史缺字段不补造。当前共享池资源只展示本节点请求范围的汇总，保持未知／零／不限制与process／cumulative事实分离。预览的active_attempts包括running与reconciling，文案为“执行或待核对尝试”，不能称全部机器进程正在运行。

自动化消费者覆盖主流程、服务端只读动作、损坏恢复记录、未知注册和策略提交、一次秘密、切组织迟到秘密隔离、真实App创建后导航、预览路由接线、草稿保护、过期／失效原因、Continue焦点、真实工作流优先级及固定run路由。HTTP使用合成响应，布局与实际执行结论由主集成另验；原始RED、类型失败及每次GREEN均留本地，不覆盖历史切面。


## 双语交互与固定任务路由

本阶段池领域全部界面标签、完整动态句、表单校验、加载／失败／无权／未知结果恢复、一次秘密说明和可访问名称纳入统一中英文目录。主壳及登录页提供本机语言选择，Radix弹窗内部也提供同一入口，避免背景inert使切换不可达。切换仅更新展示，不改变组件范围key、用户命名、输入、焦点、固定请求或幂等标识；账户跨设备／组织默认偏好尚未持久化，不宣称已保存。

工具建档可从当前项目普通登记身份与获准共享池身份中明确选择。后者只读、独立加载并显式显示失败和读取时间，不进入普通凭证撤销列表，active只说明登记有效。派发预览显示保存的执行路由、池和授权版本；旧预览没有依据时显示未记录，绝不补入今天的项目默认路由。

实现入口为[语言基础](../../apps/web/src/i18n/index.ts)、[语言控件](../../apps/web/src/i18n/LanguageSelector.tsx)、[共享身份选择](../../apps/web/src/execution-pools/ToolIdentity.tsx)和[固定派发路由](../../apps/web/src/execution-pools/DispatchRouteFacts.tsx)。自动化范围和仍待迁移模块见[前端双语验证](../quality/frontend-localization-verification.md)。语言规范是全平台目标，本阶段没有完成全站旧模块翻译。

动态完整句复用统一Trans包装：插值先转义，再仅对渲染文本节点反转义，防止用户名称中的标签样式文字变成组件结构；保留目录中审核过的code／br组件与完整句语序。
