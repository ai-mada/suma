## 状态与可访问性

- 加载使用aria-busy与统一Loading；失败复用ErrorNotice和准确原始错误，不提前显示可启动。
- 工具／目录scope改变清除旧资格，选择变更更新草稿；已固定计划不受当前草稿覆盖。
- 原生select和有名输入支持键盘，折叠区可键盘展开；数值采用严格正安全整数，错误有状态提示。
- 语言键按codex-execution领域成对维护，当前zh-CN／en-US；后续新增语言复用注册机制。模型及未知未来effort标识保持原值，已知强度有完整双语。
- Start响应必须核对原计划预留run及派生workflow后才清原请求；恢复只读失败保持待核对，旧ACK不创建新运行。
