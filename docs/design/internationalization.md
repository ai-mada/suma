# 全平台国际化与本地化规范

## 当前 T-P4-017：任务设计依据与项目 CLI

新增独立领域目录继续复用 i18next／react-i18next；中文与英文各3119键的目录检查、必要消费者和类型检查通过。任务依据的资格、来源元数据、失败与重试有成对产品文案；采用正文、原需求／任务、SHA、稳定 key 和用户内容保持原样。真实桌面切换语言保留原快照、展开状态和焦点；任务刷新与设计定位单独验证。CLI 知识／设计帮助和维护模式受控错误使用同一双语原则。精确范围见[阶段验证](../quality/task-design-context-verification.md)。

### 增加后续语言的工程流程

当前只启用 `zh-CN` 与 `en-US`。新语言采用 BCP 47 标签，扩展已有语言注册与共享合同，不在业务组件增加逐语言条件分支。后续接入应依次完成：

1. 明确显示名称、默认与回退规则、账户／组织偏好及不支持标签的协商行为；同步 Go、Web、CLI、桌面和 SDK 的语言类型／校验，不能只新增选择器选项。
2. 按既有通用和领域目录补齐全部自有产品 key，复用格式化参数约定；保留代码、用户文档、日志、模型回复和不可变证据原文。翻译文案不可成为权限、状态或来源证明。
3. 使用 Intl 等已有区域格式化接口处理时间、数字、复数和单位；标识符及机器协议数值保持。格式化不能改变排序、预算精度和原始时间戳。
4. 更新同源合同与目录门禁，检查 key 对齐、参数类型、缺失项和硬编码入口；验证代表性长文案、键盘、错误恢复、语言切换及原文保持。日常按改动范围复验，完整设备／主题／语言矩阵留给发布验收。

当前目录与局部界面结果不代表安装器、第三方库内部文案、通知／渠道及全部平台能力已覆盖；各表面按完整平台台账继续验收。

## 历史 T-P4-012 精确尝试工具历史（本地已验证）

网页两语言各2829键、后端785键。持久工具历史按project／run／node／attempt读取，原始`raw_data`为必返证据；`Event.data`仅为兼容解析投影。显示层不能重编码原始SQL正文，不能翻译工具／模型任意内容，也不能把未知内层格式删除或借用当前节点补造归属。已支持的原生诊断仍须完整规范原文与键／类型参数相符，才能使用当前语言目录。

Go与JavaScript对旧JSON中孤立Unicode代理项的解释不同。界面只在临时兼容投影中采用Go一致的字符串解释并保持原始键顺序，不更改原文或选中身份。若原工具帧需要替换，仅显示原文，不从替换结果获得原生诊断身份；合法代理对、真实U+FFFD和字符串开头U+FEFF保留。完整规则见[架构与SOP](../architecture/attempt-tool-history.md)和[冻结读取合同](../../contracts/attempt-tool-history.md)。

语言或目录变化仅重显已读取的一页，不发起新读取或执行；同页存活事件保留原文展开和焦点。翻页采用固定watermark及原位置游标，显式“读取最新”或改变每页5／25／50／100才建立新窗口。历史页展示全部返回行，不继承当前实时工具40行上限。切换项目／账号／组织／运行／节点／attempt使旧响应失效；401／403／404清除旧敏感事实，暂时网络失败保留旧页时必须明确标记未重新确认。

现有实际观察包括原生进程的两次本地HTTP429与各5条工具事实，以及独立合成协议334条事实／7页、返回旧页、双语原文和焦点、刷新精确attempt及390／768／1366／1920部分页面。完整检查为Go1179／Web652／非Web47、类型／构建／合同通过。纯读取、SQL原文及全部分页复读、关闭快照和主预览原数据保持已核验，本阶段完成限定范围的本地验证，见[专项验证](../quality/attempt-tool-history-verification.md)和[精简摘要](../quality/attempt-tool-history-summary.json)。本地传输与合成协议不代表厂商模型效果、研发验收或全语言／平台／WCAG覆盖。

## 范围和语言

首次支持简体中文 `zh-CN`、美式英文 `en-US`，目录和接口可扩展其他 BCP 47 标签。品牌中文全名“速码一栈式智能研发平台”，英文 `suma`。浏览器、Electron、CLI、SDK 示例、MCP/A2A 面向人的说明、配置帮助、通知、消息模板、导出和安装都遵守同一合同。

翻译导航、操作、标签、校验、帮助、空态、加载、权限、断线、冲突恢复、审批、调度阻塞、图表图例和无障碍名称。机器枚举、错误码及协议字段保持稳定，只翻译展示标签。需求、PRD、用户命名、代码、路径、分支、原始工具输出、异常堆栈和证据保留原文；智能翻译必须显式操作并保存原件与版本。正式状态、审批哈希及幂等摘要不因显示语言变化。

## 偏好和交互

优先级：本浏览器显式选择 > 已保存的账户语言 > 当前组织默认 > 客户端或 `Accept-Language` 协商 > 产品默认 `zh-CN`。首次登录前也可切换。账户与组织偏好通过独立版本接口持久化；读取失败明确未知，不当作已保存的继承值。具体身份、版本、回执及跨标签页保护见[偏好合同](../../contracts/locale-preferences.md)与[操作设计](locale-preferences.md)。`zh`、`zh-Hans` 归一为 `zh-CN`，`en` 归一为 `en-US`，未知语言使用明确回退。响应声明实际 `Content-Language`。

切换即时更新当前屏幕和懒加载模块，保留表单、未知结果操作、运行、节点、attempt、筛选、滚动和焦点。同步 HTML `lang`、页面标题和辅助技术名称；英文较长文案仍须完整可操作。业务时区与语言独立，切换语言不得改变计划执行时刻。

## 实现合同

前端优先成熟 `i18next` / `react-i18next`，按领域组织稳定键和中英文目录，固定语句采用插值及复数，不拼接句子。React 转义文本，目录禁止任意 HTML。日期、数量、百分比、相对时间统一通过当前语言的 `Intl` 格式化。依赖版本在本仓库 React/TypeScript/构建与离线打包验证后锁定。

后端在请求上下文协商语言，禁止进程级可变“当前语言”。错误保留稳定 `code`，逐步增加 `message_key`、有类型参数和本地化展示信息。无法映射的旧提示保留原始诊断并列为未覆盖项，不能用笼统英文冒充具体问题已翻译。日志采用稳定事件码及结构化字段；第三方原始日志不修改。

通知保存收件人语言和模板版本，不依赖随机在线会话。插件、技能、菜单、工具声明可提供 `title_key`/`description_key` 与语言包，缺项时回退声明原文，不影响能力、授权或机器 ID。文档中文正文为基线，安装使用、API 接入和公开功能提供中英文入口与同步状态，未翻译文档明确原文链接和版本。

## 验收门禁

1. 中英文键与插值一致；缺键、空值、重复键、无效复数和占位符变化使检查失败。
2. 源码扫描维护有模块归属的旧文案基线；新面向人的硬编码不得静默扩散。测试数据、用户内容、机器标识明确排除。
3. 登录前后、共享池授权/策略/路由、项目/需求、运行/attempt、测试验收、发布和问题回流实际切换并刷新，分别检查四种宽度和键盘操作。
4. 并发中英文请求不串语言，错误码、权限、正式状态与操作回执一致；无效语言和缺项回退明确，原始日志不变。
5. CLI 帮助/错误与 `--json` 机器合同分别验证；桌面、安装、渠道、导出逐项登记，未实测端不能标记全平台完成。

## T-P4-008 自有工作台实现

剩余18个旧前端模块已迁入成对领域目录。项目概览、运行、能力、项目设置和检索拆为独立视图，共享项目只读快照；语言只改变展示，不触发重新读取，也不重建编辑器、草稿或未知写入。该阶段两语言各2798键。源码门禁覆盖全部生产模块及模板字符串片段，旧清单为0个含汉字候选；这不代表第三方控件、后端诊断、通知和安装器已全部本地化。

分页和共享写入保留结构化错误，到渲染时解析消息键及参数；HTTP状态和机器错误身份不接受服务端展示字段覆盖。未映射诊断与供应商输出保留原文。能力页的六项平台声明只有稳定ID和目录中的规范原文同时匹配才翻译，自定义名称及未来声明不套用现有译文。

数据缺失、真实零值和已加载窗口分别表达：未上报版本或指标不推测默认值；能力的配置、可用和验证各有未知状态；当前列表没有进行中任务不能宣称项目全部交付。自动化时间保留秒，UTC依据与原RFC3339并列保存。IDE平台操作及编辑器ARIA名称可即时切换；本地Monaco ESM内部菜单和语言诊断当前仍为英文，界面明确显示这一限制，后续单独验证语言包与离线打包。

实现、有效RED→GREEN回归、最终输入切面和真实页面范围见[该阶段验收](../quality/remaining-localization-verification.md)。该切面后端123个消息键；工作区与搜索新增16个，后续目录迁移分别记录在后续阶段。
