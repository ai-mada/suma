## 清晰而轻量的操作

保持原“交付与质量”按需展开区，不增加常驻步骤条、综合完成率或额外审批表单。运行／测试入口保持原准确节点与attempt；团队计划、问题、回流需求及验收使用有实际目标地址的原生链接。对象名称可以理解，精确ID和当前项目始终由正式引用决定。

普通当前页点击先通过原导航guard，有SPA回调就交给原路由；没有回调则走同一地址。复制链接、键盘和新标签能力保留。Ctrl／Cmd／Shift、另开标签等原生操作不切走当前页，不触发当前页SPA回调，也不为此清除原未确认操作。锁定、读取中、拒绝或错误时移除目标地址并退出Tab序列，避免“看似禁用仍能新开”。

## 验收定位与状态

“打开验收”直接指向原Review界面。跨视图定位只含公开任务版本和Run ID；目标页先匹配当前账户／组织、准确任务、版本及运行，不自动查询其他对象或改变Run选择。

| 状态 | 用户反馈及处理 |
|---|---|
| 准确匹配 | 一次打开原验收，说明导航没有提交决定 |
| 定位符缺失字段或非法格式 | 请从当前交付记录重新打开，不猜测目标 |
| 当前账户／组织不符 | 重新读取当前项目任务，不自动切换身份 |
| 任务版本或Run变化 | 提示依据已变化，不替换运行或使用旧回调 |
| 原操作未结束 | 等待或先处理原操作，不消费定位意图 |
| 原入口拒绝打开 | 保留未消费意图且不循环重试；blocked解除后可再试一次 |
| 已消费后重复render或数据刷新 | 不再次打开；完整重新访问链接属于新的明确访问 |

准确打开与正式批准分开呈现。用户进入后仍须审查原证据，使用原角色、权限与质量门禁完成验收。原问题回流和代码基线入口不因一次导航被自动执行。

复用原组件、焦点环及44像素操作规范；窄屏保持单列和可读对象名称，中英文状态成对。状态提示采用非阻断的`role=status`，不再弹额外模态窗口。

locator定向检查覆盖严格一次、依据不符、pending／拒绝重试和来源ABA；App四路由、真实HTTP页面及代表图仍由主集成按最终质量报告确认。本文不将组件检查当作完整实际通过，不引入新的候选／独测证据面板或审批授权。

成功打开后，仅在原账户、项目、任务及定位符仍一致时消费当前路由意图，详情重新挂载不再重复打开。原验收运行选择在异步选项加载期间保持明确初值，人工改选与原未确认请求正文不变。
