# Suma 协作工作台

采用已确认的紧凑协作工作台方向：固定项目侧栏、单层页面导航、页面内子视图、一个右侧记录详情。390px 窄屏使用可关闭导航与全宽详情，表格只在自身区域横向滚动。浅色与深色共享语义变量，键盘焦点可见；全局搜索使用 Ctrl/Cmd+K，模态框使用 Radix 焦点管理。

项目、页面、子视图、记录和运行保存在 URL 查询参数。登录使用同源 HttpOnly 会话；密码和 Runner 令牌不写入浏览器存储。主题是唯一写入 localStorage 的偏好。所有实体读写使用 `/api/v1`，无演示数据与假成功。

需求支持创建、修改、验收标准与人工编辑的拆分草稿。选择草稿后调用原子拆分接口。任务支持列表/看板、负责人、需求关联、依赖、状态和独立评审命令。详情不会用通用状态编辑绕过已验收门禁。成员明确区分人类、Agent 和工具。

质量区提供问题、测试记录和证据记录，问题可调用 intake 命令创建保留来源的需求；运维区提供版本记录和服务端能力声明。手工测试登记不会被当成自动执行证明，任务验收仍要求真实 test 节点成功。文档支持 Markdown 源文保存，知识检索保留来源、版本和定位。

接入令牌绑定当前项目，管理员可选择 Runner、Agent 工具或 API 范围。Runner 与 Agent 的接口范围分别说明，表单默认 Runner；结果使用实际响应的 scope、project_id 与到期时间。令牌值仅保存在当前页面内存中，复制失败有反馈。创建请求保持固定操作标识；网络或 5xx 导致结果未知时停止重复提交，在 sessionStorage 中仅记录非密钥的原操作标识、备注与范围。当前服务端尚无令牌创建回执恢复接口，页面明确要求管理员核实，不把未知结果当作创建失败后自动另建。

能力界面分别展示 configured / available / verified。文件工作空间读取真实文件清单，Monaco 与语言 Worker 均从本地构建产物加载。保存携带文件摘要；冲突时保留草稿并读取最新内容。保存期间继续输入会保留新草稿，只更新服务端已保存内容与摘要，下一次保存基于新摘要。网络未知时恢复原文件内容、摘要与幂等身份，不把当前较新草稿代入旧操作。服务端准备写入日志需要恢复时使用独立提示，保留原操作，禁止普通冲突合并绕过该状态。未保存文件阻止页面切换，刷新/关闭触发浏览器草稿提示。未绑定或缺少接口时明确显示原因，目录绑定仍由服务端权限和允许根控制。版本记录不会被描述为部署成功；外部 Agent/工具可用性以服务端事实为准。

通用实体写入对同一次失败操作复用幂等身份。错误保留表单，版本冲突刷新实体版本供用户核对。请求最长等待 30 秒；成功状态下回执解析失败仍归为结果未知，保留原幂等身份。创建项目、记录、拆分、评审、发布、启动及运行命令在结果未知时冻结原请求内容，并提供同一操作恢复；恢复前阻止页面切换与关闭表单。执行命令与工作流发布由服务端校验，网络未知结果不会被渲染为成功。

任务依赖以实际项目任务名称和状态供选择；URL 保留搜索、筛选、看板/列表状态及记录定位，直达记录不在列表窗口内时单独读取详情。单个项目切换会重置页面实例，搜索结果按项目清空，避免残留上一个项目内容。顶栏需求/任务数量和概览均读取真实 overview 响应，成功写入后刷新；未读取到时不显示假数量。

业务记录列表使用服务端 keyset 分页，每次显式读取 100 条。首屏只读取一页，“加载更多”使用 next_cursor 追加并按 ID 去重，保留响应中的完整 SQL total。项目或实体类型切换重置窗口与游标，旧上下文的在途响应不会覆盖新项目。下一页或刷新失败均保留当前窗口，并允许重试同一读取。列表、看板、状态筛选与搜索明确标注仅覆盖已加载范围；本地筛选命中数不会被当成整个项目的精确统计。不会自动把所有页面读入内存。负责人、需求及依赖选择器保留窗口外的当前关联 ID，占位说明未在已加载范围，并提供显式更多选项。运行列表与工作流历史也只读取每页 100 条摘要，显示已加载数和 SQL 总数；节点在打开运行详情时单独读取。任务评审单独读取当前关联运行，使窗口外的有效依据仍可选择。概览运行计数只使用 counts.runs，不用最新运行摘要长度推导总数。

根与延迟页面各有错误边界。旧标签页缺少延迟资源时会显示可手动恢复页面，保留当前 URL，不自动刷新或重新提交操作。默认构建保留旧摘要资源，具体版本目录、资源追加和回收窗口见 `apps/web/README.md`。错误边界不承诺恢复尚未保存到服务端的内存草稿。

本次源码检查已通过 TypeScript 与 29 项合同测试（记录扩展字段和数组、真实 DAG 边、依赖编辑和环路拒绝、渲染失败的显式恢复、同源 Cookie、未知/截断回执与超时后的原请求恢复、项目范围令牌与丢失回执后停止重复创建、真实审批与补偿入口依据、分页追加/去重/失败保留/项目隔离、窗口外关联保留、保存期间输入及日志恢复、深链初始化、运行摘要与当前关联运行独立读取）。Vite 生产构建包含本地 Monaco 语言 Worker；IDE 与工作流按页面延迟加载。大型编辑器/布局包仍会触发构建体积提示。浏览器交互与生产集成验收由总交付记录单独说明，本文不替代该证据。
