# 工具接入交互

T-TOOL-ONBOARDING-176；1.0.0；状态：本阶段实现，生产组件代表视觉已验证，完整 App 待验。负责人：工作台体验。关联[需求](../product/tool-onboarding.md)、[合同](../../contracts/tool-onboarding-scan.md)、[架构](../architecture/tool-onboarding.md)。

## 入口

“此电脑的开发工具”放在原快捷连接区，以一块紧凑面板展示，不增加页面层级。进入当前桌面项目自动检查一次；重新检查是次要按钮，执行中显示明确进度。各行只有工具／协议、当前事实和下一步。选择一行进入原配置，不安装、不连接、不授予权限。两个 Codex 协议明确命名。

浏览器模式提供执行节点或桌面接入引导。缺少运行环境、安装形式不支持、配置尚未完成、观察失败分别显示可操作说明；未知结果不显示绿色健康状态。不用自动刷新和循环重试掩盖失败。

## 状态与草稿

| 状态 | 行为 |
| --- | --- |
| 检查中 | 保留页面位置，避免重复进程；原配置仍可按既有规则操作 |
| 近期观察 | 显示观察时间与缓存事实，不延长有效期 |
| 请求失败 | 保留明确失败提示，可手动重试；不沿用其他项目结果 |
| 原连接结果未知 | 保持原恢复／核对入口，禁止用扫描选择绕过原限制 |
| 采用清单过期 | 表单中提示需重新读取，名称保留；新登记按钮不可写入 |
| 原登记结果未知 | 继续原操作核对，不能因新清单过期而变为重建配置 |
| 手工配置 | 明确未验证，允许暂停登记，启用仍按现有门禁 |

语言切换只改变展示，不触发重复扫描。异步结果绑定当前身份／组织／项目和组件实例；离开或切换后旧结果不能填充新页面。明确选择后聚焦并滚动到原配置起点；自动检测结果不会抢焦点。同一身份／项目内各接入项的名称及配置选择草稿保留在内存，切回时仍重新读取正式库存，不缓存连接事实。窄屏行内容允许换行，动作保持可达，使用原按钮、焦点和无障碍语义。中文、英文词条成对管理，不在业务组件硬编码新语言。
