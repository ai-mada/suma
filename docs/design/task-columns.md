# 任务列表显示列与共享偏好

状态：T-TASK-COLUMNS-160已完成Windows／SQLite限定交付，产品1.0.0。关联[正式合同](../../contracts/task-columns.md)、[共享任务视图](../../contracts/shared-task-views.md)与[任务集合交互](task-collection.md)。实际验收与生产状态分开记录。

列表工具栏提供一个默认收起的“列”入口；不新增设置页面。面板列出任务、状态、优先级、负责人和更新时间。任务标题固定，其他列可勾选，并通过上移／下移按钮调整顺序；用户始终可用键盘操作。恢复默认只改变显示偏好，不修改任务。

选择框和打开详情入口保留在表格原操作区。迭代仍来自标题中的正式排期徽标。列变化不重新查询任务、不清除选择或分页，也不修改筛选；看板保留同一偏好但不改变卡片。本机、刷新和URL恢复使用同一配置语义。

保存到个人或项目共享视图继续原有明确表单、当前权限、版本和原操作回执。面板不暗中保存到服务器；应用共享视图先校验完整列配置，非法正式响应明确报错。未知写入仍保留原body／key，显示列重排不能改写未确认的操作。

界面状态包括默认、定制、仅标题、面板展开／关闭、移动边界、重置、非法读取、保存中、冲突及未知恢复。中文／English词条、标签和状态对应；原任务文本与人员名称不翻译。窄屏保持可读标题、触控目标和操作入口，所有已选列仍遵从明确配置。

开发与AI操作顺序：读取当前视图和版本；在本机预览显示列；若需要共享，明确保存到原个人／项目范围；核对服务端回执；刷新重读。共享视图不授予任务访问权，列隐藏也不构成权限控制。

本阶段实际18项检查、未知保存原操作恢复、中英代表界面和未验范围见[验收报告](../quality/task-columns-verification.md)。列操作无新增任务查询或业务写入；其他数据库、物理多机、完整离线及生产另验。
