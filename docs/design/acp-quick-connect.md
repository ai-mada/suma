# 原生工具快速连接：简洁交互设计

T-ACP-QUICK-CONNECT-171；suma 1.0.0；2026-10-31；负责人：工作台／主集成。状态：代表中英文局部视口已核对，完整矩阵及显式停止按钮仍待验。关联[验收合同](../../contracts/acp-quick-connect.md)及[架构与AI SOP](../architecture/acp-quick-connect.md)。

## 用户路径

工具管理保留原有固定导航和QuickConnect，不增加一页配置中心。Qoder以一张紧凑卡显示下一步主要操作：检测本机、读取实际模型、确认连接。已经连接时优先显示固定模型和连接状态；高级手动配置默认折叠。

| 当前事实 | 主操作与反馈 |
|---|---|
| 还未检测 | “检测本机工具”；不在打开页面时启动探测 |
| 没有原生工具 | 显示固定官方安装入口，说明安装后重新检测 |
| 仅包装器／无法核实 | 准确解释当前限制；不以“已安装”代替可用 |
| 检测到原生程序 | 显示产品、实际完整版本；“读取模型”需明确点击 |
| 读取中 | 原操作等待反馈，防重复；不伪造进度百分比 |
| 目录可用 | 下拉列出真实名称及精确ID，用户选择后确认连接 |
| 目录过期／来源变化 | 禁止采用并说明原因，重新读取必须明确操作 |
| 原观察未知 | “核对原观察”；不自动重试新会话 |
| 托管发行／连接未知 | 显示原配置并核对原连接，当前选择不能覆盖 |
| 精确新库存已连接 | 复用原暂停登记，再明确启用；两步状态分别显示 |

## 信息层次与视觉

默认只展示用户决策所需的工具版本、模型、当前状态和一个主要按钮。模型名称相同但ID不同须保持可辨识；不能自动采用第一个选项或未经验证的current value。长版本、模型ID和错误提示可换行，不挤出390px视口。

可执行和配置摘要、观察期限、模型来源、停止事实放在展开详情中。主进程保管安装引用，不在普通界面展示本机路径或凭据值。身份、工作区未绑定时显示当前可执行的下一步；浏览器环境不得呈现可用的“扫描我的电脑”假按钮。

深浅主题复用现有设计令牌、边框、间距和按钮。状态使用文字配合图标，不能只用颜色；读取、失败、断线、过期和恢复反馈在原卡位置出现，避免整个页面跳动。

## 中英文与可访问性

新增文案全部采用独立可扩展词条，中英文一一对应。精确模型ID、错误码和版本不翻译；日期按当前语言显示。按钮、模型选择和详情有明确标签；键盘可完成完整路径，忙碌时保留可感知状态，反馈区域适当播报且不持续抢焦点。焦点不因状态轮询被移走。

用户编辑新的模型草稿时，界面立即区分“当前连接”与“待连接配置”。停止和原操作恢复操作不读取草稿。目录过期不打断原连接，也不能把过期目录直接用于新启动。

初次状态核对从首帧开始标记忙碌，检测和模型控件在核对结束前禁用；不能显示可点按钮后静默忽略。目录过期只安排一次到期更新，不为无倒计时的界面持续每秒重渲染。读取中的原操作核对保留有界轮询，不能由轮询新建工具会话。
