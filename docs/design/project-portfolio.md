# 组织项目组合

T-ORG-PROJECT-PORTFOLIO · 项目管理

组织成员从「项目管理」在一个列表查看当前可访问的项目。项目名进入该项目概览，设置另有入口。管理员仍可在同页新建项目。项目名、描述与验收分子分母优先显示；阻塞和活动风险分别呈现。没有任务时显示空范围。最早尚未完成的有日期里程碑保留计划日期，逾期按同一读取快照标识。窄屏按项目逐项展示，键盘可搜索、翻页和进入项目。

搜索由明确提交触发，按项目标题或描述匹配。浏览器返回组合时恢复已提交搜索。分页一次展示当前读取的项目，显示读取时间；无匹配、无权限、请求失败或游标过期均可回到明确入口继续。组织切换及授权失败清除旧数据，后台校验保持同一视图来源。

服务端沿组织会话授权读取页面，再在同一事务按页面项目统计全部任务和风险，选择每个项目的首个未完成里程碑。页面规模与单项目业务计数独立。任务验收与运行状态、项目自身状态分开，组合视图不写入业务或调度命令。工作台当前只比较已核验的三组业务事实，组合资源冲突、预测与跨项目计划依赖继续按总计划推进。 [授权与查询合同](../../contracts/governance-planning.md#组织项目组合)
