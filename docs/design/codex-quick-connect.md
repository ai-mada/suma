# 原生连接的简洁交互

T-CODEX-QUICK-CONNECT-175；suma 1.0.0；2026-10-31。负责人：工作台与桌面。关联[产品需求](../product/codex-quick-connect.md)、[合同](../../contracts/codex-quick-connect.md)和[验证](../quality/codex-quick-connect-verification.md)。

以一个连接卡完成“检测 → 必要配置／目录 → 连接”，不用另开复杂向导。安装文件、摘要等技术细节按需展开；提供方、地址、凭据引用和Windows模式使用清楚标签。任务模型选择仍在原任务面板，不在连接页维护第二份默认模型。

| 状态 | 默认操作 |
| --- | --- |
| 未检测 | 检测本机工具；浏览器模式提供本地桌面／服务端Runner指引 |
| 已安装但缺配置 | 直接解释需要提供方设置，不显示为可派发 |
| 缺运行环境或不支持启动器 | 显示具体原因及既有安装指南／重新检测入口 |
| 正在读取目录 | 保留当前scope和配置，防止切换隐藏原操作 |
| 结果未知 | 核对原操作，保留原body/key，不出现模糊重试 |
| 目录ready | 展示真实模型数量／依据，允许连接；不宣称账号或模型健康 |
| 已连接 | 显示准确节点及当前新库存，继续暂停登记／明确启用 |
| 已停止 | 可明确更新配置；运行中及停止未确认时继续保护原配置 |

草稿按当前人、组织、项目和adapter隔离，切换语言保留当前输入；项目、身份或来源变化立即停止旧异步结果覆盖新视图。凭据只填写环境引用，不能把秘密原值发送给renderer或保存进草稿。

使用原设计令牌和组件。窄屏单栏、可见焦点、明确忙状态、可操作空态和错误后的下一步；不把长JSON或重复诊断文案作为主要操作。中文／英文采用独立成对词条，后续语言通过同一目录机制扩展。

配置、目录、连接、登记、启用及任务执行分别展示。任何UI状态都不能替代当前服务端授权、真实库存或原操作回执。
