# 原讨论消息追加到原执行

状态：suma 1.0.0 当前实现中；需求：T-TURN-STEERING-188；负责人：Web／主集成。依据：[领域合同](../../contracts/turn-steering.md)、[产品](../product/turn-steering.md)、[架构](../architecture/turn-steering.md)、[English](../en/turn-steering.md)。当前实现说明不代表界面或真人验收完成。

## 入口与确认

在现有任务讨论的 human 消息旁提供一个明确入口，用户选择已保存的本人消息后打开单一追加面板。面板按需读取该消息的权威 context；不为每行消息创建轮询，也不增加一级页面或桌面开关。普通评论、回复保存、自动刷新不会发送追加指令。

面板显示完整原文、准确目标的运行／节点／attempt，以及当前投递记录。正文沿原讨论的 32,000 UTF-8 字节／8,000 Unicode 字符上限，须为有效 UTF-8、非空白且不含 NUL，其余字符经 JSON 完整保留、不裁剪。目标与原消息由服务端确认；用户不能在这里修改正文。需要补充或改写时先保存一条新讨论消息，再明确发送。多个可用目标必须明确选择；不得从历史 `execution_run_id` 或“运行中”标签推断活回合。

“发送到原执行”是独立提交。发送前说明它追加给原 Codex 活 turn，沿原模型、预算、工作区及工具权限执行。确认内容与原任务验收分开，不使用“已完成开发”“已验收”等文案。技术身份和摘要放入可展开详情，主要区域保持原文、目标、事实与动作清楚。

## 状态与可操作性

| 服务端／投递事实 | 页面表达与行动 |
|---|---|
| context 加载中 | 保留所选消息，禁止发送 |
| 当前有权且有准确活目标 | 可选择目标、核对原文并单独发送 |
| 平台已保存 | 展示已登记指令，禁止同消息重复提交 |
| 执行器已观察 | 显示观察事实，不冒充 native ACK |
| 开始写出／完整写出 | 分别显示实际阶段，保持记录只读 |
| 原生已接受 | 显示“原生已接受”，提示不代表模型已遵从或代码通过验收 |
| 原生已拒绝 | 显示准确拒绝事实；不自动再发 |
| 结果待核对 | 保留原操作，提供核对原提交；禁止另造新请求 |
| 原回合已关闭，指令未派发 | 显示未送达，不把会话关闭等同于接受 |
| 无当前活目标／执行暂不可用 | 禁止发送，提供当前原因或刷新读取 |
| 任务已验收／非本人消息 | 不提供新发送资格 |
| 当前撤权 | 清理受保护原文和目标，按现权限错误处理 |

`active`仅是 session 记录状态；可发送按钮以当前 `can_send`、准确目标 allowed_actions 和提交保护共同决定。产品原因采用闭集的本地化文案，保留原协议 reason，不拼接原始私有错误。

## 原操作恢复与页面协作

浏览器发送仅包含 project／task／message／session ID、准确期望版本与稳定 key，完整正文和原生参数不由浏览器传入。原意图在网络前保存，绑定 user／org／project／task 作用域；内容固定旧 session、消息、执行 tuple、body 与 key。新 attempt 不能清除或覆盖旧待核对意图。

超时、断线或响应不可解析时保留 pending，先读取或重放同一原操作。恢复回执与当前 context 分开：旧操作恢复成功不表示旧目标重新可发送；同 key 不同 body 必须拒绝。不能把 unknown 改成“发送失败，可重试”，也不能换 key 自动发送。存储失败、受保护拒绝和未知操作未核对前不得清 pending。

账号、组织、项目、任务或所选消息切换时重置读者 epoch，迟到结果不能回填当前面板；撤权立即清私有内容。原讨论回复、据此开发、草稿 guard 与追加动作共同聚合 busy，单个子面板退出不得把另一个动作解锁。保留输入、未知请求和范围变化时，沿现有离开保护处理。

## 中英文、窄屏与键盘

产品标签、原因、按钮和投递事实提供中文／英文；用户原文与原生消息不自动翻译。390px 窄屏采用单列、可换行正文和目标摘要，不让长 ID 撑开页面。详情折叠不隐藏当前风险或唯一恢复动作。

复用原按钮、标签、错误与 focus-visible；入口、目标选择、确认、详情和核对动作可按顺序键盘操作。加载和提交时禁重复，结果就近呈现，焦点不被后台刷新抢走。不得用伪进度、自动提交或仅颜色表达接受／拒绝／待核对。

代表验证应覆盖中文宽屏、英文 390px、真实键盘焦点、准确目标选择、正常保存、未知恢复、关闭未送达、当前撤权与源切换。组件合成 API 与真实登录 App、CLI／模型调用及真人验收分别记证；本阶段不据此扩大全平台覆盖。原 31 项／P0–P7／58 限定／34 待交付／92 总账及 T171 显式 GUI 停止缺口继续。
