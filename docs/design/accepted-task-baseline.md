# 任务开发基线的明确来源选择

速码1.0.0 · T-ACCEPTED-TASK-BASELINE-222。[用户步骤](../product/accepted-task-baseline.md)／[领域合同](../../contracts/accepted-task-baseline.md)／[验证](../quality/accepted-task-baseline-verification.md)。

沿原任务详情基线面板，按需展开，不新增页面。普通任务先选择“已验收任务候选／合成结果”；候选必须明确选择任务和步骤，展示版本与SHA，并链接原准确run/node/attempt。固定合成计划入口保持原义，终端来源不伪装普通智能体。

使用现有组件、44px触达和窄屏换行，标签和确认文案中英文对应。最近200条的读取范围明确，不把空范围说成没有历史候选。输入、加载、错误、无权限、来源变化、原操作未知和已采用分别呈现；候选SHA是代码事实，不显示“新任务已测试／已验收”。

确认绑定目标版本、基线版本、当前来源完整快照和单调代次。来源资格、候选、任务、账号／组织／API变更均撤销旧确认；A→B→A不能复活旧授权。原恢复保留原path/body/key，来源目录变化不会删除未知操作，也不把原恢复改成一次新采用。

采用成功只表达来源已固定，不跳过原模型预算与派发预览，不自动开始或批准。新任务开发、独立测试与正式验收仍分别操作和取证。验证只检查本次变化和代表界面，不重复原供应方／完整设备矩阵。
