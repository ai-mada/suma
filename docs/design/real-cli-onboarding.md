# 工具检测诊断与快速重检交互

状态：T-REAL-CLI-ONBOARDING-226，1.0.0 阶段交付。负责人：工作台代理与主集成代理。关联[产品](../product/real-cli-onboarding.md)、[接入架构](../integrations/real-cli-onboarding.md)、[验证证据](../quality/real-cli-onboarding-verification.md)。

## 信息顺序

保留工具管理的原扫描区域。每行先显示工具名称、安装事实和简短原因，再提供一个主要动作。检测阶段、协议、版本及原始原因码放入“查看检测依据”，不增设诊断中心或多步向导。

- 本机结果区保留已检测数量和需处理数量，普通未安装项仍可折叠；当前选中项始终可见。
- 未能确认安装显示“尚未确认”，不将权限或来源异常归入明确未安装。
- 已安装但存在分类故障，同时计入已检测和需处理。计数不改变工具可执行资格。
- 远程行始终保留目标节点；指南回调直接传入该行的工具和 Worker，避免先更新选择再读取旧状态。

## 行为与状态

| 状态 | 主要操作 | 限制 |
| --- | --- | --- |
| `guide` | 打开此工具的配置指南 | 原因和建议按需展开；不同时堆叠重复准备按钮 |
| `scan` | 重新检测 | 本机沿原 `scan(true)`；远程沿原单工具扫描；权限、来源、busy 和未知回执规则优先 |
| `none` | 保留记录，先核对 | 行级重检与本机顶部重检均禁用；不能把已过期的未知停止当作安全 |
| 正常安装观察 | 使用原配置／准备入口 | 安装、库存、登记、启用分开表达 |
| 失败或断线 | 展示原可恢复状态 | 不自动换请求、切换节点或清除用户输入 |

本机或远程没有对应回调时只展示建议。原键盘、焦点、折叠和窄屏布局沿现有组件；动作按钮维持至少 44px 高度。中英文翻译使用固定消息键，机器输出不直接翻译或作为界面文字。减少动效与主题沿现有令牌。

## 代表验证

采用可维护的[本地界面夹具](../../tests/integration/real-cli-onboarding/entry.tsx)，直接渲染生产扫描组件。中文 1366px 验证帮助检查失败进入准确工具和节点的指南；英文 390px 验证明示重检及停止未知后的禁用。夹具桥和指南回调为合成观察，完整应用导航与真实 IPC 单独验收。截图及输入摘要留在忽略的证据目录，结果见[报告](../quality/real-cli-onboarding-verification.md)。
