状态：T-P4-034／1.0.0，2026-10-27；限定本地已验证。负责人：平台集成。定向检查、隔离推荐／预览、真实Monaco回执恢复与主预览核对通过；没有新正式运行或厂商／生产验收。见[阶段证据](../quality/task-dispatch-options-verification.md)。

## 信息与视觉层级

在原任务派发弹窗中，保持“流程版本 → 开发节点 → 工具选择 → 知识 → 明确预览”的主顺序。在开发节点之后增加默认折叠的“查找兼容工具”，不扩成新的复杂配置页面。

展开区先解释当前兼容的含义，再显示刷新、当前页与观测时间。候选使用紧凑列表，呈现工具名、配置版本、工具版本、执行节点及兼容原因；本页推荐放在独立简短提示区。“采用当前推荐”只填写下面已有的工具选择。

模型、费用与路由放在“模型、费用与执行检查”二级展开区，减少主流程负担。费用明确未知，模型明确由工具配置固定。观测路由和正式预览固定路由是不同事实，不能相互补造。

复用 React、已有 Radix 弹窗、Lucide 图标、Field／Loading／ErrorNotice、统一双语目录和现有可展开区域样式；不新增依赖、付费设计运行时或独立主题体系。

## 步骤、焦点与键盘

1. 用户通过原生 select 选择流程与实际 Agent 节点。
2. 推荐入口使用 button，支持键盘，提供 aria-expanded 和 aria-controls；默认折叠无额外读取。
3. 展开后的加载区提供忙碌与状态提示；候选不是必须拖拽的画布。
4. 用户可选择本页推荐，也可回到原工具选择；采用后仍需单独点击原预览按钮。
5. 下一页替换当前页并更新页码，刷新返回首页。颜色不单独承载兼容状态，文字始终完整。
6. 折叠会中止本区未完成读取并清除观测，再展开重新读取；语言切换不触发请求。

全部新增操作均为 type=button。错误后的重读与表单提交分别处理，避免重试意外生成派发预览。沿用现有弹窗焦点管理与响应式布局，不将“面板已展开”误作执行确认。

## 状态设计

| 状态 | 显示与操作 |
| --- | --- |
| 尚未选开发节点 | 不显示推荐入口；原选择流程保持清楚 |
| 折叠 | 仅入口，不加载候选 |
| 读取中 | 清除旧候选及采用入口，显示加载；禁止重复读取 |
| 有兼容项 | 显示页内列表与本页首个兼容项，明确只比较当前页 |
| 本页无兼容项 | 展示各项原因，允许下一页或去工具设置处理 |
| 空页 | 说明没有配置，引导登记与授权；不伪造推荐 |
| 网络或服务错误 | 显示错误并提供明确重读；不将失败解释成零个工具 |
| 响应结构或范围错误 | 拒绝候选，提示刷新；不从200状态推断可信 |
| 401／403 | 隐藏推荐事实和采用入口；非待恢复状态清除选择 |
| 输入范围变化 | 旧页卸载，旧推荐和选择立即失效；新范围仍默认折叠 |
| 已有待恢复写入 | 推荐、刷新和采用不可用；原请求恢复入口保持既有语义 |

兼容项只证明已观测到的库存、授权和纯构建兼容。即使显示兼容，机器槽位、实际预算、额外知识及最终执行策略仍由正式预览／启动／领取检查。

## 原选择与异步边界

采用时传递已验证的完整工具配置对象。若原列表同 ID 只有旧版本，选择和详情必须使用推荐返回的新版本与摘要，不能悄悄退回旧配置。服务器通过原预览的 expected_tool_version 再核对，并固定正式工具摘要。

项目、账号、组织、任务版本、流程版本或节点变化都属于不同读取范围。未完成读取通过取消和代际检查隔离，旧响应不回填新页面。响应同时校验任务上下文、项目路由、工具范围与页内唯一顺序，推荐 ID 必须恰是当前页首个兼容项。

待恢复操作的原调用者、请求路径、正文和操作标识继续由既有恢复机制保存。采用与读取不创造写入；切换输入不会把原未知结果变成新执行。

## 工作区保存回执与异常恢复

保存动作复用现有 Monaco 工作区、正式文件接口和原操作恢复机制。HTTP200本身不足以显示“已保存”：回执路径、返回内容与准确提交内容、实际 UTF-8 SHA-256、可选语言字段结构均须通过校验；不改换行后再比较。

- 有效回执：更新文件基线并结束原保存；保存期间用户继续编辑形成的新草稿保留，不被旧提交内容覆盖。
- 丢失、错误或不匹配回执：保留原保存请求和当前草稿，显示说明，继续找回原保存，不创建新的写入。
- 已经未知的写入随后遇到权限或哈希拒绝：不能据此推断前次未提交，继续保留原操作等待核对。
- 明确版本冲突：沿用当前远端内容比较与人工合并入口；比较失败也保留草稿。
- 文件打开晚到：旧文件响应不能覆盖后来选择；未确认保存时阻止切换文件，离开页面给出未保存提示。

这些保护覆盖当前编辑会话和既有服务恢复合同，不声称已交付跨重启离线同步、终端PTY、调试器或完整协作 IDE。Monaco 内置菜单的运行时语言边界继续按界面说明披露；本阶段新增平台操作与异常说明提供中文、英文。
