# 组织人员工作日历

T-ORG-WORK-CALENDAR · 组织设置

从「组织设置 → 人员工作日历」进入。组织管理员选择当前成员，可编辑其周工作制和日期例外。普通成员在同一入口读取自己的日历。选周时查看当周已保存的每日可用小时和已知范围，草稿另有保存提示。界面同时支持中文、英文、键盘和窄屏，复用项目工作日历的表单及写入恢复。

未配置时七天均显示未知。填入 0 明确表示当天不可用，日期例外覆盖周工作制。标准工作周模板需要主动应用并保存。周总量要求七天都有明确值。查看下一周、离开或更换人员走现有草稿保护；授权消失时移除已失去读取权限的内容。版本冲突需要重新读取，网络结果不明时核对原操作。

组织日历按租户和真实账号单独保存。它提供跨项目计划使用的人员可用工时依据。各项目资源日历继续提供项目排期分摊依据；两份日历各自编辑、各自追溯。组织总负荷、工时超配、外部节假日与请假流程仍按实施计划推进。 [接口与授权](../../contracts/resource-calendars.md#组织人员工作日历)
