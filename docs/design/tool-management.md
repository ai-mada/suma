# 工具管理交互设计

状态：限定实现与验证完成；suma1.0.0；T-TOOL-MANAGEMENT-193。负责人：工作台代理；关联[PRD](../product/tool-management.md)、[合同](../../contracts/tool-management.md)、[架构](../architecture/tool-management.md)与[验证](../quality/tool-management-verification.md)。

页面以“当前接入”列表和一个“连接工具”主入口为中心。Quick、Advanced、Doctor是同一流程的不同步骤：常用操作直接可见，高级配置与来源依据按需展开，返回时保留搜索、位置和已选目标，不再堆叠多张重复大卡。

## 接入与诊断

Quick明确区分本机检测和授权节点状态读取。自动读取展示来源与目标；缺少能力或fresh上报时给出准确下一步，不以占位动画、CLI安装记录或generic连接图标表示SDK就绪。选择配置后用同scope公开草稿接续Advanced，保留既有身份，不重新要求填写相同信息。

Doctor默认一句话说明当前阻碍，保留原授权、worker、库存和profile四项事实；仅突出一个最合适的动作。动作打开准确节点、当前配置或已有接入复核，不能跳到空白表单。刷新是读取；原生重扫、安装与修复有各自能力和结果，不合并成“已修复”。

## 列表与维护

默认active只显示enabled与paused，已移除记录按需查看。搜索覆盖五个公开字段，名称和协议等长文本可读；状态、搜索、账号、项目或目标改变后清空旧分页，迟到响应不能覆盖新列表。空结果与加载、读取失败、无权限分别表达，保留可恢复草稿。

常用动作集中在列表或详情菜单。“调整配置”沿原目标本机准备与上报形成新固定配置；“停用”是pause；“移除接入”是永久revoke并保留历史。确认文案明确实际效果和影响范围，不暗示已停止进程、删除代码或物理删除记录。无当前权限时不提供可执行入口。

## 影响与未知结果

影响摘要默认一句话，必要时展开原运行入口和覆盖详情。complete显示当前项目活动run范围；partial与unknown明确保留未覆盖原因。最多5项公开引用，已观察数量不称全局总量；0个已观察引用但覆盖未知时，不能显示“没有影响”。尚未领取的节点不显示虚构执行者或正数attempt／fence。

请求未确认时保留原tuple、body、操作ID与版本，提供核对原操作的恢复路径。保存、授权、启用、执行和停止各自显示事实；未知不能改显示为成功，也不自动用新请求重试副作用。

中文和英文共用控件与状态，主要动作满足44px触达，390px使用单列，长命令和来源可选择、滚动。复制、异步busy、菜单和确认保留键盘焦点；折叠不隐藏当前决定所需的信息。代表性验证聚焦接续草稿、筛选分页、移除及未知覆盖，完整平台和设备矩阵继续独立验收。

## 停用与移除确认

参考 Multica 的运行时移除窗口在来源变化后重置确认。速码复用现有工具诊断、影响组件与版本化命令。窗口先显示当前配置、版本、节点和命令，紧跟一句活动运行影响；范围和引用节点按需展开。用户可以取消或重试准确读取。窄屏采用单列，操作保持可触达。

读取失败或过期时隐藏旧影响并锁住确认。提交发生冲突或权限变化时，留在原窗口重新核对；读到新版本后重新确认。已经移除或已经停用的相应操作不可重复提交。移除保留历史，已发生的外部执行沿原运行核对。 [验证记录](../quality/tool-decision-impact-verification.md)

## T-TOOL-EXPERIENCE-198 简洁交互

继续一个“连接工具”主入口。不可用配置在原卡片展示原因，并提供一个次级“配置工具”入口；长诊断换行，按普通文本渲染并使用status语义，不靠颜色传达失败。高级引导只在需要时展开，焦点进入正确配置区；不同配对节点不能改变当前目标。

窄屏保持单列、按钮可触达；中文／英文提示含义一致。配置草稿、安装事实、库存、已启用、可派发、模型和质量各有原事实来源。用户对配置调整和移除继续沿原确认与操作回执，无额外重复确认，也无隐式自动执行。

## 派发与云账号读取恢复

兼容工具和推荐历史共用紧凑的分页操作。页码在读取和失败时仍指向用户所请求的页，重试沿用原游标。上一页和首页可明确返回。键盘焦点保留在分页操作，屏幕阅读器可感知页码及读取状态。页面未确认时收起该页的工具或推荐操作，成功后用本次结果恢复。

WorkBuddy 的“检查授权结果”读取原连接。检查失败时重试同一连接，期间隐藏原官方链接，列表刷新无法替代准确核对。当前连接仍允许原待授权链接时恢复入口，已断开或授权代次改变时显示当前状态。该行为复用原 WorkBuddy 权限、连接详情和授权回执。

参考 Multica 事项列表在原续读失败处提供重试的交互。速码在派发对话框使用显式分页，并分别按兼容候选的 opaque cursor 和推荐记录 ID 续读。 [派发合同](../../contracts/task-dispatch-options.md#ui-and-cli) · [授权合同](../../contracts/workbuddy-connections.md#授权实例与回调)

## 从节点查看工具配置

普通节点和当前项目获准查看的共享节点都提供“查看工具配置”。入口把焦点移到原配置列表，显示可清除的节点条件，并先展示该节点的全部状态，方便找到已暂停和已移除的配置。后续可继续按状态或名称筛选。

节点筛选随当前项目的工具页链接保存。打开详情、返回和刷新可重用该条件。列表收到其他节点的配置时拒绝该结果，保留明确的恢复入口。清除筛选后可返回全项目列表。节点凭证、实时库存和工具配置状态仍各自显示。

参考 Multica 按机器查找运行时的交互，将定位接到速码已有的授权档案列表。 [工具列表合同](../../contracts/tool-management.md#当前列表接口)
