# OpenCode快捷接入交互

T-OPENCODE-QUICK-CONNECT-177；suma 1.0.0。状态：已实现，代表生产组件布局与操作已验证；完整App及设备矩阵待验。关联[产品流程](../product/opencode-quick-connect.md)、[冻结合同](../../contracts/opencode-quick-connect.md)、[架构](../architecture/opencode-quick-connect.md)和[限定验证](../quality/opencode-quick-connect-verification.md)。以下规定当前交互，不替代对应范围的实际证据。

原工具入口按“检查安装 → 填写固定配置 → 连接并核实”逐步展示。默认只显示提供方ID、固定模型、服务地址和可选凭据环境引用；路径、摘要及原操作标识按需展开。任务不会在此获得第二套选模器，OpenCode固定模型也不冒充目录发现结果。

| 状态 | 显示及可执行操作 |
| --- | --- |
| 未检查 | 检查本机安装；浏览器模式显示桌面／服务端Runner指引 |
| 未安装／不支持版本 | 说明精确1.19.4要求，提供重新检查，不自动安装或降级 |
| 已安装、缺必要配置 | 展示四项固定配置；凭据输入明确为环境变量名称 |
| 资源不可用 | 说明SDK或目标Node缺失，保留草稿；不能先发行新身份 |
| 正在连接 | 阻止并行换配置，区分登记／启动／等待新库存，不提前显示成功 |
| 原登记未知 | 显示原操作核对入口，保留原请求和key，不换发身份 |
| 已连接 | 展示持久配置的提供方、模型、安全origin和准确节点，再引导暂停登记及独立启用 |
| 已停止 | 允许明确更换配置；普通重连继续采用原配置 |
| 停止未确认／来源变化 | 显示具体原因与核对入口，不能显示成可改配的安全停止 |

当前人、组织、项目和adapter共同界定草稿与异步结果。来源改变时旧结果不能覆盖新视图；失败保留仍可用的原操作，撤权清理私有显示。已连接信息采用主进程回执，不从用户正在编辑的草稿推导提供方或地址。

六项metadata为 `model/tool_version/executable_sha256/configuration_sha256/provider_id/endpoint_origin`，connected时必须完整、匹配。tool_version表示原生1.19.4；库存包装器版本与Node SHA是另外两项执行事实。连接回执不回显私有Node／manifest路径、完整服务地址或凭据原值，也不接受可编辑命令；安装来源细节沿原被动检测合同，高级管理员样例不产生renderer路径授权。

中文与英文使用原词条机制。沿现有设计令牌和组件，窄屏单栏、44px主要控件、可见焦点、明确忙状态；空态和错误必须给下一步，长JSON不作为主要操作。待统一集成后用必要代表交互验证，不把这些设计要求写成已通过。
