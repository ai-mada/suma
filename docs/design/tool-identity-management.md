# 执行节点凭证与 WorkBuddy 授权管理

阶段标识 T-TOOL-IDENTITY-MANAGEMENT。沿用工具管理和 WorkBuddy 连接的领域合同，继续推进完整平台交付。

执行节点默认展示当前有效凭证。需处理视图单独展示过期与待核对记录，撤销历史可查看。按公开节点标识筛选，计数只覆盖已读取的记录。检测和配置入口与当前有效节点绑定。配置进入原快速接入流程，自动带入所选节点。原操作或诊断指向的节点可在筛选之外保留定位。撤销使用原确认、版本和操作标识，正式回执后移入历史。

WorkBuddy 连接显示权限、到期、更新时间与可安全解释的异常原因。重新授权由用户选择权限，可明确复用当前仍可申请的权限，并对照新增、取消、保留和已不可申请的范围。本地断开在正式回执后收进默认折叠的已断开记录。直接链接定位到历史账号时展开原记录。原授权与未知操作恢复在同一个账号上下文内处理。

凭证有效、节点在线、工具可用及任务可派发各自显示。撤销或本地断开保留历史运行依据。手动登记节点提供「轮换凭证」。操作者确认原进程已停止，服务端核对排空后沿原节点签发一次性新凭证。使用受控配置替换原 SUMA_RUNNER_TOKEN，再按原节点和工作目录启动。界面核对原操作并提示新库存上报，WorkBuddy 的供应商授权仍需独立验收。 [轮换合同](../../contracts/manual-runner-rotation.md)
