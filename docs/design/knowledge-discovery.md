# 已发布知识发现交互

状态：限定实现与验证完成；负责人：工作台代理；T-KNOWLEDGE-DISCOVERY-196。[需求](../product/knowledge-discovery.md) · [合同](../../contracts/knowledge-discovery.md) · [架构](../architecture/knowledge-discovery.md)。

资料、任务派发和讨论复用统一的发现与准确预览组件。保持原导航，先输入关键词或浏览，再预览、明确选择；技术引用和来源按需展开。搜索结果不自动成为任务输入。

| 当前事实 | 用户操作与反馈 |
| --- | --- |
| 浏览发布知识 | 三类共用类型筛选；提示当前项目已发布范围 |
| 搜索中 | 保持输入和已选引用，防止重复提交与旧响应覆盖 |
| 当前页有命中 | 展示准确发布标题、类型、片段及来源数；打开原修订预览 |
| 空页但仍有游标 | 提示当前批次未命中，提供继续查找，保留查询条件 |
| 已扫描到尾 | 按当前查询显示空态或已结束，不夸大全项目覆盖 |
| 预览准确旧发布 | 展示正文、来源、修订和摘要；当前资格有效才允许明确选入 |
| 已选引用不在当前页 | 选择保留，按准确ID独立核验；搜索和翻页不能取消或升级引用 |
| 新发布／退役／来源变化 | 保留原引用解释冲突，引导重新预览；原任务门禁再次核验 |
| 账户、组织或项目变化 | 取消或隔离旧读取，清除旧作用域内容；失权后不保留可操作旧结果 |
| 临时读取失败 | 保留用户输入和准确引用，提供明确重试；错误不变成空结果 |

中文和英文共享状态码、权限与引用逻辑；业务原文、SHA和版本不翻译。窄屏按搜索、结果、预览顺序排列，长引用换行，键盘可完成搜索、预览、选择和返回，关闭面板后焦点回到触发入口。

验证以共享组件的代表布局和真实消费者为范围，覆盖精确预览、分页后的已选引用、权限变化及迟到响应；完整设备矩阵留在发布验收。
