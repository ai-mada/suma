# Cursor node configuration and service lifecycle

Status: scoped implementation verified; authenticated vendor and production acceptance remain separate. suma1.0.0, T-CURSOR-SETUP-191. See the [contract](../../contracts/cursor-setup.md), [architecture and AI SOP](../architecture/cursor-setup.md), [design](../design/cursor-setup.md) and [scoped evidence](../quality/cursor-setup-verification.md). The full31-requirement/P0–P7 objective remains active.

The existing advanced tool entry opens one Cursor guide. It collects the target shell, official package directory, complete reviewed version, exact model ID, credential environment reference and a new command-file path. Go derives the fixed Node/index.js host and complete package digest; users do not construct private JSON, hashes, arbitrary arguments or secret values.

The generated command uses the existing `--prepare-tools` with `--prepare-acp-stdin`. Preparation checks the destination before reading input and creates a new allowlist exclusively. It does not overwrite files, read credentials, run a model, register a worker or claim work. PowerShell/Bash quoting and UTF8 are explicit; shell encoding changes are local and restored.

An explicit action transfers the non-authoritative file/shell draft to the original node guide. Identity, project, reporting, fresh inventory, paused registration and separate enablement retain their existing authority. Copying a command is not file creation, connectivity or model health.

Cursor ACP is a service. After an exact successful RPC, with no pending/truncated/unknown input, current context, unchanged source and verified full process-tree termination, an owner-controlled host stop can preserve the RPC operation result. The actual host exit code remains unchanged and separately visible. Cancel is a notification with requested/written facts, not an independent native acknowledgement.

Cancellation, timeouts, errors, partial replies and unproved descendant containment remain unknown. The existing candidate, independent same-commit tests and human acceptance gates stay in force. Controlled local evidence is separate from authenticated vendor models, other operating systems, installation, distributed scale and production acceptance.
