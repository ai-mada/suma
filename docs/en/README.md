# suma 1.0.0 documentation

suma is an intelligent development platform for teams, projects, requirements, design, execution, testing, human acceptance, releases and issue feedback. The full P0–P7 scope and accepted requirements1–25 remain in progress. Business acceptance, execution state, test evidence and deployment are distinct facts.

There is one current **1.0.0** product baseline, with fresh schema initialization and no historical compatibility or automatic legacy database upgrades. Protocol, workflow and business revisions remain independent. Current saved facts, user originals and scoped verification records are preserved.

Simplified Chinese (`zh-CN`) and US English (`en-US`) use extensible catalogs. UI language, business time zone and source content are separate concerns. Original user documents, code, tool output and immutable evidence retain their original language. Detailed documents are not all translated; the links identify the authoritative originals. Library/native controls, installers, exports, notifications and channels need their own implementation and acceptance.

Current local browser checks and protocol fixtures establish only their recorded scope. They do not attest vendor models, commercial bills, physical multi-host execution, operating-system installation or production acceptance. Codex remains observe-only with configuration acknowledgement rather than provider-model attestation; native conflict repair remains a separate, native-only workspace lifecycle.
