# 本地开发工作区目录浏览合同

状态：1.0.0／T-WORKSPACE-106，本机限定实现与验证。负责人：控制面、工作台、主集成代理。关联 P2、P3、需求9、10、15、22；完整范围保持在[实施计划](../docs/delivery/implementation-plan.md)。

## 用户目标与当前接口

大项目按目录浏览真实文件，避免启动 IDE 时遍历整个仓库及静默截断。目录切换、筛选、分页与刷新不关闭编辑器，不改变草稿或原保存请求；Git 审阅沿用原入口。

- `GET /workspace?project_id=...` 只返回 `WorkspaceMetadata{configured,binding_available,name?,reason?}`，不递归扫描、不返回绝对宿主路径或旧 flat files。
- `GET /workspace/tree?project_id=...&directory=...&limit=100&before=...` 返回 `WorkspaceTreePage{project_id,directory,entries,limit,next_cursor,snapshot_sha256,observed_at}`。
- CLI：`suma --project PROJECT workspace files [--directory src] [--limit 100] [--before CURSOR]`，只读取一页，不访问客户端文件系统，不自动重试或遍历全目录。
- `WorkspaceTreeEntry{path,name,kind}`，kind 只为 file／directory，path 是相对工作区的正斜杠路径。根目录 directory 为空，缺省 limit100，范围1–200。entries 永远为数组；next_cursor 为空表示本目录末页，不伪造整个项目的总文件数。

请求拒绝未知、重复、非正常编码、无效项目或超限参数。directory 最多1024字节，before最多1024字节；禁止绝对路径、遍历、链接、敏感目录／文件及控制字符。文件打开和保存继续使用已有权限与摘要合同，本接口没有创建、写入、Git或执行权限。

## 一致性与资源界限

只通过当前项目绑定与已经验证的目录根句柄读取一层目录；所有路径组件检查链接。按目录优先、名称字节序稳定排列。最多扫描一个目录10000个原始条目，超过明确失败，不把部分结果说成完整。

分页游标固定调用者、项目、根绑定、目录、可见条目元数据快照与确切上一项。下一页重新核验；目录／绑定变化必须从第一页刷新，不能把两个快照拼接。读取前后核对原身份、当前项目权限、绑定及目录身份。快照只固定所观察的目录元数据，不承诺整棵工作树或文件正文是原子快照。

## 简洁交互与国际化

沿用现有 IDE 侧栏：根与面包屑、返回上级、目录／文件列表、当前目录已加载范围筛选、加载更多及范围提示。选择文件显示当前项；加载、空态、失败和“目录已变化，请刷新”有明确反馈。API或项目身份变化立即清除旧列表和取消请求，迟到回执不得覆盖当前目录；隐藏来源不新增请求；重新激活时先清旧目录并按当前权限重新读取，保留编辑草稿。全部平台文案使用成对中文／英文目录，文件名和用户代码保持原文。

## 必要验收与 AI SOP

检查多页和子目录、当前范围错误与变化、敏感路径／链接、当前授权及元数据不遍历；界面检查目录切换、更多、刷新、草稿保护、迟到请求与两语言。只运行受影响检查和一个代表性浏览器旅程。源码、协议检查、真实本机行为分别记录；本功能不替代完整远程 Git、PTY、LSP／DAP或全平台验收。
