# 固定技能修订比较合同

T-SKILL-COMPARE-157，版本1.0.0。现有组织共享技能目录的只读扩展；不新增正文仓库、后端路由或生成类型。

比较默认收起。展开后以当前账号／组织／目标项目／目录项读取 `GET /skill-catalog/{id}/revisions?project_id={project}&limit=20`，更多历史仅在明确点击后带原分页cursor读取。页面列出已读取的固定目录版本、源知识修订及SHA；两侧必须是不同目录版本，保留服务端原文，不把SHA误称为正文单独哈希。当前项与历史同版记录必须具有相同来源元组和正文；未来版、重复版、错误目录／来源、无效或超界正文整页拒绝。

比较与选择均无写入。只有被比较的一侧包含服务端当前有效目录项，且 `state=published`、`eligibility=current`、`source_current=true`、`can_adopt=true`、`allowed_actions`含adopt时，才显示“采用当前版本”。按钮只打开原采纳表单；原表单继续固定目录版本和origin SHA，要求原因及明确草稿确认，复用useWriteAction的原body/key、冲突及未知恢复。历史正文永不直接采用；比较不发布、不执行、不静默升级既有项目副本／任务／运行。

读响应属于原caller和账号／组织／项目／目录及当前不可变来源元组；换scope取消读取、卸载正文／编辑器，并丢弃晚响应。刷新未核实、读失败、401/403时不显示比较正文；撤权转交原工作区权限处理。历史已超出当前显示版本时整页拒绝；明确重读同时核对当前详情与历史，当前版本改变即关闭旧比较，需重新展开。只读GET不能解除原未知采纳操作。

Monaco使用现装独立MIT依赖，本地ESM和worker按需加载，模型只存内存，换比较对或折叠／撤权即销毁。比较器加载失败可明确重试或改用纯文本对照。界面中英同义、原文不翻译、键盘可操作，窄屏采用内联差异或上下纯文本。

复用Multica8906285的修订冲突比较及刷新确认行为作为参考，复制产品源码0；不引入其受附加许可约束的产品实现。实际验收及未验边界由本阶段质量记录另列，不把组件模拟测试写成真实GUI通过。
