# 核对并结束未封存发布制品

在「工具管理 → 执行节点身份 → 轮换凭证」打开「核对未封存制品」。列表显示原运行、节点、尝试、围栏、清单摘要和声明大小。每页最多 20 项。服务端以当前浏览器项目管理员和手动登记人身份查询原节点当前凭证绑定的上传。节点过期不影响符合条件的核对。

当前仍在运行、等待或核对的尝试不能结束上传。可结束的依据是原运行中精确匹配节点、尝试、围栏和执行者的已结束记录，以及明确的已知结果。已发布反向引用、封存引用、缺失或冲突的证据会阻止操作。

`GET /api/v1/release-workers/{id}/artifact-uploads?project_id=P&cursor=UPLOAD_ID` 返回授权范围内的安全摘要，不返回执行输出、凭证、文件内容或存储路径。省略 cursor 读取首页。围栏以十进制字符串返回以保留精确值。

`POST /api/v1/release-workers/{id}/artifact-uploads/{uploadID}/abandon` 要求当前节点版本、原清单摘要、明确确认和原操作编号。提交与现有项目授权和调度锁一起复核。只将原上传从 `receiving` 改为 `abandoned`。清单、已收文件、声明配额和历史运行继续保留，新的写入或封存被拒绝。旧操作回执仍可按当前授权核对。正式发布制品、候选、执行结果和业务验收各自沿原合同表达。

收到原回执后刷新列表。轮换是用户另行确认的操作，其他未决执行或候选代码传递仍由原排空规则判定。
