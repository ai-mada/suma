# 人员工时登记合同

状态：T-WORKLOG-135，初始1.0.0；负责人：计划领域／工作台。原P3人员协作范围，非新的派发或计费权威。源码与实际验证边界见[报告](../docs/quality/worklogs-verification.md)。

## 正式语义

`Worklog`是人员明确登记的工作事实陈述，`source=human_manual`；不是自动测量、工资、验收批准、机器执行耗时、模型用量或供应商账单。不从任务估算、运行时长或日历回填。每项为整数分钟1–1440，日期为明确YYYY-MM-DD业务日期；备注／更正理由是用户原文，最多200个Unicode码点，不翻译、不执行。

`member_id`是当前项目人员资源，不是组织账号ID；服务器通过规范人员绑定和当前组织／项目资格取得`user_id`与姓名。创建时资源必须active、kind=human；任务必须在同项目且当前版本匹配。可以为非本人负责的协作任务登记，不会改变任务负责人、进度或验收状态。

当前具备项目写权限的人员可登记本人工作。浏览器当前管理者为他人操作必须明确`on_behalf_ack=true`；勾选不授予权限。项目API仅可按当前账号资格登记本人；Runner／Agent凭证拒绝进入人员登记域。历史读取使用当前项目读取权限；离职不抹去原记录。管理者可在明确代办确认及理由后更正／作废原人员历史，不能更换原人员身份。

## 接口

| 方法和路径 | 合同 |
|---|---|
| GET `/worklogs` | 必给`project_id,from_date,to_date`，含端点最多31日；可筛`task_id,member_id,status=all/active/voided`；`limit`默认20、最大50及不透明`cursor` |
| POST `/worklogs` | 完整`WorklogCreateRequest`：项目、任务及`expected_task_version`、人员、日期、分钟、备注、代办确认与稳定操作标识；201返回初始修订 |
| GET `/worklogs/{id}` | 必给项目，返回当前头与当前可操作提示 |
| POST `/worklogs/{id}/corrections` | 完整`WorklogCorrectionRequest`：当前记录`expected_version`、任务及其期望版本、日期、分钟、备注、理由、代办确认、稳定操作标识；不能传人员／账号 |
| POST `/worklogs/{id}/void` | 项目、当前记录版本、理由、代办确认和稳定操作标识；保留原分钟及日期的作废修订 |
| GET `/worklogs/{id}/revisions` | 当前项目授权后按修订倒序分页；默认20、最大50，历史项不可直接修改 |

所有POST拒绝未知／重复／错误大小写字段、null标量、非整数版本／分钟、缺失完整字段和query参数。浏览器写操作沿用原页面账号／组织上下文头。错误由中英消息目录显示；用户原文保留。

列表`WorklogPage`含当前头`items,total,limit,next_cursor,scope_version`、当前筛选范围的`summary.active_count/voided_count/total_minutes`及当前`can_create/can_manage_others/self_member_id`。分钟只汇总有效头，不把更正历史相加。默认all保留作废记录。翻页绑定租户、项目、账号、筛选、页大小及范围版本；任何本项目登记变化后旧游标409，重新加载第一页，避免日期更正后漏项／重复。

## 事务与恢复

每次写入在当前权威事务中复核权限和人员身份，再恢复原成功回执；相同键和正文恢复原修订，不将其改成当前头。旧回执的操作按钮仅在它仍对应当前头时有效。相同键不同正文409。新的更正／作废必须匹配当前头；已作废不再更正，纠错创建新记录。

同租户／真实账号／同日期，跨项目有效分钟合计不得超过1440。整数台账用唯一主键及带上下界条件的原子更新，日期移动将旧减新加按日期顺序锁定；登记头CAS、不可变修订、日汇总、项目范围版本、活动与回执同事务提交，任一步失败全部回滚。错误不披露其他项目或其分钟数。

独立初始域包含`suma_worklogs`、`suma_worklog_revisions`、`suma_worklog_daily_totals`、`suma_worklog_scopes`。完整当前声明数据库可安装空域；已存在不完整表、缺列或错误主键在初始化写入前拒绝。没有旧工时导入、历史估算转换、双写兼容路径或用户数据清理。

## 交互与边界

开发→计划→工时：按已选周显示精确有效登记和作废数量，按需打开登记、更正、作废或历史。人员默认本人；代办显式确认。表单保留草稿，结果未知时沿用原操作和原身份重试；冲突核对当前记录后再发新操作。周切换、项目／账号切换与关闭沿用离开保护。任务／人员选择器说明已加载范围，不能把前端角色当授权。

当前不提供HR审批、工资／账单、自动计时、跨组织身份合并、离线写许可或跨项目计划容量扣减。完整平台需求1–26和58／34／92总账保持待交付边界；这些功能不能由工时登记推断完成。
